# B0 · 原力创业四关 · 证据计划

> 状态：candidate / to_verify  
> 用途：为“一势两账三链四权”总论课建立理论、数据、案例与反例证据槽位。

## 1. 本课需要证明什么

1. 创业失败可被区分为势、账、链、权四类首要瓶颈。
2. 前台教学压缩不应替代后台正典。
3. 识别首要瓶颈比同时改造全部经营问题更适合作为首次行动。
4. 30天实验与回写可以把课堂理解转化为可验证结果。

## 2. 四证计划

| 证据类型 | 证明内容 | 当前状态 | 下一动作 |
|---|---|---|---|
| 理论证 | 环境适配、价值选择、商业闭环与控制权是不同机制 | candidate | 从B1—B4正典来源中提取一手文献 |
| 数据证 | 学员能否正确区分四关并提高诊断一致性 | to_verify | 首轮试讲做前测与后测 |
| 案例证 | 同一企业的首要瓶颈可被四关定位并形成行动 | candidate | 选择3个已授权真实案例 |
| 反例证 | 仅靠流量、降价、加产品或保密无法解决其他关问题 | candidate | 建立至少4个边界型案例 |

## 3. 首轮试讲数据

建议样本：8—12位专家型创业者。

采集：

- 课前对“生意不好”的自由归因；
- 课后四关分类正确率；
- 后台正典与教学投影区分率；
- 四关诊断卡完成率；
- 30天实验合格率；
- 七天内启动率；
- 高频误解与用户原话。

## 4. 工作假设阈值

- 至少80%能复述四关问题；
- 至少75%能区分教学投影与正典模块；
- 至少70%完成合格诊断卡；
- 至少60%形成可证伪30天实验；
- 至少50%在七天内启动行动。

以上阈值均为工作假设，须在真实试讲后校准，不得提前写成已验证事实。
