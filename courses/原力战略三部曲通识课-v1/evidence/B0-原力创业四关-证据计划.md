## 3. 外部理论证计划

### E-THEORY-01 · 瓶颈与串行系统

- 证明什么：在由多个相互依赖环节构成的系统中，整体表现会受到主约束或薄弱环节显著影响。
- 来源候选：约束理论、系统动力学、运营管理的主瓶颈研究。
- 证据等级：primary。
- 状态：to_verify。
- 课程用途：支持“看见全局后只打一场主战役”，不用于声称企业永远只有一个瓶颈。

### E-THEORY-02 · 用户选择与价值框架

- 证明什么：用户对价值的判断不仅由价格决定，还受到时间、风险、努力、比较框架与预算分类影响。
- 来源候选：行为经济学、JTBD、感知价值研究。
- 证据等级：primary / longitudinal_or_cross_case。
- 状态：to_verify。
- 课程用途：支持极致性价比的总成本定义；不得把“两账”包装成成熟学术分类。

### E-THEORY-03 · 能力保留与组织化

- 证明什么：一次性成功若没有被流程、数据、关系和组织能力保留，难以形成持续优势。
- 来源候选：组织能力、动态能力、知识基础观研究。
- 证据等级：primary。
- 状态：to_verify。
- 课程用途：支持四权与 OS 回写的必要性。

## 4. 数据证计划

### E-DATA-01 · 三链经营数据

需要寻找同一业务内可对照的：

- 流量 / 线索 / 转化；
- 客户结果 / 复购 / 推荐；
- 收入 / 毛利 / 现金流 / 创始人工时；

用来证明单一增长指标无法代表完整模式健康度。

状态：to_verify。

### E-DATA-02 · 四权运营指标

候选指标：

- 心智：无辅助提及、品类复述、品牌搜索、信任来源；
- 交付：结果稳定度、创始人介入、复用资产、质量偏差；
- 入口：自然线索、转介绍、渠道集中度、网络贡献；
- 留存：复购、迁移成本、活跃、数据沉淀、共建行为。

状态：working_hypothesis；不得作为冻结正典指标。

## 6. 反例计划

1. 一势很弱，但依靠强关系或政策保护仍能短期盈利。
2. 两账表达清晰，但交付失败导致业务不成立。
3. 三链运转良好，但平台规则变化使入口突然丧失。
4. 四权较强，但市场需求整体消失。
5. 四关评分全部较高，却因团队治理、合规或重大风险事件失败。

课程边界：四关是原力创业 B 轴诊断地图，不替代全部公司治理、法律、财务与风险管理。

## 7. 教学验证证据

首轮建议样本：8—12 位专家型创业者。

### 课前

- 四种失败原型直觉选择。
- 对“势、心理账户、商业模式、壁垒”的原始定义。

### 课后即时

- 无提示复述四关。
- 正典名称与教学标签区分题。
- 两账与心理账户区分题。
- 四关诊断卡完成率与评分质量。
- 主瓶颈选择与讲师复判一致率。

### 七天

- 他人独立复判提交率。
- 诊断卡 v2 修改率。
- 30 天实验是否启动。

### 三十天

- Action 是否真实发生。
- 成功 / 失败 / 修改证据。
- 结果是否写回。

## 8. 首轮通过门

- 至少 80% 能用自己的话解释四关。
- 至少 75% 能区分教学标签与正典模块。
- 至少 75% 不混淆“两账”和完整心理账户体系。
- 至少 80% 完成有证据的四关评分。
- 至少 70% 形成单一、可证伪的 30 天实验。
- 至少 50% 七天内提交他人复判后的 v2。

这些阈值是工作假设，不是已验证标准。
