## 视觉方向

继承本仓：

```text
翡翠墨绿 × 鎏金
#0d2018 × #c9a961
```

视觉原则：

- 内容结构优先于视觉包装。
- 每页只承担一个认知动作。
- 高信息密度不等于缩小字号。
- 图必须帮助判断，不做装饰性架构图。
- 第一眼击中困境，第二眼看懂结构，第三眼知道行动。
- B0 总图必须画成串行链，不画成四个并列模块。
- B4 外围只显示“飞轮强化 / 母体生成”，不得与四权并列。
