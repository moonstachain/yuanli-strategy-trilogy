## 1. 战略原点

- 对象：有十年以上经验、正在用AI重构事业的企业家、专家型创业者和高认知个体。
- 高价值问题：如何避免能力被AI平权，把自身不可复制性转化为能复利的生意与系统。
- 学习终态：学员先理解并认同“原力战略”，再判断自己卡在A、B、C哪一部，并在30天内完成一个可检查产物。
- 本轮不做：不一次讲完全部理论，不把12个模块平均铺陈，不直接批量生成其余九模块完整讲稿。

课程北极星：

> **把创始人的不可复制性，变成可复利、可传承、可系统化的事业生命体。**

母机制：

> **每一次输出，都必须成为下一次输入。**

## 2. 课程承诺

这不是一门“听懂三部曲”的概念介绍课，而是让学员第一次完成一条完整认知链：

```text
为什么旧人生算法正在失效
→ 什么是原力战略
→ 为什么必然分成三部
→ 我当前卡在哪里
→ 未来30天只做什么
→ 结果写回哪里
```

总产物：

> 《我的原力战略起点卡 v2》+ 一项30天可验证行动 + 第一条回写机制。

## 4. L0核心概念课教学逻辑

统一采用：

```text
WHY → WHAT → HOW
```

### WHY：为什么AI时代必须有原力战略

三种第一性视角：

- 人文心智：保留价值主权。
- 数理逻辑：形成非对称优势。
- 复杂系统：建立递归进化能力。

统一公式：

```text
价值主权 × 非对称优势 × 递归进化
```

### WHAT：原力战略是什么

- 正典母定义：资产化、事业化、生命化。
- 底层进化定义：变异源、选择环境、保留机制、递归再生成。
- 小白定义：找到不可复制的东西，让世界认出，让生意放大，让系统越做越强。

### HOW：三部曲如何实现

```text
原力资产：建立独特生成源
原力创业：建立真实选择与放大机制
原力OS：建立保留、回写与再生成机制
```

## 6. 明哥主案例

公开安全主线：

```text
发现隐藏主线
→ 翻译复杂认知
→ 形成战略结构
→ 沉淀复利系统
```

在三部中的投影：

- A：从多段职业标签退回“从复杂中发现隐藏主线，并翻译为可执行战略系统”的生成源头。
- B：把这一源头放进企业家的贵问题、原力战略品类、产品和交付系统。
- C：把经验写成文脉、大脑、CBM战略地图、OSA/Codex链路与Skill。

边界：

- 只使用已公开、已确认材料。
- 未确认的私人经历不进入讲稿。
- 作者价值裁决保持 `pending`，直到本人确认。
- 单一案例只解释机制，不承担普遍性证明。

## 7. L0核心概念课验收门

### 7.1 桌面结构验收

- [ ] 唯一概念、唯一判断、唯一产物一致。
- [ ] WHY—WHAT—HOW链路完整。
- [ ] 三种第一性视角没有互相重复。
- [ ] 三部曲只作实现路径简介，不提前展开十二模块。
- [ ] 定义、非定义、机制、边界齐全。
- [ ] 起点卡能直接生成30天行动。
- [ ] PPT蓝图每页只承担一个认知动作。
- [ ] 外部证据均已标注核验状态。

### 7.2 首轮真实试讲门槛

建议样本：8—12位创富圈或相近的专家型创业者。

最小通过门：

1. 至少80%学员能用自己的话解释原力战略。
2. 至少80%学员能说出AI时代的三场结构性危机。
3. 至少75%学员能正确区分原力战略与职业规划、能力升级、追风口和AI提效。
4. 至少80%学员能判断自己当前卡在A、B或C。
5. 至少70%学员完成符合评分尺的《原力战略起点卡v2》。
6. 至少50%学员在七天内提交迁移结果。
7. 收集至少三条高频误解、三条有效用户语言和两个失败样本。

这些门槛是首轮工作假设，真实试讲后再校准。
