## 使用顺序

1. 讲师先读讲师手册，确认唯一判断、唯一产物和不得自动执行的动作。
2. 学员只填写匿名 ID；姓名、公司、客户、收入、录音地址与私密链接不入仓。
3. 观察员在 XLSX 中分别记录第一班和第二班，不合并样本掩盖某班失败。
4. `SYNTHETIC_DEMO` 只验证公式与格式，永不进入真实课堂指标。
5. 真正开课前仍需明哥确认排期、8–12 人名单、录制授权和隐私告知。

## 边界

- PPT、DOCX、XLSX 都是本地课程资产，不会自动上传或发布。
- 工作簿状态 `metrics_met_pending_human` 只代表公式门，不能自动改为 `live_trial_pass`。
- 无真实逐字稿和时码，就不生成现场金句和真实短视频候选。
- 小鹅通只保留本地未发布草稿创建包；定价、分享、通知、支付、删除均未授权。

详细验证见 `../receipts/03-asset-validation.json`。
