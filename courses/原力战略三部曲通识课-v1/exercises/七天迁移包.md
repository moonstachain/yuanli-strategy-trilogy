# 七天迁移包

> 当前为离线模板。尚未创建飞书任务、表格或消息，也未写入任何学员信息。

## 学员回传

```text
匿名代号：
课堂主卡点：A / B / C
七天最小动作：
实际完成时间：
行动证据指针：
这条证据：支持 / 削弱 / 推翻 原判断
我学到的不是感想，而是：
下一步：继续 / 修改 / 停止
```

有效证据至少满足一项：

- 可回读的访谈、客户反馈或市场行为。
- 可检查的原型、页面、文件、流程或交付记录。
- 可复现的行动链及其 Evidence / Writeback。
- 明确的反证，足以修改或推翻主卡点判断。

学习感想、转发截图、无内容的打卡或只有口头声称不计为有效行动证据。

## 匿名汇总字段

| 字段 | 说明 |
|---|---|
| class_id | 班次代号，不含个人身份 |
| participant_alias | 随机代号 |
| start_card_score | 0–10 |
| main_constraint | A / B / C |
| two_fact_pass | yes / no |
| evidence_returned_7d | yes / no |
| evidence_valid | yes / no |
| judgment_change | support / weaken / overturn |
| misunderstanding_code | 匿名主题代码 |

## 课程验收公式

- 两事实判断率 = `two_fact_pass=yes` 人数 / 到课人数，目标 ≥ 80%。
- 8/10 达标率 = `start_card_score>=8` 人数 / 到课人数，目标 ≥ 70%。
- 七天有效证据率 = `evidence_valid=yes` 人数 / 到课人数，目标 ≥ 50%。

两班分别计算，不用合并结果覆盖某一班失败。

## 人工门

在明哥确认参与者授权、字段最小化、通知文案和发送范围之前，不创建飞书 Base、任务或消息。任何外部写入只针对获准动作，不自动授权后续提醒或公开传播。
