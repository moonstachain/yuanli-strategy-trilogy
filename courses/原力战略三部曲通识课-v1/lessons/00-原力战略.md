## B. 学习契约

### B1. 学员课前的典型旧判断

```text
我有很多能力和经验，只要继续学习更多技能、找到更大流量、使用更强AI，事业就会变得更好。
```

旧判断常表现为：

- 把能力数量当作长期优势。
- 把热门赛道当作战略。
- 把个人独特性理解为履历、头衔、人设或天赋标签。
- 把市场理解为迎合对象，而不是现实选择环境。
- 把知识库、自动化和智能体理解为原力OS。
- 把项目完成理解为能力已经积累。

### B2. 本课要改变的唯一判断

> **AI时代，真正的长期优势不是拥有更多通用能力，而是让个人独特人生算法持续产生差异，进入真实世界接受选择，并把有效结果保留成下一轮能力。**

### B3. 学完后能够完成的动作

学员能够：

1. 用自己的话复述“原力战略”的正典定义和白话定义。
2. 说清原力战略为什么在AI时代成为必要，而不是可选项。
3. 区分原力战略与职业规划、能力升级、个人品牌、追风口和AI提效。
4. 解释为什么三部曲必然对应自我、世界、时间三个维度。
5. 判断自己的当前主瓶颈位于原力资产、原力创业还是原力OS。
6. 设计一个30天可验证、可回写的最小行动。

### B4. 最终产物

> 《我的原力战略起点卡 v2》

至少包含：

- 我正在被AI平权的能力。
- 我可能的独特生成源线索。
- 我当前的A/B/C主瓶颈。
- 我未来30天唯一行动。
- 完成证据、反证条件与回写位置。

### B5. 验收标准

1. 能准确复述原力战略，不把它说成能力提升或职业规划。
2. 能从人文心智、数理逻辑、复杂系统三个角度说明必要性。
3. 能解释原力资产、原力创业、原力OS为何缺一不可。
4. 能找到自己的一个真实问题，而不是填写抽象口号。
5. 30天行动包含期限、证据、失效条件和回写位置。
6. 能把概念迁移到一个课堂未讲过的新情境。

## C. 课程第一性目标：完成一次认知迁移

本课不是增加一个新名词，而是让学员完成以下迁移：

```text
旧认知
我有很多能力与经验
→ 只要更努力、更专业、更高效
→ 事业自然会增长

认知冲突
AI正在平权大量“会做事”的能力
→ 通用能力成本下降
→ 经验若不外化、验证、回写，仍然只是个人消耗

新认知
我需要找到持续生成差异的源头
→ 把它放进时代与市场
→ 再把有效结果写入系统
→ 让每一轮行动提高下一轮起点
```

一句话课程目标：

> **让学员理解并认同原力战略，知道它解决什么、为什么必需、与自己什么关系。**

## D. 小切口：能力越多，为什么反而越难形成复利？

### D1. 主人公

一位拥有十五年以上经验的专家型创业者。

### D2. 具体时刻

他准备向潜在客户介绍自己，却发现必须不断罗列：行业经历、岗位、项目、课程、证书、客户、工具和AI能力。

### D3. 表面问题

> 我还缺一个更准确、更高级的个人定位。

### D4. 真正两难

- 继续增加能力与标签，获得短期安全感；
- 还是退回所有能力背后，找到持续生成差异的源头。

### D5. 已经发生的代价

- 每个项目仍高度依赖本人。
- 团队无法复制关键判断。
- 内容很多，但没有形成同一条主线。
- 工具越来越多，辨识度反而越来越低。
- 做过很多事，却没有提高下一次工作的起点。

### D6. 旧解释为什么失效

如果真正的问题只是技能、流量、团队或AI工具不足，那么增加这些要素之后，事业应该明显减轻对创始人的依赖。

但现实常常相反：

```text
能力越多 → 选择越散
业务越多 → 本人越忙
内容越多 → 认知越模糊
AI越强 → 平均答案越多
项目越多 → 沉淀仍然不足
```

### D7. 开场问题

> **当你的职位、工具、平台和大部分技能都能被AI辅助甚至平权之后，什么仍然值得围绕你长期构建？**

### D8. 学员自检

- 我最依赖本人完成的工作是什么？
- 如果我离开一个月，哪种价值最先下降？
- 过去三年，我重复做了哪些工作，却没有让下一次更容易？

## E. WHY：为什么AI时代必须有原力战略

WHY不是“AI很强，所以我们要更独特”。

本课要证明：AI改变了人生竞争的基本条件，旧的人生算法正在同时遭遇三场结构性危机。

```text
人文心智 → 价值主权危机
数理逻辑 → 比较优势危机
复杂系统 → 静态规划危机
```

---

## F. 人文心智：AI越会回答，人越要决定什么值得回答

### F1. 第一性起点

人不是只负责执行目标的机器。

人还必须决定：

- 什么值得占用有限生命；
- 哪种成功值得追求；
- 哪种代价不能支付；
- 愿意为谁承担责任；
- 想成为怎样的人。

这属于人的价值函数。

### F2. AI带来的结构变化

AI正在降低答案、表达、整理、分析与标准执行的成本。

当“怎样做”越来越容易获得，真正稀缺的问题变成：

> **做什么、为什么做、什么不做、愿意承担什么后果。**

### F3. 价值主权危机

```text
平台告诉我什么有流量
市场告诉我什么赚钱
同行告诉我什么算成功
AI告诉我怎样表达
算法告诉我下一步看什么
```

一个人可能越来越高效，却越来越不知道：这些目标究竟是不是自己的目标。

### F4. 第一性结论

> **AI可以帮助人优化手段，但人生的目的函数必须由人自己承担。**

原力战略在人文心智层面保护的，不是固执的自我，而是：

```text
价值由自己承担
→ 解法进入现实检验
→ 判断在反馈中成熟
```

### F5. 人文心智原则

> **保留价值主权。**

没有价值主权，效率越高，可能越快走向一个不属于自己的人生。

## G. 数理逻辑：通用能力越便宜，独特判断越值钱

### G1. 第一性起点

人生是有限资源面对无限可能的动态配置问题。

有限资源包括：

- 时间；
- 注意力；
- 身体能量；
- 资本；
- 信用；
- 深度关系；
- 能够承担的重大失败次数。

### G2. AI改变能力价格

当一种能力可以被低成本、大规模调用时，它仍然重要，但不再天然形成长期超额回报。

所以“拥有AI”类似“拥有电力”：

> 它可能成为经营基础设施，却不会自动构成战略差异。

### G3. 人真正的长期优势

更可能来自：

- 独特的问题定义；
- 深度领域经验；
- 跨领域组合；
- 品味与价值判断；
- 用户隐性需求洞察；
- 长期关系与信任；
- 高不确定性中的裁决；
- 对结果承担责任的能力。

这些共同构成一个人的独特人生算法。

### G4. 教学诊断式

```text
长期事业价值
≈ 独特优势
× 高价值问题
× 时代杠杆
× 可持续时间
× 系统回写率
```

这是乘法关系的理解工具，不是财务测算公式。

### G5. 第一性结论

> **有限生命不能平均投入，必须集中到少数具有独特优势、正期望、非对称回报和复利效应的问题。**

### G6. 数理逻辑原则

> **形成非对称优势。**

不是比所有人更强，而是在某类高价值问题上形成难以被平均化的优势边。

## H. 复杂系统：未来不可预测，所以必须设计能够进化的自己

### H1. 第一性起点

现实世界不是静态棋盘。

用户、竞争者、技术、平台、制度和自己都在不断变化，并相互影响。

### H2. AI加速系统变化

AI同时提高：

- 内容与产品生成速度；
- 模仿速度；
- 信息流速；
- 市场反馈频率；
- 商业模式变化速度；
- 既有优势被侵蚀的速度。

### H3. 静态规划危机

传统线性规划假设：

```text
确定目标 → 找到路径 → 坚持执行 → 抵达终点
```

在复杂适应系统中，今天的最优解可能很快成为明天的惯性。

### H4. 进化循环

```text
产生差异
→ 接受选择
→ 保留有效结果
→ 在更高起点再次产生差异
```

对应：

```text
变异
→ 选择
→ 保留
→ 再变异
```

### H5. 第一性结论

> **在不可预测环境中，真正强大的不是一次找到正确答案，而是持续感知、试验、选择、保留和更新。**

### H6. 复杂系统原则

> **建立递归适应能力。**

系统是否进化，不看做了多少项目，而看每一轮结果是否改变下一轮起点。


## J. WHAT：原力战略究竟是什么

### J1. 正典母定义

> **原力战略，是围绕一个人不可复制的生成源，依次完成资产化、事业化与生命化，使独特性在不被稀释的前提下被世界放大、被系统继承，并在时间中形成复利的战略。**

### J2. 底层进化定义

> **原力战略，是构建一个以个人独特人生算法为变异源、以真实市场为选择环境、以原力OS为保留机制的递归进化系统。**

### J3. 小白定义

> **找到你真正不可复制的东西，让世界认出它，让生意放大它，让系统把它越做越强。**

### J4. 记忆钩子

> **找到原力，进入世界，形成复利。**

### J5. 超级命题

> **让不可复制的你，创造可复制、可传承、会进化的事业。**

### J6. 核心机制

```text
找到持续生成差异的原力母体
→ 训练成可调用资产
→ 放进时代、用户心智与商业系统
→ 将每一次结果回写
→ 使下一轮更强
```

## K. 原力战略不是什么

原力战略：

- 不是单纯职业规划；
- 不是能力清单升级；
- 不是只做自己喜欢的事；
- 不是个人品牌包装；
- 不是追逐风口；
- 不是把个人完全标准化；
- 不是使用更多AI工具；
- 不是把人生所有部分自动化；
- 不是一次性找到一个永不变化的“真我”。

关键边界：

```text
价值由人承担
解法由现实检验
已验证结果由系统保留
新环境继续要求更新
```

## L. 原力战略解决的五次形态升级

原力战略不是局部优化，而是完成五次状态转换。

### L1. 隐性经验 → 独特生成源

过去：我凭感觉做得好。

升级：看见持续生成判断、作品、关系和意义的底层规则。

### L2. 个人能力 → 原力资产

过去：能力只存在于本人。

升级：能力可以被表达、训练、调用、验证和复用。

### L3. 原力资产 → 用户价值

过去：我擅长什么。

升级：谁的什么高价值问题最适合由我的原力解决。

### L4. 用户价值 → 可复利事业

过去：项目、收入与流量。

升级：品类、利润容器、交付系统与关键控制权。

### L5. 经营结果 → 自进化系统

过去：项目结束，只留下收入和疲惫。

升级：留下文脉、记忆、判断、地图、链路与下一轮能力。

完整链路：

```text
隐性生命经验
→ 原力母体
→ 原力资产
→ 市场价值
→ 事业系统
→ 递归生命体
```

## M. 原力战略的第一性结构

原力战略的底层进化循环：

```text
个人独特人生算法
→ 产生差异、假设与解法
→ 进入真实市场接受选择
→ 原力OS保留被验证的结果
→ 回写并升级人生算法
```

可以压缩为：

```text
独特生成
→ 现实选择
→ 系统保留
→ 递归再生成
```

## O. HOW：三部曲是原力战略的实现路径

第一课只简介三部曲，不展开十二模块细节。

### O1. 原力资产：建立独特生成源

第一性问题：

> **差异价值从哪里产生？**

四步：

```text
发现母体
→ 回到母体
→ 获得原力
→ 显化原力
```

终态：可进入市场与OS的原力资产。

### O2. 原力创业：建立真实选择与放大机制

第一性问题：

> **差异价值如何被世界接受、交换和放大？**

四步：

```text
原力借势
→ 品类独创
→ 模式升维
→ 壁垒锁定
```

终态：会复利、守得住、可放大的事业。

B4冻结口径：

```text
虚壁垒 = 心智控制权
实壁垒 = 交付控制权
入壁垒 = 入口控制权
出壁垒 = 留存控制权
```

飞轮是四大控制权相互强化的机制，不是第五种壁垒。

### O3. 原力OS：建立保留、回写与再生成机制

第一性问题：

> **已经产生的价值如何跨时间积累并使下一轮更强？**

四步：

```text
一纸文脉
→ 一个大脑
→ 一张地图
→ 一条链路
```

终态：会递归进化的工作生命体。

### O4. 三部同构关系

```text
自我 × 世界 × 时间
价值生产 × 价值交换 × 价值积累
生成源 × 外部接口 × 递归系统
变异源 × 选择环境 × 保留机制
```

### O5. 缺一不可

```text
只有原力资产：有独特性，但可能没有市场结果。
只有原力创业：有收入，但可能高效率放大同质化。
只有原力资产 + 原力创业：能做成项目，但创始人仍可能是瓶颈。
没有原力OS：每一次成功都无法提高下一次起点。
```

## P. 概念心智加工协议

本课按照十二步处理“原力战略”概念：

1. 学员症状：能力很多，事业却不复利。
2. 旧有解释：缺流量、团队、技能或AI。
3. 认知冲突：增加这些以后，创始人依赖反而更重。
4. 第一性问题：如何让独特性被放大而不被稀释？
5. 正典定义：资产化、事业化、生命化。
6. 它不是什么：排除职业规划、能力升级、风口和工具化误解。
7. 为什么成立：价值主权、非对称优势、递归进化。
8. 全局位置：原力战略是道，三部曲是法。
9. 一叶知秋案例：从隐性判断到市场位置再到系统回写。
10. 自我映射：判断自己的A/B/C主瓶颈。
11. 最小输出：原力战略起点卡。
12. 下一概念伏线：差异价值究竟从哪里产生？

## Q. 120分钟课程流程

课程采用“破局—建模—全景—对号入座—行动”的五段式结构。

### 第一段：破局（0—20分钟）

目标：击中痛点，制造必要性。

```text
0—3分钟：学习承诺与验收说明
3—10分钟：专家型创业者小切口
10—15分钟：AI平权后的三个失效现象
15—20分钟：提出母问题与课前自诊断
```

关键输出：

- 我的当前困境一句话。
- 一个尚未被解释的反常现象。

### 第二段：建模（20—50分钟）

目标：讲透原力战略为什么成立。

```text
20—30分钟：人文心智——价值主权
30—40分钟：数理逻辑——非对称优势
40—50分钟：复杂系统——递归进化
```

关键输出：

- 原力战略必要性三证。
- 价值主权 × 非对称优势 × 递归进化。

### 第三段：全景（50—75分钟）

目标：建立全局概念地图与因果链。

```text
50—58分钟：正典定义、底层定义与白话定义
58—65分钟：五次形态升级
65—70分钟：道、法、术、器
70—75分钟：三部曲同构与递归飞轮
```

关键输出：

- 一句话复述原力战略。
- 画出三部曲总图。

### 第四段：对号入座（75—100分钟）

目标：找到当前主瓶颈。

```text
75—82分钟：A/B/C三类典型症状
82—90分钟：案例映射
90—96分钟：个人诊断填写
96—100分钟：同伴互评与修正
```

关键输出：

- 我的主瓶颈：A / B / C。
- 支持判断的三个事实。
- 一个反证或失效信号。

### 第五段：行动（100—120分钟）

目标：把认知转化为下一步行动。

```text
100—108分钟：完成30天唯一行动
108—113分钟：写出完成证据与反证条件
113—117分钟：确定回写位置
117—120分钟：复述、迁移与课程收束
```

关键输出：

- 《我的原力战略起点卡 v2》。
- 30天行动承诺。
- 第一条回写机制。

## R. 关键教学策略

### R1. 击中痛点优先于概念

先让学员认出自己的困境，再给名称。

### R2. 案例驱动理解

案例必须服务概念机制，不作为励志故事。

### R3. 图像先行，文字跟进

先呈现：

```text
独特生成 → 现实选择 → 系统保留 → 递归再生成
```

再展开定义和三部曲。

### R4. 少即是多，记忆钩子化

全课只保留三句核心记忆：

1. 找到原力，进入世界，形成复利。
2. 用独特性创造价值，用现实校准判断，用系统积累人生。
3. 每一次输出，都必须成为下一次输入。

### R5. 对号入座与自我映射

所有概念必须回到学员的：

- 真实项目；
- 用户；
- 业务瓶颈；
- 时间配置；
- 系统沉淀。

### R6. 微实践产生掌控感

学员不需要在课堂找到最终母体，只需完成一次可靠诊断与一个可验证行动。

### R7. 伏线式引导

课程不讲完十二模块，而是制造三个必然问题：

```text
我的差异价值究竟从哪里来？
它如何进入真实世界？
有效结果如何不再消失？
```

### R8. 回写机制贯穿始终

每个输出都必须回答：

- 写回哪里；
- 谁负责；
- 何时更新；
- 什么证据触发升级。

## S. 一叶知秋案例结构

主案例不得虚构陌生人物经历。

优先采用明哥公开安全主线：

```text
发现隐藏主线
→ 翻译复杂认知
→ 形成战略结构
→ 沉淀复利系统
```

### S1. 原力资产投影

从IBM、教育互联网、创业、课程、内容与AI项目的表面差异中，寻找持续重复的生成规则。

### S2. 原力创业投影

把“从复杂中发现隐藏主线，并翻译为可执行战略系统”的源头，放进企业家高价值问题、原力战略品类与交付系统。

### S3. 原力OS投影

把经验写成：

- 文脉；
- 大脑；
- CBM战略地图；
- OSA / Codex行动链路；
- Skill与回写机制。

### S4. 案例使用边界

- 只使用已公开、已确认材料。
- 不替作者编造人生事件。
- 作者价值裁决保持 `pending`，直到明哥确认。
- 单一案例用于解释机制，不证明普遍性。

## T. 高弧光

### T1. 旧信念

> 能力越多，机会越多，人生就越安全。

### T2. 现实击穿

AI让大量能力快速外化；机会越多，如果没有稳定生成源与选择标准，反而越容易分散。

### T3. 真实代价

- 做得很多，却没有形成同一条主线。
- 客户认可本人，却无法形成组织能力。
- 项目成功，却没有提高下一次起点。

### T4. 价值裁决

> **不再用“我还能做什么”配置一生，而用“什么值得围绕我的独特生成源长期构建”作出选择。**

### T5. 主动放弃

- 放弃“什么都能做”的安全感。
- 放弃平均配置生命。
- 放弃把每个机会都变成项目。
- 放弃只收获当期结果、不沉淀下一轮能力的工作方式。

### T6. 人格金句

> **原力战略，不是帮助你成为另一个更成功的人，而是把只有你能持续生成的东西，变成一个离开今天的你，仍然可以不断成长的事业系统。**

### T7. 作者确认状态

`pending`

### U2. 现场练习

1. 写出三项正在被AI平权的能力。

5. 选择一个30天最小产物。
6. 写出完成证据、反证条件和回写位置。

### U3. 评分规则

#### 0分：概念未进入现实

- 只有口号；
- 没有真实问题；
- 没有行动与证据。

#### 1分：能复述，但不能诊断

- 能讲定义；
- 无法判断自己的主瓶颈。

#### 2分：能诊断，但行动不可验证

- 找到A/B/C卡点；
- 行动仍然宽泛，没有期限或证据。

#### 3分：形成可执行闭环

- 有真实主瓶颈；
- 有30天唯一行动；
- 有完成证据；
- 有反证条件；
- 有明确回写位置。

### U4. 七天迁移任务

选择一个课堂没有讨论的项目，回答：

```text
它当前主要缺生成源、选择环境还是保留机制？
我依据什么事实作出判断？
最小修复动作是什么？
结果写回哪里？
```

### U5. 失败信号

- 把所有问题都选为主瓶颈。
- 30天行动仍然是“继续学习”“多做内容”“使用AI”。
- 没有可观察的完成证据。
- 没有写出什么事实会推翻当前判断。
- 输出完成后没有进入任何系统。

### U6. 下一课接口

## W. 递归回写

真实试讲后必须收集：

### W1. 学员新语言

- 学员如何自然描述“独特人生算法”。
- 学员如何描述“被AI平权”。
- 学员如何区分资产、创业和OS。

### W2. 高频误解

- 原力等于天赋或兴趣。
- 原力战略等于个人定位。
- 市场验证等于迎合市场。
- OS等于知识库或自动化。
- 递归等于复盘总结。

### W3. 有效案例

记录哪些案例真正帮助学员完成迁移，而不是只产生赞叹。

### W4. 失败案例

记录哪些学员能复述定义，却不能找到真实主瓶颈。

### W5. 新证据

新增理论、数据、案例和反例一律先进入课程证据包，标记核验状态。

## Y. 最终收束

本课只要求学员记住三句话：

> **AI越会提供答案，人越要决定什么问题值得回答。**

> **通用能力越容易获得，个人独特人生算法越成为长期优势。**

> **环境越不可预测，越不能依赖一次正确，而要建立持续进化的系统。**

最终定义：

> **原力战略，是让个人独特人生算法进入真实世界接受选择，并让每一次有效结果成为下一轮更强起点的人生与事业战略。**
