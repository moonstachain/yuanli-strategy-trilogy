## 课程总命题

> AI 时代，真正稀缺的不是“会做事”，而是把不可复制的生成源头，放进时代与市场，再用 OS 让每一次行动成为下一次的资产。

## 三次跃迁

1. 从能力到原力资产：找到源头，回到源头，训练源头，验证源头。
2. 从原力到会复利的生意：借势、独创、升维、锁定。
3. 从会赚钱到会进化：写成文脉，沉成大脑，画成地图，跑成链路。

## 生产纪律

- 每节课先完成概念授课卡，再生成讲稿、PPT 与练习。
- 一课一念，一念三幕，一课一果。
- 外部论文、数据和案例在进入讲稿前必须逐条核验。
- 高弧光中的作者经历必须由明哥确认。
- B4 只使用虚、实、入、出四大控制权口径。
- 桌面试跑不等于真实课堂验证。
