## 1. 为什么选择 A1、B1、C4

- A1 检验个体生命与认知主题。
- B1 检验历史、产业与商业判断主题。
- C4 检验组织执行与 OS 主题。

如果同一协议能覆盖这三类差异最大的课题，才有资格作为其余九模块的上游生产契约。

## 2. 逐课裁决

### A1

- 唯一概念：母体是持续生成差异的源头。
- 唯一判断：从“我会什么”退回“我为什么持续生成这些不同”。
- 唯一产物：带证据与反证的母体候选。
- 纵深轴：学术与认知 + 个体生命史。
- 结果：PASS。
- 风险：保留 `A1-unvalidated-by-live-readers`。

### B1

- 唯一概念：原力与结构窗口的四势匹配。
- 唯一判断：借势不是追热点。
- 唯一产物：可验证、可证伪的入场机会假设。
- 纵深轴：文明与技术 + 产业结构。
- 结果：PASS。
- 风险：康波、技术扩散与采用数据必须逐条核验，不得把长周期当精确择时公式。

### C4

- 唯一概念：Goal → Action → Evidence → Writeback → Mirror。
- 唯一判断：任务完成不等于系统完成。
- 唯一产物：可执行、可验收、可回写的行动链。
- 纵深轴：组织进化 + 企业生命周期。
- 结果：PASS。
- 风险：需用真实接手复现验证链路是否脱离创始人口头补充。

## 4. 桌面演练发现

1. 三幕可以跨三部复用，但纵深轴不能统一套康波。
2. “唯一产物”是控制课程膨胀的最强闸门。
3. 四证必须允许 `to_verify`，否则容易逼迫课程生产者编造权威感。
4. 高弧光应分为“价值命题”和“作者经历”，后者必须确认。
5. C4 能反向审计本轮任务：如果没有标准、模板、Schema、Skill、Resolver、试跑和回写，本轮课程仍只是一次性文档。
