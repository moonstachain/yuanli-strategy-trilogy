# Evolution Note · 课程全链路能力配置 v2

## 1. 本轮改变了什么

课程入口从“记住十几个 Skill 名称”收敛为 yuanli-content-engineering → capability-router.yaml。路由覆盖正典、洞察、研究、叙事、强落地、资产、试讲、转写、七天迁移、营销、小鹅通与回写 16 个阶段，并为每个阶段写明输入、输出、前置、回退、质量门、凭据和回写位置。

首轮产品仍是 8–12 位专家型创业者、明哥主讲、120 分钟付费诊断工作坊，唯一产物仍是《原力战略起点卡 v2》。A1、B1、C4 只做三面诊断镜，其余九课没有生成。

## 2. 哪些判断被证据改变

- 外部研究能支持“AI 对任务的暴露和增强不均匀”，不能直接证明 A/B/C 是普适三分法；后者继续保留为待两班真实课堂验证的课程假设。
- 学员语言为空时，最优动作不是写一个更像真的故事，而是建立 evidence_gap 和访谈问题。
- 课件、工作簿和营销草稿可以在真实课堂前完成；现场金句、时码、学习结果和营销证明不能提前完成。

## 3. 能力使用效果

- research-design-gate 有效阻止了“先搜再想研究什么”。
- yuanli-research-max 与 hv-deep-research 共同形成四证与反证边界。
- yuanli-narrative-four-beats 让心智隔离、小切口、大纵深、新植入和高弧光进入同一叙事脊柱。
- yuanli-narrative-course 把叙事落成一个工具、一次练习、一个产物、评分尺和七天任务。
- content-quality-gate 找到并修复一处结构性套话，同时保留 L4 作者声纹人工门。
- 文档、课件和表格资产均完成渲染复核；表格工具对中文跨表公式存在非阻断 sheetId 诊断噪声，必须继续保留在凭据中。
- DOCX 在缺少可用中文字体回退的无头办公套件中会出现缺字；本轮改用隔离且具备系统中文字体的渲染链复核，资产字节与哈希未变化。后续验收必须同时记录渲染器、字体条件和原始资产哈希。

## 4. 仍存在的能力债

1. yuanli-brain-surface 声明的 CLI helper 缺失，本轮由 Soul 仓内检索回退。
2. yuanli-narrative-course 与 yuanli-narrative-marketing 声明的 references 未随投影提供，本轮只使用 Skill 内嵌速用协议。
3. yuanli-course-video-factory 缺 scripts 和 workflow references，且没有真实授权录像，因此只验证了回退路由。
4. Governor validation_state 仍是 unknown，不可写成 passed_current。
