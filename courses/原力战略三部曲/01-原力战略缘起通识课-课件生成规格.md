# 原力战略缘起通识课 · 课件生成规格

## 0. 生成入口

课件生成使用现有私有仓：

```text
moonstachain/slides
```

该仓已经具备：

- PptxGenJS 可编辑课件生成；
- `pptxgenjs_helpers` 布局辅助；
- `.pptx` / `.pdf` 渲染为逐页 PNG；
- montage 总览图；
- 溢出、越界与字体替代检测；
- 最终交付 `.pptx + .js + 必要 assets`。

本课程不在 `slides` 仓另建内容真源。正确链路是：

```text
本课程母稿
→ 本课件生成规格
→ slides 能力生成 pptx
→ 渲染 / 校验 / 人审
→ 成品进入课程交付面
→ 学员反馈回写本目录与 soul
```

## 1. 课件总原则

### 1.1 不是目录型 PPT

课件不以“三部十二模块”平铺为主线，而采用：

```text
时代变化
→ 三次断裂
→ 原力战略缘起
→ 完整问题
→ 母公理
→ 三部必然推导
→ 个人诊断
```

### 1.2 一页只承担一个认知动作

每页只完成一种任务：

- 提出问题；
- 制造冲突；
- 给出命题；
- 展示结构；
- 讲述故事；
- 促成诊断；
- 完成收束。

禁止把正文母稿直接压缩成大段文字。

### 1.3 视觉基调

```text
高端战略舱
暗色底
暖金 / 玫瑰金强调
高对比留白
企业家第一眼
不是互联网发布会
不是普通商学院模板
不是炫技型科技蓝
```

建议：

- 主背景：近黑 / 深棕黑；
- 主强调：暖金；
- 次强调：低饱和玫瑰金；
- 正文：米白；
- 警示：暗红；
- 图形：圆环、飞轮、路径、三面墙、轴承，不堆装饰图标。

### 1.4 交付物

必须交付：

```text
origin-course-v0.1.pptx
origin-course-v0.1.js
rendered/*.png
origin-course-v0.1-montage.png
speaker-notes.md
```

必须运行：

- 渲染检查；
- montage 全局节奏检查；
- overlap / out-of-bounds 检查；
- 字体替代检查；
- 全部页面 16:9；
- 关键图形保持可编辑。

# 2. 36 页课件结构

## A. 点火：三问与时代错位（1–7）

### P01 · 封面

**标题：** 原力战略  
**副标题：** 把不可复制的自己，变成会自我生长的事业  
**视觉：** 一个微小光核向外生长为轨道 / 飞轮，三层结构隐约出现。  
**讲述作用：** 不是介绍方法，而是宣布主题。

### P02 · 今天不讲什么

```text
不讲如何多学一个工具
不讲如何复制一个成功者
不讲如何把自己逼得更努力
```

底部一句：

> 今天只回答：什么值得你用一生去放大？

### P03 · 开场第一问

全屏大字：

> 拿掉公司、职位、学历和职业名称，你是谁？

留白，不马上解释。

### P04 · 开场第二问

> 用户为什么必须选择你，而不是比较你？

视觉用“比较货架”与“新品类出口”的对比。

### P05 · 开场第三问

> 如果你离开事业三个月，它会继续学习、创造和增长吗？

视觉：创始人离开后，系统停摆 / 系统继续运转的左右对照。

### P06 · 三个问题，三种困境

```text
身份困境
市场困境
系统困境
```

三者不要直接标“三部曲”，先建立问题。

### P07 · 时代错位

标题：

> 你以为你在和同行竞争，其实你在和“平均能力”竞争。

视觉：过去稀缺能力被 AI 平台化的阶梯：写作、研究、设计、编程、方案。

---

## B. 三次断裂：为什么旧成功开始失效（8–15）

### P08 · 过去的个人优势

呈现：知识多、经验多、执行快、会表达、会总结、会工具。

结尾：

> 这些能力仍然重要，但正在从稀缺品变成基础设施。

### P09 · 真正危险的不是 AI 太强

中央命题：

> 真正危险的是，你不知道 AI 应该放大什么。

### P10 · AI 值不值得放大你？

左右对照：

```text
模糊的你 → 更多平均答案
清晰的你 → 独特判断被万倍放大
```

### P11 · 第一次断裂：能力与自己分离

以“做得好 / 能赚钱 / 被认可 / 持续耗电”四层落下。

### P12 · 卓越区与原力区

二维对照：

| 卓越区 | 原力区 |
|---|---|
| 做得好 | 像本能 |
| 外部认可 | 内在能量 |
| 可以替代 | 难以复制 |
| 做完耗电 | 做完生长 |

### P13 · 第二次断裂：做自己与做生意分离

中间一条鸿沟：

```text
真实、热爱、天赋
        ↓ 尚未完成翻译
用户、支付、品类、模式
```

### P14 · 第三次断裂：做成生意与拥有事业分离

标题：

> 创始人不是事业的拥有者，而是事业里最贵、最累、最不可替代的员工。

### P15 · 三种创业者群像

```text
成功但枯竭
独特但不赚钱
赚钱但离不开自己
```

首次在底部映射：资产 / 创业 / OS。

---

## C. 缘起：原力战略从哪里长出来（16–20）

### P16 · 不是书斋理论

标题：

> 原力战略先是一条走过的路，后来才成为一套理论。

### P17 · 明哥的生命路径

时间轴：

```text
计算机与技术
→ IBM 与企业战略
→ 上市公司与内部创业
→ 教育互联网与组织变革
→ 个人创业与企业家陪跑
→ AI 原生事业系统
```

每段只写“看见了什么问题”，不写履历荣耀清单。

### P18 · 同一套工具，为什么做出不同事业

中央问题：

> 为什么拥有同一套战略工具，不同创始人会做出完全不同的事业？

周围出现：经历、注意力、痴迷、品味、边界、长期承诺。

### P19 · 两套学问长期分离

左右两栏：

```text
个人成长：认识我，但不一定进入市场
商业战略：研究市场，但经常遗忘我
```

中央出现“原力战略”作为桥梁。

### P20 · 原力战略的完整问题

全屏命题：

> 如何把一个人最不可复制的部分，变成一个对世界有价值、对自己有能量，并且能够长期复利的事业？

---

## D. 母公理：从一次性劳动到自我繁殖（21–26）

### P21 · 三重成立

```text
人格一致
× 市场成立
× 系统复利
```

说明三个缺一不可。

### P22 · 唯一母公理

全屏：

> 做会自我繁殖的事，不做一次性的事。

### P23 · 什么叫一次性劳动

四个归零案例：文章、项目、咨询、AI 任务。

底部：

> 做完有结果，但没有下一代能力。

### P24 · 什么叫自我繁殖

四组箭头：

```text
文章 → 选题系统
咨询 → 诊断模型
项目 → 交付方法
工作流 → 下一代工作流
```

### P25 · 1·x 到 ʸx

四级阶梯：

```text
1·x  使用工具
x·y  调度工具
x^y  形成飞轮
ʸx   系统孵化系统
```

### P26 · 主语改变

标题：

> ʸx 的变化不只是效率，而是主语。

视觉：人推动系统 → 系统反馈 → 系统生产下一代能力。

---

## E. 三部必然推导（27–32）

### P27 · 为什么必然是三部曲

三面墙视觉：

```text
人：什么值得繁殖？
事：如何进入市场？
法：如何持续进化？
```

### P28 · 第一部：原力资产

标题：找到你。

核心问题：

> 拿掉职位、平台和评价，什么仍然属于你？

只出现：母体、原力、显化，不展开四模块目录。

### P29 · 第二部：原力创业

标题：变现你。

路径：

```text
个人原力 → 用户贵问题 → 新品类 → 模式 → 壁垒
```

### P30 · 财富 = 借势 × 合力

左右两极：

```text
合力：你真正独特的母体
借势：会放大你的时代和市场
```

底部强调：任何一项为零，乘积为零。

### P31 · 第三部：原力 OS

标题：系统你。

四器官：文脉、大脑、地图、链路。

### P32 · 完整传动系统

```text
找到你
→ 把你放进市场
→ 把结果沉淀成系统
```

底部：不是三个盒子，是一套传动系统。

---

## F. 飞轮、发心与个人诊断（33–36）

### P33 · 三部不是直线，是飞轮

飞轮图：

```text
原力资产
→ 原力创业
→ 原力 OS
→ 新证据回到资产
```

OS 画成轴承 / 涡轮，而不只是第三格。

### P34 · 原力战略的四层发心

```text
夺回人生主语
回到天才区
形成结构性利他
让一生的创造不被一次性消耗
```

### P35 · 我现在卡在哪一部

三问诊断：

1. 我能否不用职位和技能解释自己的不可复制性？
2. 我能否解释用户为什么非我不可？
3. 我不在场时，事业是否仍能学习和生长？

现场书写 3–5 分钟。

### P36 · 结尾

```text
原力资产，让你成为你；
原力创业，让世界需要你；
原力 OS，让价值超越你。
```

最终出现：

> 先找到值得繁殖的你，再把你放进时代与市场，最后让每一次创造都成为下一次创造的起点。

页脚：

> 做会自我繁殖的事，不做一次性的事。

# 3. 演讲节奏

| 区段 | 页码 | 建议时长 |
|---|---:|---:|
| 点火与时代错位 | 1–7 | 15 分钟 |
| 三次断裂 | 8–15 | 20 分钟 |
| 缘起与完整问题 | 16–20 | 15 分钟 |
| 母公理 | 21–26 | 15 分钟 |
| 三部推导 | 27–32 | 20 分钟 |
| 飞轮、发心、诊断 | 33–36 | 15 分钟 |
| 互动与机动 | 全程 | 10–20 分钟 |

90 分钟版：压缩案例与互动讨论。  
120 分钟版：加入明哥生命故事、1 个脱敏客户案例和同桌复述。

# 4. 讲者备注规则

每页备注至少包含：

```text
本页目的
开场句
核心论证
一个故事 / 例子
转场句
禁止扩展的旁枝
```

讲者备注不能只是把页面文字再读一遍。

# 5. 图片与案例边界

- 明哥个人故事优先使用真实照片与时间轴；
- 外部人物案例只作为旁证，不成为课程主线；
- 客户案例默认脱敏，除非获得公开授权；
- 不使用无关科技感图库；
- 尽量以结构图、现场照片、真实工作痕迹替代装饰插画。
