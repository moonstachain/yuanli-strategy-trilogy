# 原力战略三部曲 · 产品参数历史记录

> 本文件保留上一轮产品参数裁决的历史轨迹。
>
> 明哥在重新审视 GitHub 中原力创业真实课程、用户案例、内容矩阵与营销路径后，作出新裁决：**先按用户价值与证据链重构产品，再决定价格、周期、班型与交付形态。**
>
> 因此，本文件中的旧参数自本次重构起暂停执行，不应被用于课件、销售页、合同、招生、预算或对外传播。

---

## 一、上一轮曾批准的参数

以下内容仅作为历史记录：

| 项目 | 历史参数 |
|---|---|
| 缘起通识课角色 | 入门产品申请说明会 |
| 入门产品价格 | ¥12,980 / 人 |
| 入门产品周期 | 10 周 |
| 线下实战营 | 2 天 1 夜，1 次 |
| 私教班创始价 | ¥168,000 / 人 |
| 私教班标准价 | ¥198,000 / 人 |
| 私教班首期人数 | 20 人 |
| 私教班周期 | 6 个月 |

这些参数产生于上一轮“三层产品阶梯”假设：

```text
缘起通识课 / 申请说明会
→ 入门产品
→ 原力战略私教班
```

本轮研究发现，该结构过早合并了通识教育与销售转化，也在未验证用户价值、证据周期和交付产能前锁定了价格与周期。

---

## 二、为什么暂停执行

GitHub 历史材料显示，原力战略过去已经拥有：

- 三天原力创业线下课；
- 四模块通关手册；
- 真实学员案例；
- 十二类甜用户；
- 六十条内容矩阵；
- 公域、私域和高阶产品规划。

但这些资产尚未被统一到同一条：

```text
用户状态
→ 用户价值
→ 内容与课程
→ 产品介入
→ 证据成熟度
→ 下一阶段资格
```

的产品链上。

因此，在重新验证以下问题前，不应锁定参数：

1. 第一核心用户是否应是“十年专家型创始人”；
2. 通识课与转化公开课是否应分开；
3. 战略体检是否具有独立价值；
4. 原型形成与市场验证是否应拆分；
5. 真实市场证据需要多长时间；
6. 明哥、教练、PMO 与 AI 的真实产能；
7. 董事会真正适合多少个核心战略项目；
8. 各层用户实际支付意愿和问题价值。

## 四、当前可以继续使用的非参数判断

虽然旧参数暂停，但以下原则继续有效：

- 产品不能按“内容越来越多、价格越来越贵”设计；
- 高阶产品不能依赖无限增加明哥个人时间；
- 不以收入、融资或不可控结果作保证；
- 不使用虚假稀缺和焦虑营销；
- 每层产品必须独立交付真实价值；
- 高阶产品必须严格筛选真实项目和决策权；
- 所有交付必须产生证据并回写；
- 不适合用户应被明确拒绝，而不是强行转化。

## 五、重新启动参数裁决的条件

完成以下首轮证据后，重新召开参数人审：

```text
30 条内容测试
→ 3 场通识课
→ 2 场细分转化公开课
→ 20 份战略体检
→ 少量原型与市场验证项目
→ 少量董事会主战役试点
```

重新裁决时至少提交：

- 目标用户和非目标用户数据；
- 内容到课程、课程到诊断的有效转化；
- 用户价值和支付意愿；
- 各阶段证据产生时间；
- 导师、教练、PMO 和 AI 时间；
- 失败、证伪与主动退出案例；
- 真实市场和组织结果；
- 班型与交付质量的产能测算。

在此之前，任何价格与周期都只能作为内部测试假设，不能称为正式产品口径。
