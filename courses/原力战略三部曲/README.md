## 0. 本目录的作用

本目录承接《原力战略三部曲》的课程母稿、课件生成规格、产品地图、验证协议与交付设计。

它不修改三部十二模块正典；其职责是把正典与书稿转化为：

```text
能被用户理解的问题
→ 能产生实际价值的内容与课程
→ 能留下证据的产品
→ 能形成案例与系统资产的交付
→ 能回写并持续升级的下一轮能力
```

---

## 1. 当前最高优先级裁决

原力战略产品不再先按价格和课时排列，而按：

```text
用户状态
→ 用户价值
→ 内容与课程
→ 产品介入
→ 证据成熟度
→ 下一阶段资格
```

进行设计。

第一核心用户：

> **十年专家型创始人：本人已经很值钱，但价值尚未脱离本人。**

用户雇佣原力战略完成的总任务：

> **把最值钱、却最难说清、做大和传下去的东西，变成一门真正属于自己的事业。**

---

## 2. 当前全链路

```text
精准引流内容
→ 原力事业四断点测试
→ 原力战略通识课
→ 细分转化公开课
→ 原力事业战略体检
→ 原力事业原型工作坊
→ 原力创业市场验证
→ 原力战略董事会
→ 行业共创 / 战略合伙
```

这不是强制每人走完的线性漏斗，而是根据用户状态、问题价值和证据成熟度进入相应节点。

### 各层真正售卖的变化

| 层级 | 真正用户价值 | 核心证据 |
|---|---|---|
| 引流内容 | 准确认出自己的问题 | 用户原话、四断点测试 |
| 通识课 | 理解 AI 时代专家资产化的新问题 | 原力事业断点图 |
| 转化公开课 | 把通用认知翻译到自己的行业和业务 | 一页原力事业价值卡 |
| 战略体检 | 找到根因、优先级和首个验证动作 | 诊断报告与证据缺口 |
| 原型工作坊 | 形成可被证伪的事业主张 | 原力、甜用户、贵问题、产品原型、测试卡 |
| 市场验证 | 获得真实用户与付费证据 | 访谈、报价、订单、证伪、单位经济初证 |
| 战略董事会 | 推动一个主战役并沉淀组织系统 | 决策、项目结果、SOP、数据、OS 回写 |
| 行业共创 | 形成行业品类与基础设施 | 行业版本、标杆案例、系统部署、商业结果 |

## 5. 共同交付原则

所有内容、课程和产品必须满足：

```text
不是展示体系，而是解决用户当前问题；
不是听懂，而是产生资产；
不是完成作业，而是留下证据；
不是老师给答案，而是形成可被证伪的判断；
不是课程结束，而是结果回写后开始下一轮。
```

每一项产品至少定义：

1. 用户进入时的真实状态；
2. 输入材料；
3. 当层唯一任务；
4. 用户带走的价值；
5. 必须产生的证据；
6. 适合与不适合边界；
7. 进入下一层的资格门；
8. 内容、案例、方法和 OS 的回写位置。

## 6. 当前冻结项

首轮验证完成前，不锁定：

- 最终产品名称；
- 正式价格；
- 正式周期；
- 班级人数；
- 线上 / 线下比例；
- 通识课收费方式；
- 战略体检收费方式；
- 董事会席位结构；
- 行业共创合作结构。

参数必须由以下证据共同决定：

```text
用户问题价值
＋ 真实支付意愿
＋ 证据产生周期
＋ 导师与团队交付强度
＋ AI 和 PMO 杠杆率
＋ 首轮实际转化与结果
```

## 7. 当前执行顺序

```text
30 条精准内容测试
→ 3 场通识课
→ 2 场细分转化公开课
→ 20 份战略体检
→ 少量原型与市场验证项目
→ 少量董事会主战役试点
→ 正式裁决价格、周期、班型与产品名称
```

当前优先建设：

1. 《原力事业四断点测试》；
2. 五大内容栏目与首批 30 条选题；
3. 通识课的断点图；
4. 转化公开课的一页价值卡；
5. 战略体检模板与证据分级；
6. 首轮实验数据看板；
7. 案例授权与回写协议。

---

## 8. 版本原则

真实开课和项目后必须回写：

- 用户原始问题；
- 目标用户匹配度；
- 内容和课程产生的认知变化；
- 诊断与假设质量；
- 用户、付费、组织和系统证据；
- 被证伪的判断；
- 导师、教练、PMO 与 AI 的真实投入；
- 产品适配率与主动退出率；
- 案例是否允许对外使用；
- 哪些反馈只优化表达，哪些构成产品或正典候选。
