## 0. 本目录的作用

本目录承接《原力战略三部曲》的课程母稿、课件生成规格与产品交付设计。

它不是另一套正典，也不修改三部十二模块；其职责是把 soul 中的正典与书稿，转化为：

```text
能讲授的课程
→ 能实操的任务
→ 能带走的资产
→ 能验证的结果
→ 能回写的下一轮能力
```

## 4. 共同交付原则

所有课程必须满足：

```text
不是听懂，而是产生资产；
不是完成作业，而是改变判断；
不是老师给答案，而是形成自己的战略；
不是课程结束，而是结果回写后开始下一轮。
```

每一项任务至少定义：

1. 输入：学员带着什么真实材料进入；
2. 判断：使用什么标准做取舍；
3. 输出：离场带走什么可直接使用的资产；
4. 验收：如何判断不是漂亮作业；
5. 回写：结果进入文脉、大脑、地图或链路的哪里；
6. 下一步：如何进入下一模块或下一层产品。

## 7. 版本原则

本目录属于课程产品设计与执行真源，不自动改变 soul 正典。

真实开课后必须回写：

- 到课、申请与录取率；
- 各任务完成质量；
- 学员最强顿悟与最大阻塞；
- 真实产出样例；
- 入门产品到私教班的适配率；
- 课程承诺是否需要收缩或升级；
- 哪些反馈只是表达优化，哪些构成正典候选。
