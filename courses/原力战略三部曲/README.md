## 0. 本目录的作用

本目录承接《原力战略三部曲》的课程母稿、课件生成规格与产品交付设计。

它不是另一套正典，也不修改三部十二模块；其职责是把 soul 中的正典与书稿，转化为：

```text
能讲授的课程
→ 能实操的任务
→ 能带走的资产
→ 能验证的结果
→ 能回写的下一轮能力
```

## 2. 产品阶梯

```text
缘起通识课
点火、建立问题、完成三部诊断

↓

入门产品 · ¥12,980
线上实操课程 + 一次线下实战营
完成个人 / 事业的第一轮三部曲资产包

↓

利润产品 · 原力战略私教班
陪伴真实事业完成战略重构、关键决策与原力 OS 运行闭环
```

三层产品不重复售卖同一份知识：

| 层级 | 卖的不是 | 真正售卖的变化 |
|---|---|---|
| 通识课 | 十二模块介绍 | 从模糊焦虑到看见自己的战略断点 |
| 入门产品 | 录播课与一次活动 | 从“知道框架”到完成第一版三部曲资产 |
| 私教班 | 无限答疑和一对一陪聊 | 从第一版方案到真实事业的战略落地与递归升级 |

## 4. 共同交付原则

所有课程必须满足：

```text
不是听懂，而是产生资产；
不是完成作业，而是改变判断；
不是老师给答案，而是形成自己的战略；
不是课程结束，而是结果回写后开始下一轮。
```

每一项任务至少定义：

1. 输入：学员带着什么真实材料进入；
2. 判断：使用什么标准做取舍；
3. 输出：离场带走什么可直接使用的资产；
4. 验收：如何判断不是漂亮作业；
5. 回写：结果进入文脉、大脑、地图或链路的哪里；
6. 下一步：如何进入下一模块或下一层产品。

## 5. 当前人工裁决点

1. 入门产品线上周期最终采用 8 周还是 12 周；本稿建议 10 周；
2. 线下实战营采用 2 天 1 夜还是 3 天 2 夜；本稿建议 2 天 1 夜；
3. 私教班首发价与标准价；本稿建议创始班 ¥69,800，标准价 ¥98,000；
4. 私教班每期人数；本稿建议 12–18 人，不超过 20 人；
5. 是否将通识课作为公开课、低价课或入门产品报名说明会。

## 6. 版本原则

本目录当前属于产品设计稿，不自动进入正典。

真实开课后必须回写：

- 到课与完成率；
- 各任务完成质量；
- 学员最强顿悟与最大阻塞；
- 真实产出样例；
- 入门产品到私教班的适配率；
- 课程承诺是否需要收缩或升级。
