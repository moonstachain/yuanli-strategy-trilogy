# 原力战略 · 用户状态—内容—课程—产品—证据全链路地图

> 本文件是当前原力战略产品设计的最高优先级工作真源。
>
> 产品先按用户状态、用户价值和证据成熟度设计；价格、周期、班型在首轮证据形成后另行裁决。

---

## 一、产品设计的第一性原理

### 1. 产品是什么

产品不是课程、活动、社群和服务的集合。

产品是：

> 帮助一类特定用户，从一个可描述的当前状态，可靠地抵达一个更好的状态，并留下可验证证据。

原力战略核心用户的起点通常是：

```text
拥有十年以上积累
＋ 本人很值钱
＋ 用户认可本人
＋ 价值大量存在于隐性经验中
＋ 收入与交付高度依赖本人
＋ 无法把经验变成产品、品牌和系统
```

目标状态是：

```text
清楚自己最不可复制的部分
→ 找到最需要自己的甜用户与贵问题
→ 形成用户愿意付费的独创价值
→ 跑通获客、交付和利润的真实闭环
→ 把判断、经验和流程沉淀为可复利系统
```

### 2. 营销是什么

营销不是成交前的包装，也不是说服更多人付费。

营销是：

> 在成交之前，逐步交付足够的理解、诊断、案例和体验，让适合的用户获得行动确定性，让不适合的用户主动退出。

用户需要依次获得五种确定性：

```text
你在说我
→ 你解释清楚了根因
→ 你的方法有结构
→ 和我相似的人获得过真实结果
→ 下一步值得我投入行动
```

### 3. 产品升级的唯一正当理由

用户不是因为“下一层内容更多”而升级。

只有当用户完成当前层价值后，自然出现一个必须通过更深行动才能解决的新问题，才进入下一层。

因此每一层都必须同时完成：

1. **当层价值**：不购买下一层也获得真实帮助；
2. **证据产出**：留下可判断的材料或结果；
3. **下一阶问题暴露**：用户清楚看见下一步为什么需要更深投入；
4. **适配筛选**：不适合者被明确排除；
5. **系统回写**：结果成为案例、方法、内容或产品改进依据。

## 二、核心用户与核心任务

### 1. 第一核心用户

> **十年专家型创始人**

他可以是企业老板、专业服务者、教育者、设计师、高端消费主理人、制造业专家、咨询顾问、内容创业者或传统产业转型者。

共同特征不是行业或资产规模，而是：

```text
十年真积累
× 已有真实能力、客户或收入
× 客户认人不认系统
× 有隐知识没资产
× 赚钱高度依赖本人
× 正面临转型、产品化或 AI 重构
```

### 2. 用户雇佣原力战略完成的总任务

> **把我最值钱、却最难说清、做大和传下去的东西，变成一门真正属于我的事业。**

拆成五个连续任务：

```text
看清我究竟值钱在哪里
→ 找到最需要我的用户
→ 把价值变成用户愿意购买的产品
→ 跑通真实的获客、交付与利润闭环
→ 让事业逐渐摆脱对我本人的高度依赖
```

### 3. 前台语言与后台引擎

前台不要求用户先理解三部曲。

前台价值路径：

```text
看清你最值钱的部分
→ 找到最需要你的用户
→ 创造无法替代的产品
→ 跑通真实商业闭环
→ 建立持续复利的事业系统
```

后台方法引擎：

```text
原力资产
→ 原力创业
→ 原力 OS
```

原则：

> 用户从问题进入，在结果中理解三部曲。

## 三、一张总地图

| 阶段 | 用户当前状态 | 用户此刻真正的问题 | 主要内容 / 课程 / 产品 | 当层用户价值 | 必须产生的证据 | 进入下一层的门 | 主要营销任务 |
|---|---|---|---|---|---|---|---|
| U0 未识别 | 累、忙、焦虑，但把问题归因于流量、管理或环境 | “为什么我越能干，事业越离不开我？” | 精准引流内容 | 第一次准确认出自己 | 高质量评论、行业自述、四断点测试入口 | 愿意完成初诊 | **被看见**：让用户确认“你在说我” |
| U1 已共鸣 | 知道自己有问题，但没有完整解释 | “这是个人状态问题，还是事业结构问题？” | 原力战略通识课 | 建立 AI 时代专家资产化的新世界观 | 《原力事业断点图》 | 能说清自己的主要断点 | **被解释**：给出比用户原有认知更好的解释 |
| U2 已理解 | 接受原力战略，但仍不确定是否适合自己 | “我的具体业务卡在哪里？” | 细分转化公开课 | 把通用认知翻译到自己的行业和业务 | 《一页原力事业价值卡》 | 有真实业务、真实用户和明确问题 | **被证明**：案例与方法对号入座 |
| U3 已诊断 | 知道断点，但根因、优先级和可行性不清 | “我最该先解决哪一个战略问题？” | 原力事业战略体检 | 获得基于材料与事实的初步战略判断 | 诊断报告、证据缺口清单、首个验证建议 | 愿意提交材料并承担行动 | **被选择**：双向筛选，不追求全部成交 |
| U4 已选择 | 有方向，但尚未形成可测试方案 | “如何把十年隐知识变成可被市场验证的事业主张？” | 原力事业原型工作坊 / 战略集中营 | 完成事业原型和最小验证设计 | 原力定位、甜用户、贵问题、品类假设、产品原型、测试卡 | 完成真实用户访谈与验证准备 | **被体验**：让用户实际经历方法价值 |
| U5 已验证 | 已有方案，但市场是否买单仍不确定 | “这个主张能否形成真实订单和闭环？” | 原力创业市场验证计划 | 跑出真实用户反馈、付费或强购买承诺 | 访谈记录、报价反馈、成交、证伪、单位经济初证 | 有一个值得扩大或重构的真实项目 | **被证实**：结果代替承诺 |
| U6 已有闭环 | 能赚钱，但创始人仍是瓶颈 | “如何把个人能力变成组织和系统能力？” | 原力战略董事会 | 围绕一个主战役完成战略、组织和系统重构 | 决策日志、项目证据、SOP、数据、AI 工作流、OS 回写 | 已形成稳定结果或行业级机会 | **被信任**：长期结果与同级转介绍 |
| U7 可共创 | 已有业务基础、行业影响与组织能力 | “如何成为新品类标杆或行业基础设施？” | 行业共创 / 战略合伙 | 共同建设行业品类、系统和生态 | 行业版本、标杆案例、系统部署、商业收益、方法资产 | 年度人审，不做规模化售卖 | **被结盟**：从客户关系升级为长期共同体 |

## 四、五条纵向经线

总地图不是一条销售漏斗，而是五条同时向前推进的经线。

## 经线一：用户状态

```text
模糊疲惫
→ 认出问题
→ 理解根因
→ 完成诊断
→ 作出战略选择
→ 获得市场证据
→ 建立组织系统
→ 形成行业影响
```

用户状态必须先变化，产品层级才有意义。

## 经线二：用户价值

```text
共鸣价值
→ 解释价值
→ 诊断价值
→ 选择价值
→ 验证价值
→ 结果价值
→ 复利价值
```

越往后，价值不应表现为“内容更多”，而应表现为：

- 问题更重要；
- 判断更困难；
- 结果更接近现实；
- 需要协调的资源更多；
- 能产生的长期价值更大。

## 经线三：证据成熟度

```text
E0 感受
→ E1 自我识别
→ E2 结构化诊断
→ E3 战略假设
→ E4 用户证据
→ E5 付费证据
→ E6 组织执行证据
→ E7 系统复利证据
```

### 证据分级

| 证据级别 | 定义 | 典型产物 |
|---|---|---|
| E0 感受 | 用户觉得被击中，但尚未形成判断 | 评论、私信、口头共鸣 |
| E1 自我识别 | 用户能用自己的语言说明问题 | 四断点测试、行业自述 |
| E2 诊断 | 问题被结构化并确定优先级 | 一页价值卡、诊断报告 |
| E3 假设 | 形成可被证伪的战略方案 | 甜用户、贵问题、品类与产品假设 |
| E4 用户证据 | 真实用户对方案有明确反馈 | 访谈、点击、预约、报价反馈 |
| E5 付费证据 | 用户愿意付出金钱或高成本承诺 | 订单、定金、合同、复购 |
| E6 组织证据 | 团队可以重复完成关键动作 | SOP、角色、数据看板、交付质量 |
| E7 复利证据 | 一次结果持续产生下一次能力 | 案例库、AI 工作流、品牌、数据飞轮、壁垒 |

原则：

> 不能用低等级证据，冒充高等级结果。

例如：

- 点赞不能冒充购买意愿；
- 课堂兴奋不能冒充战略成立；
- 一句话定位不能冒充品类成立；
- 一次成交不能冒充商业模式成立；
- 创始人亲自完成不能冒充组织能力成立。

## 经线四：营销确定性

```text
被看见
→ 被解释
→ 被证明
→ 被体验
→ 被证实
→ 被信任
→ 被结盟
```

营销内容必须与用户所在阶段一致：

| 用户阶段 | 不该做什么 | 应该交付什么 |
|---|---|---|
| 未识别 | 直接讲完整方法论 | 用真实语言命中问题 |
| 已共鸣 | 马上报价 | 给出时代与结构解释 |
| 已理解 | 只讲创始人权威 | 展示同类案例和诊断方法 |
| 已诊断 | 制造焦虑 | 说明适配与不适配边界 |
| 已选择 | 承诺结果 | 提供真实体验和测试设计 |
| 已验证 | 继续堆内容 | 帮助推进组织和系统落地 |
| 已有结果 | 继续做客户管理 | 建立共同体、案例与生态关系 |

## 经线五：原力战略后台方法

| 用户任务 | 原力战略后台模块 |
|---|---|
| 看清最值钱的部分 | 原力资产：母体、能量、优势、痴迷、长期命题 |
| 找到最需要自己的用户 | 原力创业：甜用户、贵问题、心理账户 |
| 创造无法替代的产品 | 原力创业：品类独创、价值主张、模式升维 |
| 跑通真实商业闭环 | 原力创业：前链路、后链路、财链路、测试卡 |
| 建立可复利系统 | 壁垒锁定 + 原力 OS：文脉、大脑、地图、链路、回写 |

## 五、内容系统：内容不是流量池，而是用户问题雷达

## 1. 五个长期内容栏目

### A. 十年专家的人肉困境

作用：让用户认出自己。

主题：

- 客户只认你，不认公司；
- 离开六十天，业务会不会停；
- 越能干，越无法退出；
- AI 会不会让十年经验贬值；
- 为什么老板最后成了公司最贵的员工。

### B. 你最贵的那部分

作用：帮助用户从“技能”走向“原力资产”。

主题：

- 做完充电还是耗电；
- 哪些经验拿掉平台仍属于你；
- 同行能学方法，为什么学不会判断；
- 缺点、阴影与独特能力；
- 创始人的品味如何形成商业价值。

### C. 一人一品类

作用：教育市场理解“个人原力如何翻译成用户价值”。

主题：

- 教育不是卖课，而是某类家庭的未来生产力；
- 文创不是卖物件，而是精神与身份资产；
- 咨询不是卖 PPT，而是复杂问题的解释权；
- 高端制造不是卖材料，而是确定性与信任；
- 设计不是交付方案，而是重构用户人生场景。

### D. 真实事业重构案

作用：提供证据。

每个案例统一六段：

```text
原来是什么生意
→ 创始人真正的原力
→ 用户真正购买的任务
→ 新品类或新价值主张
→ 做了什么验证
→ 最终形成什么资产
```

必须同时保留失败、证伪和未解决问题。

### E. 原力事业工具箱

作用：帮助用户从观看进入行动。

首批工具：

- 原力事业四断点测试；
- 十年隐知识盘点表；
- 卓越区 / 天才区能量账本；
- 甜用户五问；
- 贵问题判断卡；
- 一句话价值主张卡；
- 创始人依赖度测试；
- 人肉生意 / 复利事业对照表。

## 2. 内容的统一行动入口

绝大多数公域内容只引导一个动作：

> 完成《原力事业四断点测试》。

四个断点：

```text
身份断点
用户价值断点
商业闭环断点
系统复利断点
```

不同结果进入不同内容和课程路径，而不是全部导向同一场销售活动。

## 六、课程系统：通识课与转化公开课必须分开

## 1. 原力战略通识课

### 唯一任务

> 创造新的问题解释和新品类认知。

它回答：

- AI 时代，为什么十年经验必须重新资产化；
- 为什么专家最大的风险不是没有能力，而是能力无法脱离本人；
- 为什么个人价值、用户价值和系统价值必须同时成立；
- 为什么需要“找到自己—进入市场—形成系统”的完整路径。

### 主要产物

《我的原力事业断点图》：

- 我最值钱的部分是什么；
- 价值目前卡在哪里；
- 下一步最应解决哪个问题。

### 课程边界

- 不直接诊断完整商业模式；
- 不把十二模块全部讲完；
- 不以当场成交为第一目标；
- 不承担高价产品申请说明会功能。

## 2. 细分转化公开课

### 唯一任务

> 把通用认知翻译到一类具体用户和具体业务，完成适配判断。

主课题建议：

> 《十年专家，如何把隐知识变成高价产品和可复制系统》

后续可以发展行业版本：

- 专业服务者版；
- 教育与知识服务版；
- 高端消费与审美主理人版；
- 制造业与技术专家版；
- 内容与直播创业者版。

### 主要产物

《一页原力事业价值卡》：

- 十年隐知识；
- 当前甜用户；
- 用户贵问题；
- 当前商业断点；
- 最小验证动作。

### 转化逻辑

公开课不是靠话术成交，而是通过：

```text
具体问题
＋ 同类案例
＋ 诊断框架
＋ 现场产物
＋ 清晰适配边界
```

让用户判断是否进入战略体检或下一阶段产品。

## 七、产品系统：按证据深度而不是内容量分层

## P1 原力事业战略体检

### 用户状态

已经知道自己有问题，但不知道根因和优先级。

### 核心价值

> 用真实材料判断：最值钱的资产是什么，用户价值断在哪里，当前最应验证什么。

### 输入

- 创始人经历与能力材料；
- 当前业务、产品和客户；
- 收入与交付结构；
- 代表案例；
- 当前主要困境。

### 输出

- 一页战略诊断；
- 证据成熟度分级；
- 最大断点；
- 不做清单；
- 首个最小验证建议；
- 产品适配建议。

### 证据门

愿意提交真实材料、接受反证，并拥有一个真实业务问题。

## P2 原力事业原型工作坊

### 用户状态

有真实积累和业务，但尚未形成可测试的事业主张。

### 核心价值

> 把十年隐知识变成一份可以被市场证伪的事业原型。

### 输出

- 一句话原力；
- 长期命题；
- 甜用户；
- 贵问题；
- 独创品类假设；
- 一句话价值主张；
- 产品原型；
- 市场测试卡。

### 成功标准

不是“方案漂亮”，而是形成清楚、具体、可执行、可证伪的假设。

## P3 原力创业市场验证计划

### 用户状态

已有事业原型，需要知道市场是否真正买单。

### 核心价值

> 在投入大资源之前，用真实用户和真实交易验证最关键假设。

### 必做证据

- 真实用户访谈；
- 内容或渠道测试；
- 报价与购买反馈；
- 至少一个被证伪的假设；
- 真实付费、定金或高成本承诺；
- 初步获客、交付、利润闭环。

### 成功标准

获得 E4—E5 级证据，而不是完成课程作业。

## P4 原力战略董事会

### 用户状态

已有真实闭环或高价值主战役，但创始人仍是瓶颈。

### 核心价值

> 围绕一个主战役，完成战略判断、组织推进、市场验证和系统回写。

### 主要产物

- 主战略问题；
- 决策与反证日志；
- 资源配置；
- 90 天主战役；
- 市场与组织证据；
- 文脉、大脑、地图和链路回写；
- 可教学案例。

### 成功标准

不仅项目产生结果，而且结果进入组织和系统，下一次不再从零开始。

## P5 行业共创 / 战略合伙

### 用户状态

拥有行业基础、组织资源和成为新品类标杆的可能性。

### 核心价值

> 共同建设行业品类、商业系统、AI 基础设施和长期生态。

### 主要产物

- 行业品类定义；
- 行业版方法与产品；
- AI 系统或原力 OS 部署；
- 标杆案例；
- 商业结果；
- 联合品牌或长期权益。

### 边界

每年只选择极少数项目，不作为规模化课程销售。

## 八、三条用户路径

## 路径 A：品牌教育路径

适合尚未准确意识到问题的人。

```text
精准内容
→ 四断点测试
→ 原力战略通识课
→ 细分转化公开课
→ 战略体检
→ 原型工作坊 / 市场验证
```

## 路径 B：问题解决路径

适合已经有明确痛苦和真实业务的人。

```text
行业痛点内容
→ 细分转化公开课
→ 一页价值卡
→ 战略体检
→ 原型工作坊 / 市场验证
```

## 路径 C：存量客户升级路径

适合已经跑出市场证据的人。

```text
市场验证结果
→ 主战役申请
→ 原力战略董事会
→ 行业共创
```

通识课不是所有用户必须通过的销售步骤。

## 九、用户价值指标与营销指标必须成对

| 层级 | 用户价值指标 | 营销 / 产品指标 |
|---|---|---|
| 引流内容 | 是否准确认出自己的问题 | 高质量评论率、四断点测试进入率、目标行业占比 |
| 通识课 | 是否理解新问题框架 | 完课率、断点图完成率、课程复述率 |
| 转化公开课 | 是否形成一页个人诊断 | 合格诊断率、真实项目率、适配申请率 |
| 战略体检 | 是否找到根因与第一优先级 | 证据完整度、拒绝率、建议采纳率 |
| 原型工作坊 | 是否形成可证伪事业原型 | 假设清晰度、访谈启动率、测试卡完成率 |
| 市场验证 | 是否产生 E4—E5 证据 | 用户访谈质量、报价率、付费证据、证伪率 |
| 战略董事会 | 是否完成主战役并形成系统资产 | 主战役进度、组织执行、OS 回写、案例形成率 |
| 行业共创 | 是否形成行业级成果 | 商业收益、系统部署、标杆影响、方法资产 |

北极星指标：

> 每进入下一层的用户，是否比上一层拥有更强的确定性、更真实的证据和更大的行动能力。

## 十、内容—交付—营销的复利飞轮

```text
真实用户问题
→ 精准内容
→ 诊断数据
→ 战略假设
→ 市场验证
→ 项目结果
→ 脱敏案例
→ 判断规则与工具
→ 更精准的内容与产品
```

营销与交付不是两个部门。

> 高质量交付产生的真实证据，是下一轮最强的营销。

所有案例回写必须区分：

1. 用户原话；
2. 事实与数据；
3. 原始假设；
4. 实际行动；
5. 验证结果；
6. 被证伪部分；
7. 方法论候选；
8. 是否允许对外使用。

## 十一、当前冻结项

在完成首轮验证前，以下项目不作为正式裁决：

- 各产品最终名称；
- 各产品价格；
- 各产品周期；
- 线上与线下比例；
- 班级人数；
- 通识课是否收费；
- 战略体检是否独立收费；
- 董事会席位与共修席位结构；
- 行业共创的收费、分成或股权方式。

这些参数必须根据：

```text
用户价值
＋ 证据产生所需时间
＋ 交付强度
＋ 导师与团队产能
＋ 用户可承担风险
＋ 首轮真实转化和交付数据
```

再进行裁决。

## 十三、最终裁决

原力战略不是一条：

```text
免费内容
→ 低价课
→ 高价课
→ 更高价咨询
```

而是一条：

```text
内容帮助用户看见自己
→ 通识课帮助用户理解时代与根因
→ 公开课帮助用户完成具体诊断
→ 产品帮助用户作出战略选择
→ 验证帮助用户获得市场证据
→ 董事会帮助组织产生真实结果
→ 系统回写让结果成为下一次能力
```

营销也不是：

```text
吸引流量
→ 制造焦虑
→ 说服成交
```

而是：

```text
交付理解
→ 交付诊断
→ 交付案例
→ 交付体验
→ 交付证据
→ 交付结果
```

最终增长飞轮是：

> 用户价值产生证据，证据产生信任，信任带来更合适的用户，更合适的用户产生更高质量的价值。
