# 三分钟原力通识 v1

> 用人类经典学科与高价值思维模型，照亮原力战略；用三分钟内容，帮助专家型创业者完成一次可行动的认知迁移。

## 一、项目身份

本目录是课程与内容实例，不是 Soul 正典。

```text
Soul 定法
→ Trilogy 做课
→ Content Engine 组织发布与测量
→ 真实用户反馈
→ Evolution Note
→ Soul 人工裁决
```

本栏目不新增第四部，不新增第十三模块，也不以外部学科替换原力战略三部十二模块。

## 二、栏目总命题

原力战略可以被理解为一套事业生命体的演化工程：

```text
原力资产：生成差异
→ 原力创业：接受选择并建构生态位
→ 原力 OS：保存有效结构并提高下一轮可进化性
```

记忆钩子：

> 让一个人的生命差异，经过世界选择、商业放大、制度保护和系统继承，成长为会自我进化的事业生命体。

## 五、单期叙事协议

每一期统一采用：

> 一幅画、一个悖论、一条规律、一次照见、一句拷问。

每期最小产物：

1. 唯一概念与唯一创业困境；
2. 180秒脚本；
3. 学科原义、证据与解释边界；
4. 一张主机制图；
5. 一张学员判断卡；
6. 试讲或发布记录；
7. Evolution Note。

统一遵守：

> 一课一念，一念三幕，一课一果。
