# 学科优先级与边界 v1

## 一、筛选原则

学科不是越多越好。一个学科或模型进入栏目，必须同时满足：

1. **解释力：** 能解释一个反复出现的专家创业困境；
2. **区分力：** 能帮助学员排除至少一种常见误解；
3. **映射力：** 能明确映射到 A1—C4，而不是泛泛而谈；
4. **行动力：** 能生成一个最小判断、实验或输出物；
5. **证据力：** 原义和关键事实可以追溯；
6. **边界力：** 能说明何时不适用、不能推出什么。

## 二、优先级

### P0｜第一季必须进入

| 学科域 | 关键模型 | 首要原力价值 |
|---|---|---|
| 演化生物学与生态学 | 变异、选择、遗传、生态位建构、稳健性 | 解释事业生命体与三部曲递归 |
| 概率与决策科学 | 基准率、贝叶斯更新、安全边际、机会成本 | 把母体和机会从身份宣言变成可验证假设 |
| 心理与行为科学 | 激励、损失厌恶、框架、有限理性 | 解释用户账户、行动摩擦与决策偏差 |
| 系统科学与控制论 | 反馈回路、瓶颈、延迟、稳态 | 解释三链、控制权和递归回写 |
| 微观经济学 | 激励、交易成本、单位经济、委托代理 | 解释价值交换、组织与利润容器 |

### P1｜第二阶段扩展

| 学科域 | 关键模型 | 首要原力价值 |
|---|---|---|
| 信息论与知识工程 | 信号噪声、编码、压缩、版本 | 解释文脉、大脑与知识遗传 |
| 组织与制度科学 | 权责、制度、惯例、治理 | 解释创始人判断如何成为组织能力 |
| 会计金融与资本配置 | 现金流、回报率、资本配置、复利 | 解释财链、风险与长期增长 |

### P2｜按选题调用

- 社会学与网络科学；
- 人类学与文化演化；
- 伦理学、美学与文明史；
- 博弈论、复杂性科学和创新扩散；
- 脑科学中的注意、预测、价值与学习机制。

## 三、四类禁止跃迁

### 1. 隐喻跃迁

“企业像生命体”不等于企业具备生物学意义上的基因、繁殖和自然选择。

### 2. 层级跃迁

个体心理机制不能未经证明直接推导组织和市场结果。

### 3. 规范跃迁

“自然界存在竞争”不能推出商业上应该弱肉强食；描述事实不等于价值正当。

### 4. 权威跃迁

名人说过、畅销书采用或大公司实践，不等于模型对本案例成立。

## 四、证据标签

```yaml
source_status: primary | secondary | practitioner | analogy
verification_status: verified | partially_verified | to_verify | disputed
claim_type: fact | model | inference | yuanli_translation
```

任何 `inference` 和 `yuanli_translation` 必须与学科原义分开书写。

## 五、淘汰条件

出现以下任一情况，模型不得进入正式脚本：

- 只能制造高级感，不能改变判断；
- 无法在三分钟内分清原义与映射；
- 需要大量例外才能解释案例；
- 与现有模型高度重复，不能增加区分力；
- 外部事实无法核验；
- 容易诱发宿命论、社会达尔文主义或科学主义误解。
