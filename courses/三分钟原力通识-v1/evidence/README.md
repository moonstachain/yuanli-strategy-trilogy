# 证据账本说明

本目录保存每一期的外部事实、学科定义、来源状态、冲突处理与核验结论。

## 最小字段


## 证据纪律

- 学科原义与原力转译分栏记录；
- 不以课程母稿中的外部链接直接视为已核验；
- 不用单一案例证明普遍规律；
- 出现来源冲突时保留冲突，不做静默调和；
- 事实未核验，不进入正式发布稿；
- 真实用户语言、评论与 Outcome 作为实践证据，不替代学术证据。
