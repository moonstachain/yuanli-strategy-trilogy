# D03 · 演化生物学与生态学 Domain Pack v1

## 1. 进入目的

本 Domain Pack 用于解释原力战略中的：

- 差异如何生成；
- 差异如何接受环境选择；
- 有效结构如何被保存；
- 事业如何建构生态位；
- 系统如何兼顾稳健性与可进化性。

它不是用生物学替代商业与组织科学，也不把创业者、企业、用户直接等同于基因、物种或自然选择。

## 2. 核心模型

| 模型 | 原义焦点 | 原力转译 | 主要模块 |
|---|---|---|---|
| 变异 | 个体或表型存在差异 | 母体持续产生不同判断、作品与能力 | A1—A3 |
| 选择 | 差异在特定环境中产生不同结果 | 用户靠近、付款、行动和 Outcome | A4、B1 |
| 遗传/保留 | 有效差异跨代保留 | 案例、数据、规则和链路进入下一次 | C1—C4 |
| 适应 | 性状与环境形成关系 | 原力与时代、用户、入口相匹配 | B1 |
| 生态位建构 | 生命体也改变自身环境 | 品类重新定义问题、语言与选择标准 | B2 |
| 代谢 | 获取并转换资源以维持生命 | 前链、后链、财链形成利润容器 | B3 |
| 稳健性 | 扰动下保持关键功能 | 虚、实、入、出四种控制权 | B4 |
| 可进化性 | 产生具有适应价值的新变异 | OS 保存核心，同时治理新变异 | C1—C4 |
| 共生与协同进化 | 多主体在互动中共同改变 | 用户、团队、AI 与生态共同进化 | B4、C4 |

## 3. 必须保留的科学边界

1. 演化没有预设目标；战略具有目的和人为设计。
2. 自然选择是描述机制，不提供商业伦理正当性。
3. 原力母体是战略构念，不是生物基因。
4. 企业中的“遗传”是信息、规则和能力保留，不是生物遗传。
5. 市场反馈受制度、权力、叙事和资源影响，不是纯粹自然环境。
6. “适者”不是最强者，而是特定环境下相对适配者。

## 5. 本域最高产物

不是“原力战略被达尔文证明”，而是：

> 学员能够把自己的事业看成一个需要生成差异、接受选择、保存经验和持续变异的生命系统，并据此改变一个真实行动。
