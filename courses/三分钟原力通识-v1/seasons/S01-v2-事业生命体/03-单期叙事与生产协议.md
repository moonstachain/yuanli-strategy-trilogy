# S01 v2 · 单期叙事与生产协议

## 一、单期不是“介绍一个模型”

每一期必须完成一次认知迁移：

```text
一个真实困境
→ 一个旧解释
→ 一个学科悖论
→ 一条核心机制
→ 一次原力照见
→ 一个可见产物
```

禁止结构：

```text
人物生平
→ 学术名词
→ 若干知识点
→ 原力战略也很像
→ 金句结束
```

## 二、原力五幕

每一期统一使用：

> 一幅画、一个悖论、一条规律、一次照见、一句拷问。

### 1. 一幅画

作用：让没有学科背景的观众进入问题。

要求：

- 画面应能在3秒内识别；
- 不依赖复杂术语；
- 与本期核心机制存在结构关系；
- 不能只作为装饰。

例：

- E01：忒修斯之船 / 火种；
- E06：账本；
- E07：血液循环；
- E11：星图；
- E12：螺旋。

### 2. 一个悖论

作用：击穿学员原有解释。

要求：

- 必须与目标学员的真实经验冲突；
- 不能只是语言反转；
- 必须能由后面的机制解释。

句式：

> 你以为______，但真正决定______的可能是______。

### 3. 一条规律

作用：忠实呈现该学科最值得调用的一条机制。

要求：

- 一期只保留一个主机制；
- 可以有一个辅助模型，但不得并列堆叠；
- 必须说明适用范围；
- 事实、模型、推论与原力转译必须分开。

### 4. 一次照见

作用：让观众看见该机制具体照亮A1—C4中的哪个结构。

要求：

```yaml
primary_module: A1 | A2 | A3 | A4 | B1 | B2 | B3 | B4 | C1 | C2 | C3 | C4
external_model_role: explanatory_lens | diagnostic_lens | design_lens
canon_authority: none
```

禁止：

- “某学科已经证明原力战略”；
- 用相似隐喻直接推出商业因果；
- 用一个学科解释整个三部曲；
- 修改上游正典定义。

### 5. 一句拷问

作用：让观众无法只停留在理解和赞同。

要求：

- 必须指向观众自己的事业；
- 必须能够写下答案；
- 最好包含取舍、反证或结果；
- 不使用空泛励志句。

## 三、180秒时间合同

| 时间 | 任务 | 必须产生的结果 |
|---:|---|---|
| 0—15秒 | 一幅画＋真实症状 | “这讲的是我” |
| 15—40秒 | 一个悖论 | 旧解释被击穿 |
| 40—85秒 | 学科原义与核心机制 | 分清模型究竟说什么 |
| 85—130秒 | 原力照见 | 理解它照亮哪个模块 |
| 130—155秒 | 边界与反例 | 知道不能推出什么 |
| 155—180秒 | 一句拷问＋最小产物 | 形成一个可见判断或动作 |

时长允许在150—210秒之间试讲，但正式栏目仍以180秒为目标中位数。

## 五、每期最小七件套

```text
01-lesson-card.md
02-script-180s.md
03-evidence-ledger.md
04-visual-mechanism.md
05-learner-card.md
06-trial-record.md
07-evolution-note.md
```

### 1. Lesson Card

冻结：唯一概念、旧判断、新判断、边界、产物与下一接口。

### 2. Script 180s

只负责口播与节奏，不承担全部证据细节。

### 3. Evidence Ledger

至少区分：

```yaml
claim_type: fact | model | inference | yuanli_translation
source_level: primary | secondary | practitioner | analogy
verification_status: verified | partially_verified | to_verify | disputed
```

### 4. Visual Mechanism

最多一张主机制图，不用“满屏知识地图”替代解释。

### 5. Learner Card

三分钟结束后，观众能够留下一个可见产物。

### 6. Trial Record

记录：时长、复述、误解、产物完成率、边界误用和追问。

### 7. Evolution Note

记录真实结果如何修改：标题、脚本、机制图、判断卡、Domain Pack或课程协议。

## 六、证据与边界门

每期发布前必须回答：

1. 学科原义是否来自可追溯来源？
2. 本期讲的是事实、模型还是推论？
3. 原力映射是否被明确标记为转译？
4. 是否存在一个反例或适用边界？
5. 是否把描述性规律误写成价值正当性？
6. 是否把个体层机制直接跃迁到组织或市场层？
7. 是否用名人、畅销书或名校代替证据？
8. 是否出现“证明原力战略”的不当表述？

任一不通过，不进入正式发布稿。

## 七、标题协议

标题必须同时包含：

```text
一个熟悉困境
＋ 一个反常识判断
```

优先句式：

- 为什么______，反而______？
- 真正的______，不是______，而是______。
- 当______被拿走，你还剩下什么？
- 你以为______，可能只是______。

不优先：

- “三分钟讲懂XX学”；
- “XX理论的五个知识点”；
- “大师告诉你的创业秘密”；
- 纯学术名词标题。

## 八、发布后观察协议

### 24小时：是否被击中

- 是否出现“这说的就是我”；
- 哪个画面或悖论被复述；
- 是否出现明显误读。

### 72小时：是否被理解

- 用户能否用自己的语言复述唯一规律；
- 是否能说清“它不是什么”；
- 是否完成判断卡。

### 7天：是否改变行动

- 是否做出停止、验证、训练、设计或回写动作；
- 是否出现真实结果；
- 是否出现反例；
- 本期规则是否被下一期或下一任务读取。

## 九、最高验收

单期通过不是播放量高，而是：

> 一个观众因为这一期，改变了一次真实判断；这次判断产生了可观察行动；行动结果又改变了下一次判断。
