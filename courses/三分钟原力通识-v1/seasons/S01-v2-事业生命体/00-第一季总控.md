## 一、第一季唯一母问题

> 一个人的生命差异，怎样变成被世界选择、被系统继承、并能继续进化的事业生命体？

这不是十二门学科的知识拼盘，而是同一个事业生命体的十二次发育。

```text
生命差异
→ 原力资产

被世界选择
→ 原力创业

被系统继承
→ 原力 OS
```

## 二、第一季定位

### 对外承诺

> 用十二门人类基础学问，讲清一个人如何从“我是谁”，走到“世界为什么需要我”，再走到“我不在场时，什么仍会继续”。

### 对内课程合同

第一季只完成一件事：

> 让目标学员第一次获得一张完整的“事业生命体发育图”，理解三部十二模块不是十二个并列知识点，而是一条从生命生成、世界选择到时间遗传的连续链路。

### 不做什么

- 不把外部学科当成原力战略的科学证明；
- 不新增第四部或第十三模块；
- 不把十二期做成十二个独立工具技巧；
- 不在三分钟里讲完一门学科；
- 不以名人、学术术语或宏大叙事制造权威感；
- 不因课程表达优美而自动升级 Soul 正典。

## 三、三幕结构

| 幕 | 核心问题 | 对应正典 | 学员跃迁 |
|---|---|---|---|
| 第一幕 · 生命生成 | 我为什么持续产生这一类差异？ | A1—A4 原力资产 | 从外部标签退回生命生成源 |
| 第二幕 · 世界选择 | 为什么这个时代和这些用户会选择这种差异？ | B1—B4 原力创业 | 从“我有价值”走到“世界愿意改变选择” |
| 第三幕 · 时间遗传 | 当创始人不在场，什么仍能被保存、调用和更新？ | C1—C4 原力 OS | 从个人成功走到事业可继承、可进化 |

### 第一幕 · 生命生成

```text
A1 发现母体
→ A2 回到母体
→ A3 获得原力
→ A4 显化原力
```

记忆句：

> 找到源头，离开伪我，训练生成器，接受现实检验。

### 第二幕 · 世界选择

```text
B1 原力借势
→ B2 品类独创
→ B3 模式升维
→ B4 壁垒锁定
```

记忆句：

> 找到窗口，打开账户，建立代谢，沉淀控制权。

### 第三幕 · 时间遗传

```text
C1 一纸文脉
→ C2 一个大脑
→ C3 一张地图
→ C4 一条链路
```

记忆句：

> 保住身份，保存记忆，看见结构，形成递归。

## 四、第一季首尾闭环

### E01 的问题

> 当平台、职业、工具、头衔和外部评价都被拿走，什么仍会从你身上重新长出来？

### E12 的问题

> 当你本人不在场，什么仍会继续判断、行动、学习和进化？

首尾共同完成：

```text
从“什么不会被拿走”
→ 到“什么不再依赖你亲自守住”
```

这就是第一季真正的发育弧：

> 从一个人，到一门事业，再到一个可以穿越时间的事业文明。

## 五、第一季唯一总产物

# 《我的事业生命体发育图 v1》

必须包含十二个位置：

1. 我的生成源候选；
2. 我需要退出的伪适应；
3. 我正在训练的稳定生成能力；
4. 世界对它的第一条真实选择证据；
5. 正在放大它的结构窗口；
6. 用户被重新打开的心理账户；
7. 前链、后链、财链中的代谢闭环；
8. 虚、实、入、出四种控制权；
9. 不在场时仍有效的身份与边界；
10. 可检索、可验证、可调用的记忆；
11. 当前决定命运的结构与瓶颈；
12. 让本次结果进入下一次行动的回写链路。

最终只选择一个30天发育实验：

```text
我当前停在哪一次发育：
我最危险的旧解释：
未来30天唯一动作：
可观察结果：
反证条件：
结果写回位置：
```

## 六、每一期的固定身份

每一期同时具备五层身份，但不能混写：

| 层级 | 回答什么 |
|---|---|
| 学科原义 | 这门学问中的核心问题和机制是什么 |
| 文明意象 | 用什么画面让小白进入这门学问 |
| 创业悖论 | 哪个反常识击穿旧判断 |
| 原力照见 | 它照亮 A1—C4 的哪个机制 |
| 行动拷问 | 学员今天必须面对什么真实问题 |

外部模型的权限固定为：

```yaml
role: explanatory_lens | diagnostic_lens | design_lens
canon_authority: none
```

## 七、第一季通过标准

第一季不是以“十二期全部发布”为通过，而是同时满足：

1. 十二期各自只有一个认知迁移；
2. 三幕之间存在明确输入输出接口；
3. E01 与 E12 构成首尾闭环；
4. 至少八期学员能准确复述“它不是什么”；
5. 至少六期产生可见判断卡或行动记录；
6. 至少两次出现“前一期规则被后一期明确加载”；
7. 至少一次真实行动结果进入 Evolution Note；
8. 未完成外部证据核验的事实保持 `to_verify`；
9. 未经第二次真实加载，不标记 `reusable`；
10. 任何结果都不能自动修改 Soul 正典。
