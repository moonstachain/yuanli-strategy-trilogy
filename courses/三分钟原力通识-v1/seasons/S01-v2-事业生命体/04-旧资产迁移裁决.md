# S01 v2 · 旧资产迁移裁决

## 一、裁决目标

现有 `seasons/S01-创业判断格栅/` 已形成真实课程资产，不删除、不静默改写，也不继续作为第一季主动龙骨。

本次裁决将其身份调整为：

```yaml
legacy_path: seasons/S01-创业判断格栅
legacy_status: superseded_as_active_s01_plan
retention_reason: preserve_history_and_reusable_assets
proposed_future_role: S02-创业者的十二个昂贵误判
canon_effect: none
```

## 二、为什么迁移而不是废弃

旧规划解决的是：

> 创业者如何借助经典模型，减少高频而昂贵的判断错误。

新第一季解决的是：

> 一个人的生命差异，如何被发现、训练、世界选择、商业放大并由系统继承。

两者都成立，但承担不同的教学次序：

```text
第一季：先建立原力战略独有的世界观与三部十二模块总结构
第二季：再训练创业者在真实决策中避免昂贵误判
```

## 三、现有资产逐项裁决

### 1. 原 E01《达尔文：事业如何成为会进化的生命体》

迁移为：

```yaml
new_target: S01-v2 E05
new_title: 决定命运的，不是强大，而是被时代需要
role_change: trilogy_overview -> B1_environment_selection
```

保留价值：

- 生成—选择—保留的演化链；
- 事业生命体的核心隐喻；
- 生物演化与商业战略的边界；
- 既有证据核验计划。

需要修改：

- 不再承担第一季总论；
- 重点收缩到“环境选择与原力借势”；
- “保留”部分只作为连接原力 OS 的尾钩，不在本期讲透。

### 2. 原 E02《一势两账三链四权》

迁移为：

```yaml
new_target: season_prologue_E00
new_role: B-axis navigation and diagnostic trailer
count_in_twelve_episodes: false
```

保留价值：

- 对B1—B4的前台压缩；
- 原力创业四关诊断卡；
- 一势、两账、三链、四权记忆结构；
- 四权边界与B4治理纪律。

不再承担：

- 第一季十二期中的一席；
- 对三部曲整体世界观的起点解释。

建议使用位置：

- 第一季发布前的栏目先导片；
- E05—E08第二幕的导航片；
- 原力创业长课的B0总览。

### 3. 原 E03—E12 判断模型

整体迁移为第二季候选：

# 《创业者的十二个昂贵误判》

现有映射：

| 旧期数 | 旧主题 | 第二季建议身份 |
|---:|---|---|
| E03 | 逆向思考 | 致命错误：只设计成功，不设计停止 |
| E04 | 基准率 | 经验错误：把一次成功当作普遍规律 |
| E05 | 激励效应 | 组织错误：口号正确，奖励错误 |
| E06 | 机会成本 | 战略错误：用忙碌回避真正押注 |
| E07 | 生态位建构 | 品类错误：把新品类做成新名字 |
| E08 | 瓶颈效应 | 优化错误：所有地方一起用力 |
| E09 | 反馈回路 | 增长错误：把透支循环当作增长飞轮 |
| E10 | 信号与噪声 | 证据错误：把赞美、流量和偶然成交当需求 |
| E11 | 委托代理 | 授权错误：把走样简单归因于人不行 |
| E12 | 安全边际 | 生存错误：在验证前耗尽继续游戏的资格 |

第二季仍缺两个模型，可在真实第一季运行后再裁决，不在本次扩展范围内强行补齐。

## 四、目录治理

### 当前保留

```text
seasons/
├── S01-创业判断格栅/          # 历史资产与第二季迁移源
└── S01-v2-事业生命体/        # 新第一季主动龙骨
```

### 合并本PR后建议状态

```yaml
active_season_backbone: S01-v2-事业生命体
legacy_season_backbone: S01-创业判断格栅
legacy_write_policy: maintenance_only
new_episode_development_path: S01-v2-事业生命体
```

### 不立即重命名旧目录的原因

- 保留Git历史和已有外部引用；
- 避免以文件移动制造大面积无意义diff；
- 第二季尚未补齐十二期，不应提前伪装为已冻结；
- 等第一季样片与真实试讲通过后，再独立PR完成目录正式迁移。

## 五、现有Domain Pack裁决

`domain-packs/D03-演化生物学与生态学/`继续保留为跨季度学科资产，不归属于单一一期。

新第一季后续应按需补充：

```text
D01-哲学与科学哲学
D02-深度心理与认知科学
D04-行为经济学与微观经济学
D05-制度科学与人类学
D06-信息论与知识工程
D07-复杂性科学与控制论
```

但Domain Pack必须按一期真实生产需要逐个建立，不一次性空建全部目录。

## 六、迁移完成条件

旧资产只有同时满足以下条件，才可正式改名为第二季：

1. 新S01的E01样片通过真人试讲；
2. 新S01三幕结构获得作者确认；
3. 原E01到新E05的内容迁移完成；
4. 原E02被稳定用作E00或B幕导航；
5. 第二季补齐两个不重复、可行动的核心误判；
6. Content Engine建立新的season_id；
7. 所有旧链接和Campaign引用完成迁移清单；
8. 独立PR执行目录重命名，不在本PR中混做。

## 七、本次最终裁决

> 不删除旧成果，不让旧成果绑架新结构；把旧第一季从“主世界观”降为“判断训练资产”，把新第一季提升为原力战略独有的事业生命体发育叙事。
