# S01 · 创业判断格栅

## 第一季目标

帮助专家型创业者建立十二个最小判断透镜，并将其装配为一张可以反复调用的创业格栅。

第一季不追求学科完备，只优先解决高频、昂贵、可行动的创业误判。

## 两条主线

### 认知主线

```text
识别差异
→ 判断环境
→ 做出取舍
→ 跑通价值与结果
→ 避免系统性死亡
→ 保存学习
```

### 课程主线

```text
被击中
→ 看懂模型
→ 映射自己的事业
→ 找到一个误判
→ 做一个最小实验
→ 回写结果
```

## 每期唯一产物

每一期只要求学员留下一张最小判断卡，例如：

- E01：《我的事业演化闭环》；
- E02：《原力创业四关诊断卡》；
- E04：《基准率与反证卡》；
- E08：《当前唯一瓶颈卡》；
- E12：《事业灭绝风险清单》。

## 第一季发布闸门

- E01、E02 先完成桌面试讲；
- 外部事实核验后才能进入正式脚本；
- 每期发布后记录 24h、72h、7d；
- 重点记录用户复述、误解、案例、问题与行动，而不只看播放量；
- 至少两期出现“上一期规则被下一期明确加载”，第一季才可标记为 `compounding_trial_started`。
