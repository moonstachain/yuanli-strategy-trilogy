## 1. 学员症状

你做过很多项目，也积累了很多经验，但每次开始新业务时，仍然像从零开始。

## 2. 旧有解释

你可能以为自己缺的是：

- 更多流量；
- 更多工具；
- 更强团队；
- 更完整 SOP；
- 更努力地复制上次成功。

## 3. 认知冲突

为什么有些项目成功过一次，却没有让下一次更容易？

因为一次成功只是一种“表型”；如果没有被选择、编码、保留和重新调用，它不会成为事业的进化。

## 4. 第一性问题

> 一个创始人的生命差异，怎样才能变成能够持续适应、繁殖和进化的事业生命体？

## 5. 主模型

演化最小链：

```text
产生差异
→ 进入环境
→ 接受选择
→ 保存有效结构
→ 产生下一轮新差异
```

## 6. 原力映射

| 演化机制 | 原力战略 |
|---|---|
| 差异生成 | 原力母体与原力资产 |
| 现实选择 | 用户靠近、理解、付款、行动、Outcome |
| 生态位 | 原力借势与品类独创 |
| 资源代谢 | 前链、后链、财链 |
| 稳健性 | 虚、实、入、出四种控制权 |
| 信息保留 | 一纸文脉、一个大脑、一张地图、一条链路 |

记忆句：

> 原力资产创造差异，原力创业接受选择，原力 OS 完成保留；三者递归，才产生进化。

## 7. 它不是什么

- 不是“强者淘汰弱者”；
- 不是把母体说成生物基因；
- 不是市场成功等于道德正确；
- 不是复制过去最优答案；
- 不是用达尔文为创业方法背书。

## 8. 三分钟脚本骨架

### 0—20 秒｜击中

很多创业者做成过很多项目，但事业没有因此变得更聪明。项目结束，只留下收入、疲惫和一堆文件。

### 20—60 秒｜模型

演化并不只是强者胜出。它至少需要三件事：先产生差异，再让差异接受环境选择，最后把有效差异保存下来。没有保留，一次成功就不会成为下一代能力。

### 60—130 秒｜映射

原力资产负责找到并训练你的差异发生器；原力创业让这种差异进入时代、用户和市场；原力 OS 把有效判断、案例、数据和流程保存到下一次任务。三部曲不是三门课，而是一条事业演化链。

### 130—160 秒｜边界

企业不是生物，母体也不是基因。这个模型的价值不是证明原力战略，而是提醒我们：只有产生差异、接受选择、保存学习，事业才会进化。

### 160—180 秒｜行动

回想最近一个成功项目：它留下了哪一条能被下一次明确读取的规则？如果没有，这次成功还没有完成“遗传”。

## 9. 唯一产物

# 《我的事业演化闭环》

1. 最近一次有价值的差异是什么？
2. 真实世界用什么行为选择了它？
3. 哪条判断、案例或规则已经被保存？
4. 下一次任务将在开始前读取什么？
5. 什么反例会迫使我修改这条规则？

## 10. 观察指标

- 用户能否复述“生成—选择—保留”；
- 是否停止使用“强者生存”作为主要理解；
- 是否能指出一项未完成遗传的成功；
- 是否产生一条可进入下一任务的规则；
- 是否出现边界误解。
