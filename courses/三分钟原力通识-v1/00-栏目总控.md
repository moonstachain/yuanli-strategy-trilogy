# 三分钟原力通识 v1 · 栏目总控

## 1. 北极星

不是做知识百科，也不是借名人和学科为原力战略背书。

栏目只完成一件事：

> 用一个经典模型，击中专家型创业者的一个真实困境，使其形成一个新判断，并做出一个最小行动。

## 2. 目标学员

- 有十年以上经验，但说不清不可复制价值的专家；
- 有产品和收入，但越来越依赖本人的创业者；
- 正在使用 AI，却发现产出增加、辨识度下降的高认知个体；
- 希望把经验变成课程、产品、组织能力或原力 OS 的创始人。

## 3. 三分钟标准结构

| 时间 | 教学动作 | 必须产生的心智结果 |
|---:|---|---|
| 0—20 秒 | 症状与冲突 | 这讲的就是我 |
| 20—55 秒 | 模型原义 | 分清模型究竟说了什么 |
| 55—120 秒 | 原力映射 | 看懂它照亮三部曲的哪个机制 |
| 120—155 秒 | 反例与边界 | 不把隐喻误当事实 |
| 155—180 秒 | 一个问题与行动 | 今天能做一次判断或实验 |

## 5. 三道内容门

### Gate A｜学科门

- 模型在原学科中的定义清楚；
- 能标明适用范围与争议；
- 不把生物、心理或物理隐喻直接当作商业事实；
- 外部事实有可追溯来源。

### Gate B｜原力门

- 明确照亮 A1—C4 中的哪个机制；
- 不修改 Soul 正典；
- 不与现有模块产生同义重复；
- 能说明缺少该模型会造成什么判断错误。

### Gate C｜教学门

- 一期只改变一个关键判断；
- 三分钟内可以讲清；
- 有小白语言，不只保留学术术语；
- 有一个最小动作与可观察结果。

## 6. 生产链路

```text
选题候选
→ 学科原义卡
→ 原力映射卡
→ 证据核验
→ 3 分钟脚本

```

没有真实发布与测量，不得进入 `reusable`。

## 8. 第一季

第一季名称：**创业判断格栅**。

目的不是教会十二个名词，而是帮助学员建立一张最小判断网：

- 我是否理解真实环境；
- 我是否区分信号与噪声；
- 我是否看见概率、激励和机会成本；
- 我是否跑通价值、结果与现金链路；
- 我是否先避免灭绝，再追求复利；
- 我是否把一次成功写回下一次。
