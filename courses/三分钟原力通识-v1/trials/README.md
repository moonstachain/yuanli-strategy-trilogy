# 试讲与发布验收

本目录保存桌面试讲、真人试讲、正式发布和复用试验的脱敏记录。

## 四级试验

| 级别 | 含义 | 可用状态 |
|---|---|---|
| T0 桌面检查 | 结构、术语、边界和时长检查 | desktop_checked |
| T1 真人试讲 | 至少一位目标学员完成复述与练习 | live_trial |
| T2 正式发布 | 进入真实平台并完成观察窗口 | published_measured |
| T3 复用试验 | Task1 规则在 Task2 被明确加载 | reuse_verified |

## 最小验收

- 三分钟内完成；
- 学员能复述唯一概念；
- 能指出它不是什么；
- 能映射到自己的真实事业；
- 留下一个可见产物；
- 有反证条件；
- 外部事实均已核验；
- 发布后记录误解，而不只记录赞美；
- 没有实际证据的项标记 `NOT_RUN`，不得写成通过。
