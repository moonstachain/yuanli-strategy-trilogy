本文件不负责“给原力战略找背书”，而负责保证课程中的外部事实、案例、数字和因果叙述可追溯、可核验、可降级。

当前旗舰小切口事实包：

> `01-五课旗舰小切口证据包.md`

该证据包覆盖 L01—L05 共 10 个 `ANCHOR_CUT`，并逐一标注：

```text

```

## 二、证据状态

统一使用：

```yaml
source_status:
  - to_verify
  - verified_primary
  - verified_secondary
  - internal_case_material
  - human_confirmed
  - disputed
  - excluded
```

原则：

- `to_verify` 不得作为正式结论口播；
- 内部案例材料不得自动写成已审计商业事实；
- 作者本人经历必须 Human Confirm；
- 正典定义以 Soul 为准，不以外部论文反向改写；
- 课程案例只负责帮助理解，不自动证明因果；
- 事实越弱，叙事越必须降级；
- 任何成功故事都必须恢复当时的不确定性，禁止事后诸葛亮；
- 历史人物的行为不得被课程直接宣布为“其原力母体”。

## 三、三类案例结构

### 1. 时代命运案例｜解释“秘密如何出现”

目标：让学员看到新旧生产函数交替时，旧世界可能仍然非常成功，而新财富窗口已经出现。

当前已核验旗舰：

- **古腾堡圣经**：复制生产函数突变；
- **Deep Blue**：机器跨越高阶任务边界；
- **Nokia 2007 / iPhone 2007—2008**：旧世界数据仍漂亮，新生产函数已经出现；
- **Nintendo Wii**：扩大游戏人口、重写“谁算玩家”。

历史候选仍保留：

- Ford：新范式创新如何进一步被压成极致性价比。

进入正式讲稿要求：

- 时间线核验；
- 关键数字使用一手或高质量来源；
- 明确“原力解释层”不是企业官方自述。

### 2. 人物临界案例｜解释“为什么偏偏是这个人看见”

目标：不写伟人传记，只写一个结果未知、代价真实的命运临界点。

当前已核验旗舰：

- **John Snow 1854**：异常、离群点、证据与行动；
- **屠呦呦 1971 Sample 191**：失败、文本细节、方法重写与实验验证；
- **George Washington 1783**：交还受托权力，价值作为真实约束。

候选仍保留：

- 塞麦尔维斯；
- 弗朗西丝·凯尔西。

必须回答：

- 他/她看见了什么异常？
- 当时主流解释是什么？
- 为什么另一条道路也合理？
- 支撑关键动作的证据是什么？
- 最终留下了什么可被后人调用的结果/制度/知识？
- 哪些只是课程解释，不能写成人物官方动机？

### 3. 组织与制度案例｜解释“怎样让价值穿越本人”

当前已核验旗舰：

- **Boeing Model 299 1935**：复杂系统关键状态未可靠显化；
- **Toyota Jidoka / Andon**：异常显影、停止、处理、避免复发、持续 kaizen；
- **Patagonia 2022 所有权重构**：把长期方向进入投票权、经济权益与利润流向。

必须区分：

> 已经建立的结构

和：

> 已经被长期 Outcome 证明的结构。

后者不能提前由前者替代。

### 4. 真实学员 / 客户案例｜解释“这与我有什么关系”

优先使用已有案例库：

- 苹果妈妈；
- 水月老师；
- 韬哥；
- 卷卷；
- 张姐 / 达哥；
- 帆哥；
- Matthew。

使用纪律：

- 区分原始逐字稿、综合材料、经营数据、真实 Outcome；
- 对证据不足处使用“现有案例材料显示 / 候选解释”；
- 不把 derived / unilateral synthesis 冒充本人确认；
- 不因单次付款或赞美宣称 Force Asset = compounding。

外部旗舰史料不替代真实学员案例：

> **历史案例负责打穿机制；学员案例负责完成自我迁移。**

## 五、九拍证据要求

旗舰故事必须按：

> **事 → 异 → 难 → 证 → 光 → 深 → 通 → 名 → 我**

其中证据要求：

### 事｜现场

必须可定位到至少两个：

- 时间；
- 地点；
- 人物；
- 物件；
- 真实动作。

### 异｜异常

必须来自事实之间的张力，而不是讲师制造悬念。

### 难｜两难

必须恢复当时信息条件：

> **另一条路为什么在当时也合理？**

### 证｜硬证据

至少一条官方/一手来源或高质量权威二手来源。

### 光｜弧光

弧光不能超过证据强度。

### 深｜机制

明确从这里开始是 `INTERPRET`。

### 通｜迁移

至少一个课堂未讲过的新场景。

### 名｜概念

概念来自 Soul / 课程合同，不由案例重新定义。

### 我｜裁决

必须形成真实业务判断或真实 No，不以“感悟”代替。

## 六、每一幕的最低证据需求

### L01｜AI重新定价

已满足：

- 一个复制生产函数突变的历史事实（Gutenberg）；
- 一个机器跨越高阶任务的可靠事实（Deep Blue）。

仍需在正式 Live Trial 口播前注意：

- “AI 把 80% 工作做掉”仍然只是课堂思想实验，不得口播成预测事实；
- “AI首先清算平均”属于课程判断，不是假装已有学术定律。

### L02｜秘密 × 一万倍

已满足旗舰：

- 一个时代裂缝案例（Nokia/iPhone）；
- 一个品类 / 认知重构案例（Wii）。

B3/B4 目前选择：

> 不再新增名企旗舰，优先由学员真实业务完成“繁 / 守”裁决。

### L03｜原力母体

已满足：

- 异常、反例、行动案例（John Snow）；
- 判断改写方法案例（屠呦呦）。

硬边界：

> 这些人物案例只能帮助理解“生成机制候选怎样被追踪”，不能宣称人物拥有某个已证明的“母体”。

### L04｜原力 OS

已满足：

- 一个关键状态没有可靠进入系统、造成灾难后果的案例（Model 299）；

硬边界：

> 不以“系统存在”替代真实 Outcome / Learning / Reuse。

### L05｜原力人生

已满足：

- 一个“守”在真实权力条件下发生的历史动作（Washington）；
- 一个把长期方向编码进所有权与分配机制的现代组织案例（Patagonia）。

硬边界：

> Patagonia 结构已经成立 ≠ 其百年效果已经验证。

## 七、事实与解释分层

正式课程材料统一使用：

```text
FACT        已核验事实
INTERPRET   原力战略解释
HYPOTHESIS  待现实验证的假设
CANON       Soul冻结正典
```

任何案例都不得把 `INTERPRET` 写成企业或人物的 `FACT`。

课堂教师必须能够说出一句：

> **“到这里是史料；从这里开始，是原力战略对这段史料的解释。”**
