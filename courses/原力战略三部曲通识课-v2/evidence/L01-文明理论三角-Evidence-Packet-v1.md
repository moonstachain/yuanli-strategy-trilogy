# CLAIM-01｜技术聚变会扩张能力边界

```yaml
source: The Future Is Faster Than You Think
authors: Peter H. Diamandis / Steven Kotler
role: 能
```

## SOURCE CLAIM

全书核心框架之一是多个指数技术的 convergence：AI、机器人、网络、传感器、数字生物学等并非孤立前进，而会相互增强，推动过去昂贵或不可行任务的能力边界外移。

## YUANLI INTERPRETATION

> **AI 首先改变的不是“人有没有价值”，而是大量能力的供给曲线与价格。**

可用于课堂的迁移：

```text
知识获取
表达
翻译
基础分析
基础设计
代码
研究辅助
内容生产
流程执行
↓
越来越容易获得
```

## BOUNDARY

- 不推出“所有能力都会趋近零成本”；
- 不把具体未来预测当作确定时间表；
- 不从技术可行性直接跳到社会系统同步变化。

# CLAIM-02｜丰裕会把瓶颈推向新的稀缺

```yaml
source: The World After Capital
author: Albert Wenger
role: 贵
```

## SOURCE CLAIM

Wenger 讨论数字技术如何改变工业时代以资本为中心的稀缺结构，并把人的注意力视为知识时代极其重要的约束；进一步讨论经济、信息与心理自由。

## YUANLI INTERPRETATION

> **技术不会自动消灭稀缺；旧瓶颈被突破以后，新的上层约束会变得更重要。**

课堂迁移：

```text
内容越多 → 注意力越贵
答案越多 → 好问题越贵
方案越多 → 判断越贵
选择越多 → 品味越贵
连接越多 → 信任越贵
无责任建议越多 → 承担结果的人越贵
```

## BOUNDARY

- 不表述成“注意力是唯一稀缺”；
- “答案→注意力→判断→品味→主体性”是原力教学综合，不是 Wenger 原始线性模型；
- Wenger 的制度方案不自动成为原力战略立场。

---

# CLAIM-03｜工具性问题被解决后，目的问题会显性化

```yaml
source: Deep Utopia: Life and Meaning in a Solved World
author: Nick Bostrom
role: 值
```

## SOURCE CLAIM

该书采用条件性思想实验：如果技术高度成功、许多工具性问题被解决，人类将更直接面对工作、意义、目的与价值的问题。

## YUANLI INTERPRETATION

> **当 HOW 越来越容易被解决，WHY 会越来越无法被隐藏。**

这为 L01 引出“价值主权”提供思想实验，而不是经验预测。

## BOUNDARY

- 不宣称“全面失业必然发生”；
- 不宣称 Bostrom 提出了“意义是下一种经济稀缺资源”；
- “目的显现”“价值主权”属于原力课程解释层。

# CLAIM-04｜AI 可以优化手段，但不能自动拥有人的目的函数

```yaml
source: Yuanli curriculum synthesis
role: 我
claim_type: YUANLI_INTERPRETATION
```

## INTERPRETATION

```text
AI 可以生成方案
AI 可以优化路径
AI 可以提高效率
AI 可以扩大执行

但：
什么值得投入生命？
什么代价不可接受？
什么结果值得承担？
哪种成功不值得追求？
仍然需要具体的人负责。
```

教学命名：**价值主权**。

## BOUNDARY

当前只作为 L01 的 `teaching principle / explanatory concept` 使用，不自动升级成新的顶层 canonical concept。

# CLAIM-05｜平均能力被丰裕化，不等于“人整体贬值”

```yaml
source: Yuanli curriculum synthesis
claim_type: YUANLI_INTERPRETATION
```

课程要建立的能力重估：

| 更容易被丰裕化 | 更难被平均化 |
|---|---|
| 已知问题的标准答案 | 定义什么才是真问题 |
| 通用信息组合 | 独特生命路径形成的跨域连接 |
| 普通表达 | 品味与选择标准 |
| 标准流程执行 | 高不确定性裁决 |
| 无责任建议 | 为结果承担责任 |
| 大规模连接 | 长期信任 |

皇冠句：

> **AI 不是在清算“人”，而是在重新给人的不同能力定价。**

# CLAIM-06｜规模不自动等于财富

```yaml
source: Yuanli canon / curriculum
claim_type: canonical_alignment
```

与原力母公理对齐：

> **做会自我繁殖的事，不做一次性的事。**

> **每一次输出，都必须成为下一次输入。**

因此 V3 教学公式：

```text
新财富
=
值得被放大的秘密
×
一万倍杠杆
×
时间保留率
```

其中：

- “值得”约束方向；
- “一万倍”解释空间复制；
- “时间保留率”解释资产化、复用与递归。
