## 一、总导演原则

十个 Anchor 不是“案例插播”，而是每一课最重要的认知发动机。

统一导演顺序：

> **让事实先工作 → 让异常制造不适 → 让两难恢复当时信息 → 证据逐层揭示 → 弧光只亮一次 → 机制纵深收束 → 跨尺度迁移 → 延迟命名 → 刀锋回到学员。**

录制时禁止：

- 开头先报“今天这个案例告诉我们……”；
- 把 `[PAUSE]` 全部填满；
- 每分钟制造一个金句；
- 为了情绪补人物心理；
- 把 INTERPRET 说成人物/企业本意；
- 故事结束用“大家有什么感想？”；
- 一个 Anchor 顺带讲完 3—4 个原力模块。

## 三、录制语言参数

建议中文口播速度：

```yaml
scene_and_fact: 210_to_240_chars_per_min
arc_and_pause: 130_to_180_chars_per_min
mechanism_deep_dive: 200_to_220_chars_per_min
personal_verdict_instruction: 180_to_210_chars_per_min
```

不是追求平均语速，而是形成速度差：

```text
现场：慢
事实：稳
数字：更慢
两难：问完停
弧光：最慢
纵深：恢复正常
人格裁决：再次变慢
```

## 四、屏幕纪律

每个 Anchor 的 `[SCREEN]` 只承担四类任务：

1. **定位**：时间 / 地点 / 一个关键物件；
2. **证据**：一个数字 / 一组对照 / 一条结构；
3. **弧光**：只出现一句；
4. **裁决**：让学员写一格。

禁止：

- 满屏史料；
- 一页 6 个观点；
- 把讲师口播全文同步上屏；
- 弧光页同时放解释；
- 纵深页变成论文综述。

---

## 五、黑屏纪律

黑屏只在三类地方使用：

```text
事实揭晓前
两难问完后
弧光出现前/后
```

每个 Anchor 建议 2—4 次黑屏，不追求电影化炫技。

黑屏的功能只有一个：

> **让学员脑内先生成答案，再接受下一条信息。**

## 六、逐字稿 QC Gate

每个 Anchor 进入正式录制前逐项打勾：

- [ ] 第一段没有先报概念；
- [ ] 60 秒内进入具体时间/地点/人物/物件；
- [ ] 异常来自史实，不是讲师造悬念；
- [ ] 两难恢复当时信息条件；
- [ ] 至少一处明确 `[EVIDENCE]`；
- [ ] 主 `[ARC]` 只有一个；
- [ ] `[DEEP_DIVE]` 只解释一个底层机制；
- [ ] 至少一次课堂未讲场景的 `[TRANSFER]`；
- [ ] `[CONCEPT_REVEAL]` 出现在故事后半段；
- [ ] `[PERSONAL_VERDICT]` 产生行动/No/可观察判断；
- [ ] FACT / INTERPRET / 禁讲边界存在；
- [ ] 来源可追溯；
- [ ] 预计不挤压本课唯一工具时间；
- [ ] 课后 24h 可测“故事→判断”，不是只测人物名。
