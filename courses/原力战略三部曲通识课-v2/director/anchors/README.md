## 导演纪律

1. **逐字稿不是背诵稿。** 粗体句为必保语义，其他允许口语自然化。
2. `[PAUSE]` 不能被讲师用解释填满；真正的认知冲突需要空白。
3. `[FACT]` 与 `[INTERPRET]` 必须口播区分；不把课程解释冒充人物/企业原意。
4. `[ARC]` 只允许一个主弧光；不连续制造金句。
5. `[DEEP_DIVE]` 只解释一个共同机制；最多三层镜头。
6. `[PERSONAL_VERDICT]` 必须回到真实业务/人生选择，禁止用“你有什么感悟”收尾。
7. 每个 Anchor 录制后必须保留 24h 记忆、机制迁移、FACT/INTERPRET 分离的 Live Trial 数据。
