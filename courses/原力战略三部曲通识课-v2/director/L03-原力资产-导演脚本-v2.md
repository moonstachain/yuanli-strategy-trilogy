## 一、本课导演目标

这不是“个人资产配置课”，也不是“自我探索课”。

它要完成一次认知换轨：

> **从我今天做成什么，转向我今天结束以后留下什么；再从已经留下的资产，追到持续创造资产的生成源。**

全课唯一问题：

> # **你这一生，到底在积累什么？**

“为什么偏偏是你？”保留，但降为中场追问。

---

# 0—10｜冷开场：你忙了十年，留下了什么？

[BLACK]

> **假设从明天开始，你停止直播、停止接客户、停止亲自交付、停止每天发内容。**

[PAUSE]

> **三个月以后，还有什么继续为你工作？**

不要马上解释。

[WRITE]

让学员写过去十年的五项主要投入：

- 做过的项目；
- 服务过的客户；
- 生产过的内容；
- 训练过的能力；
- 建过的团队或系统。

然后在每项后只标：

```text
停止本人投入后：
A 仍持续做功
B 快速衰减
C 几乎归零
```

[HAMMER]

> # **你做过很多事，不等于你积累了很多资产。**

# 10—20｜WHY ASSET：时间会耗散，资产让过去参与未来

[SCREEN]

```text
耗散式：
今天干 → 今天结果 → 明天归零 → 再干

复利式：
今天干 → 一部分留下 → 明天从今天之上继续 → 下一轮更强
```

教师说：

> “人的24小时不会存进银行。真正能穿过时间的，是你把这24小时加工成了什么。”

[CONCEPT_REVEAL]

> # **资产，是被保存下来的过去，能够继续为未来做功。**

只给六个企业家秒懂例子：

- 一个用户关系；
- 一个品牌心智；
- 一套方法；
- 一个内容母题；
- 一套组织系统；
- 一组可被 AI 继续调用的数据与规则。

[CHECK]

问：

> “为什么收入不自动等于资产？”

必须出现：停止今天的交换后，价值是否仍被保存、调用或继续生产。

# 20—30｜WHAT ASSET：今天赚多少，和今天留下什么是两个账户

[SCREEN]

| 收入思维 | 资产思维 |
|---|---|
| 今天赚多少？ | 今天留下什么？ |
| 这一单毛利多少？ | 做完这单下次是否更容易？ |
| 直播卖多少？ | 留下多少用户、内容、判断与系统？ |
| 我本人更厉害 | 什么能力已经脱离本人？ |
| 明年重新干 | 明年站在今年之上继续干 |

[HAMMER]

> # **收入是今天的结果；资产是今天结束后，明天仍能继续工作的价值。**

[TOOL]

写两列：

1. 过去一年最大的三项收入来源；
2. 每项收入完成后实际留下的资产。

若第二列为空，不批判，只让学员看见。
