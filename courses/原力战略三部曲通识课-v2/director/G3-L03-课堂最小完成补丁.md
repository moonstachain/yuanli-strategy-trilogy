## 1. 50—57min 资产卡不再八格全填

7 分钟只要求五个最小输出：

1. **差异作用**：我总在把什么从 A 推到 B；
2. **现实证据**：至少 1 条 Outcome；
3. **反证/替代解释**：至少 1 条；
4. **本人单点依赖**：如果我不在，什么立刻停止；
5. **90天资产化实验**：只选一项。

最后完成：

> **我似乎长期能够通过 ______，让 ______ 从 ______ 变成 ______；接下来我要把这种作用力训练、验证并保存下来。**

其余资产卡字段允许关键词、UNKNOWN 或扩展段补全。

## 2. 记忆层级

课堂不能把三套结构都作为背诵要求。

### 学生主记忆

> **源 → 力 → 形 → 留**

### 教学导航

> 找源 → 归源 → 炼力 → 证力

### 审计 Checklist

> 还在 / 叫得动 / 有效 / 带得走 / 会变强

只有第一层进入 24h 自由回忆硬验收。

## 3. L02 输入

L03 开场必须读取同一个 `VALUE_THREAD_ID`，先问：

> **上一课你已经选择的那个价值/秘密，做完以后到底留下了什么？**

禁止让学员重新发明一条完全无关的个人定位。

## 4. L03 输出

课尾只交给 L04 一个对象：

```yaml
FOUNDER_SINGLE_POINT_DEPENDENCY: ______
```

黑屏：

> **如果最值钱的东西仍只存在你本人身上，只要你不在就停止，它真的是成熟资产吗？**

下一课：原力 OS。

## 5. 真人 Fail Signal

出现任一项立即记录：

- 7 分钟内超过 20% 学员不知道先填哪格；
- 学员把“原力”回答成技能清单；
- 学员把“母体”回答成人格标签；
- 学员认为“客户满意/赚钱”即可证明资产化；
- 学员无法给出一个本人单点依赖；
- 课尾自然问题不能指向“如何离开本人继续工作”。

失败后优先减字段或改示例，不增加新理论。
