# 一、导演总目标

第三课仍不是“自我探索课”，而是一场破案：

> **职业、能力、成就只是果实；我们一路向下追踪这棵生命树为什么反复长出这一类果实，并第一次看到它怎样可能留下种子。**

本课唯一新判断：

> # **真正值得长期积累的，不是今天拥有的某一项能力，而是那个能够持续生成差异、被炼成现实作用力，并最终被保存和复用的生命机制。**

一课一果：

> **《我的原力资产生成树 v1》**

# 七、36—47｜A1 找｜概念延迟命名：Mother Hypothesis

[CONCEPT_REVEAL]

> # **原力母体，是为了理解一个 Self 为什么在跨时间、跨情境中持续产生某类差异，而提出的独特生成结构假设。**

```text

→ Interpretation
→ Value

```

[TOOL]

学员填写《原力资产生成树》“根”：

- 长期注意；
- 重复解释 / 判断；

- 长期承诺；
- 三种不同表型；
- 一个反证；
- 最强替代解释。

# 八、47—55｜A2 归｜人格裁决：我选择继续成为什么

[BLACK]

> **一个能够完美解释过去的 Mother，有什么用？**

下一页：

> **它能不能改变你明天的选择？**

[DILEMMA]

A：更赚钱，但长期把你训练成自己不愿成为的人；

B：短期收益低一些，但持续训练你主动认领的生成方向。

[ARC]

> # **真正的自我认知，不是让你更会解释自己，而是让你开始敢于舍弃不属于自己的成功。**

[WRITE]

> **即使赚钱，我也不愿长期成为 ______。**

必须是真实角色 / 项目 / 工作方式。
