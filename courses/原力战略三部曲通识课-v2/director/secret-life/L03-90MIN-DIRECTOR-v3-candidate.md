# 00—08｜归零实验：如果明天最值钱的东西全部失效

PPT 01 黑屏：

> **如果明天，你现在最值钱的东西全部失效，会发生什么？**

逐项出现：行业经验、平台流量、职位、产品、客户名单、最强技能被 AI 平权。

教师不解释，只问：

> **五年以后，你会重新变得值钱吗？**

PPT 02：

> **真正高级的资产，不是不贬值，而是贬值以后还能重新长出来。**

承接 L01：AI 会持续重新给能力定价。

承接 L02：上一课只是形成 `Wealth Candidate`，没有证明你已经拥有长期财富。

# 08—20｜剥能力：Generator ≠ Capability

PPT 03：`我最核心的能力是 ______`。

邀请学员心里填一个词。

教师追问链：

- 战略 → 不做战略，还能生成同类价值吗？
- 写作 → 不写文字，还能以别的载体显化吗？
- 连接 → 为什么你总想连接？
- 结构化 → 为什么混乱会被你优先看见？

PPT 04：

```text
Capability = 已长出的果实
Generator  = 让不同果实反复长出的结构
```

钉子：

> **能力是果实，不是根。**

边界：不否定技能价值，只否定“最强技能 = 母体”。

# 20—34｜反向侦探：三个同构痕迹

PPT 05：三个不同人生切片。

要求学员从不同阶段各取一个真实场景：

```text
A 职业 / 工作
B 创业 / 项目
C 兴趣 / 关系 / 跨域任务
```

教师按四问走：

1. 当时大家主要看什么？
2. 你偏偏注意了什么？
3. 你做了什么不同判断？
4. 你把什么转化成什么价值？

PPT 06：

```text
场景 A：异常 → 判断 → 转化 → 价值
场景 B：异常 → 判断 → 转化 → 价值
场景 C：异常 → 判断 → 转化 → 价值
```

教师：

> 现在把行业名、职位名、产品名全部删掉。剩下的动作像不像？

命名：`同构痕迹`。

钉子：

> **重复的不是你做过什么，而是你如何看见、判断和加工世界。**

# 34—40｜两个认知镜头：Snow / Tu Youyou

PPT 07｜John Snow。

只讲：异常分布、证据链、问题定义。

问：

> 为什么同一个城市里，有人接受异常，有人会持续不安？

PPT 08｜Tu Youyou。

只讲：反复失败后改变条件的判断动作。

问：

> 为什么有人增加同一种努力，有人重写条件？

教师强制边界：

> **这两个案例不证明原力母体。只说明注意和判断方式可能呈现稳定形状。**

不得补讲作者背景和英雄神话。

# 40—47｜延迟命名：原力母体

PPT 09：只出现四个字：`原力母体`。

教师定义：

> **不是一个人最强的能力，而是持续生成其独特能力、判断、作品、关系与意义的底层生命结构。**

PPT 10：禁区。

```text
≠ 兴趣
≠ MBTI / 原型标签
≠ 职业
≠ 最强技能
≠ 人设
≠ 唯一使命
≠ 不可反证的灵魂本质
```

教师：

> 今天不找“真正的你”。只允许得到 `Mother Hypothesis v0.1`。

PPT 11：前台脚手架。

```text
注意 → 判断 → 转化 → 承诺 → 价值
```

教师说明：`Value Generating Function` 是教学语言，不是新正典模块。

# 47—60｜A1 找：构造生成假设

PPT 12：四个变量。

```text
注意：别人习惯了什么，你却总会看见？
判断：别人觉得够好了，你为什么仍觉得不对？
转化：你总喜欢把什么变成什么？
承诺：什么问题短期没回报，你仍会回来？
```

给句式：

> **当我面对______类型的复杂性时，我似乎会反复注意______，用______作为判断标准，把______转化为______，从而为______创造______。**

随后必须写：

- 3 个跨情境证据；
- 1 个最强竞争解释；
- 1 个反证。

PPT 13：

> **一个无法被反驳的母体，只是一段好听的自我故事。**

教师巡场，只追问“什么会推翻你”，不帮学员润色成漂亮人格故事。

# 60—68｜A2 归：让自我认知产生机会成本

PPT 14：

> **如果它是真的，你应该停止什么？**

只选四个动作之一：

```text
加 / 减 / 停 / 拒
```

要求具体到一个真实机会、业务、角色或工作方式。

不得接受：

- “多做喜欢的事”；
- “少内耗”；
- “勇敢做自己”。

通过语言必须带真实代价。

PPT 15：

> **真正的自我认知，一定会让你失去一些机会。**

---

# 68—77｜A3 炼：把“我一看就知道”外化

PPT 16：

> **哪一句判断，你经常说“这个我一看就知道”？**

只拆一个：

```text
判断：我认为 ______
触发：当我看到 ______
依据：我重点观察 ______
反例：如果出现 ______，这个判断可能不成立
```

教师不要求写完整 SOP。

目标是第一次把隐性判断变成可观察规则。

一句：

> **母体不是资产；当它开始稳定产生可调用判断，才进入原力资产化。**

---

# 77—84｜A4 证：Out-of-Sample Test

PPT 17：`不要继续证明过去，去预测下一个场景。`

要求选择一个不同于前三个证据的新场景。

填写：

```text
我预测我仍会注意 ______
我仍会做 ______ 类判断
我仍会把 ______ 变成 ______
更可能产生 ______ 类型价值
```

再填写：

> 如果 ______ 没有发生，我愿意修改这个假设。

PPT 18：

```text
过去证据
+ 取舍证据
+ 预测证据
```

教师：

> **好的生成假设，不只会解释过去，还应该冒险预测未来。**
