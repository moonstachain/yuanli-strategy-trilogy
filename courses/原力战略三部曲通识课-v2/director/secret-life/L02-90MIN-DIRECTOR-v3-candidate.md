## 导演总目标

90 分钟不讲“四个创业模型”，只让同一个 Value Candidate 连续接受四次现实选择。

结课后学员应该能说：

> **我现在不是缺一个更好的点子，而是要判断我的价值候选卡在见、名、繁、守哪一道现实门。**

全课强制记忆：

> # **见 → 名 → 繁 → 守**

# 08—22｜第一关：见｜时代选择

## 08—12｜先打掉“风口化”

[SCREEN]

```text
AI
银发
出海
机器人
```

问：

> “这些是秘密吗？”

明确：

> **机会在外面；秘密是你对机会形成、并愿意交给现实验证的非平均判断。**

## 12—19｜Nokia / iPhone Anchor

沿用现有 Evidence Packet，不增加新事实。

只收一个机制：

> **旧世界规模仍然很强时，新生产函数也可能已经形成。**

严禁结果决定论。

让学员找自己业务中的结构差：

```text
技术已变 / 旧流程未变
用户已变 / 旧产品未变
成本已变 / 旧价格未变
问题已变 / 旧语言未变
```

## 19—22｜Why Now Thesis

[WRITE] 90 秒：

> “什么旧答案正在失效？什么新条件第一次成熟？”

揭晓：

> **见｜B1 原力借势**

钉子：

> **你不能拥有时代，只能借到时代的放大器。**

本关产物：`Why Now Thesis`。

# 22—38｜第二关：名｜心智选择

## 22—27｜制造理解危机

[SCREEN]

```text
客观价值
≠ 被理解的价值
≠ 被购买的价值
```

讲师：

> “用户不会按你脑中的价值购买，只会按他能够理解的分类、比较和标准购买。”

## 27—34｜Wii Anchor

沿用现有 Evidence Packet。

只收一个机制：

> **品类独创可以改变谁是用户、什么算价值、应该和谁比较。**

不讲“性能差所以成功”。

## 34—38｜Category Thesis

[WRITE] 2 分钟：

```text
用户现在把我归到：____
所以拿我和：____ 比
真正应该用的判断标准是：____
```

揭晓：

> **名｜B2 品类独创**

皇冠：

> # **用户不会购买客观价值，只会购买他能够理解的价值。**

辅助：

> **一个东西最昂贵的不是叫什么，而是它属于哪个世界。**

# 38—54｜第三关：繁｜结构选择

## 38—42｜100 个客户危机

[SCREEN]

> **明天同时来 100 个客户。**

问：

> “收入 ×100，还是疲劳 ×100？”

## 42—48｜最小复制单元

首次命名：

> # **最小复制单元**

定义：

> **不需要每次由创始人重新发明，也能再次产生相似价值的最小结构。**

[SCREEN]

```text
判断
→ 方法
→ 产品
→ 团队可交付
→ 软件 / AI 增强
```

讲师追问：

> “你最值钱的那份价值，现在究竟卡在本人哪一步？”

## 48—52｜三条链

只画：

```text
前链路｜到达
后链路｜交付
财链路｜健康流转
```

三条链不展开成三堂课，只用于找单点依赖。

## 52—54｜Replication Thesis

揭晓：

> **繁｜B3 模式升维**

皇冠：

> # **规模不是客户越来越多，而是同一份价值越来越少需要重新制造。**

AI 边界：

> **没有最小复制单元，AI 只会把混乱复制一万倍。**

# 54—68｜第四关：守｜时间选择

## 54—58｜所有人都知道你的秘密

[SCREEN]

> **竞争者明天拿到你的产品、价格、话术和秘密。**

问：

> “五年后，什么仍然属于你？”

## 58—63｜虚实入出

严格只讲四个：

```text
虚｜心智控制权
实｜交付控制权
入｜入口控制权
出｜留存控制权
```

不新增第五壁垒。

## 63—68｜Revenue + Asset Delta

新测试：

> **每卖一单以后，你到底变强了什么？**

[SCREEN]

```text
Revenue
+
Asset Delta
```

只问四类：

- 心智是否更深；
- 交付是否更强；
- 入口是否更自然；
- 留存/关系/数据是否更深。

揭晓：

> **守｜B4 壁垒锁定**

皇冠：

> # **真正的壁垒，不是别人不能抄你；而是别人开始抄你的时候，你已经因为昨天的成功变得更强。**

# 68—74｜四关总揭晓

[SCREEN]

```text
见｜时代选择｜为什么是现在？
名｜心智选择｜为什么用户理解并购买？
繁｜结构选择｜哪一份价值可以重复发生？
守｜时间选择｜每成功一次，什么控制权加深？
```

下一拍：

```text
见 → 时代财富
名 → 心智财富
繁 → 空间财富
守 → 时间财富
```

再翻回正典：

```text
B1 原力借势
B2 品类独创
B3 模式升维
B4 壁垒锁定
```

总钉子：

> # **见时代，名价值，繁结构，守控制权。**

# Desktop Trial 强攻项

1. 风口化：`见 = 找热门机会`；
2. 起名化：`名 = 起新词/定位`；
3. 规模化：`繁 = 多卖、多招人、多渠道`；
4. 护城河化：`守 = 别人绝对做不了`；
5. L01 接口：Value Candidate 不得被偷换为“已验证秘密”；
6. 工具：必须 `≤11min` 且达到 L3；
7. L03 Handoff：第一自发下一问应指向“为什么偏偏是我能看见”。
