## 1. 为什么需要 V3

现役 L03 的核心判断是正确的：`Generator ≠ Capability`，母体只能形成 `Mother Hypothesis v0.1`，必须有跨时期证据、反证、真实取舍和现实验证。

但 L01/L02 V3 之后，上游接口已经改变：

```text
L01 V3.1 → Value Candidate
L02 V3   → Wealth Candidate
```

因此 L03 不再假定学员携带一个“已经财富化的秘密”入场，而是从同一个 `Wealth Candidate` 反向追问：

> 为什么这类非平均判断偏偏反复从我身上出现？

## 2. 本轮只升级教学编译层

正典不变：

```text
A1 发现母体
→ A2 回到母体
→ A3 获得原力
→ A4 显化原力
```

原力母体定义不变：

> 不是一个人最强的能力，而是持续生成其独特能力、判断、作品、关系与意义的底层生命结构。

V3 新增的表达全部属于 teaching layer：

- `Re-generativity｜再生性`：真正高级的资产，不是不贬值，而是贬值以后还能重新长出来；
- `Value Generating Function｜价值生成函数`：帮助小白理解母体的前台脚手架；
- `同构痕迹`：在不同人生阶段寻找相似的注意—判断—转化动作；
- `Out-of-Sample Mother Test｜新场景测试`：母体假设不仅解释过去，还必须敢于预测未来；
- `Opportunity Cost Test｜取舍成本测试`：真正的自我认知必须改变真实选择。

这些均不新增 A5，不改变 A1—A4，不把教学隐喻升格为新正典。

## 3. 核心接口

```text
Wealth Candidate
↓
跨时期痕迹
↓
注意 / 判断 / 转化 / 承诺
↓
Mother Hypothesis v0.1
↓
真实取舍
↓
隐性判断外化
↓
新场景预测 + 反证
```

最终不是“找到终极真我”，而是：

> 得到一个比职业、技能、人格标签更有解释力，而且允许被未来证伪的个人生成假设。

## 4. V3 的五句钉子

1. **能力是果实，不是根。**
2. **一次好答案可能是运气；反复长出同类好答案，才值得追问生成源。**
3. **母体不是“真正的我”，而是目前最值得验证的生成假设。**
4. **真正的自我认知，一定会产生真实的取舍成本。**
5. **你真正拥有的，不是换一张地图以后仍然会什么，而是仍然能够重新长出什么。**

整课母句：

> **不要只研究你拥有什么，要研究什么在持续产生你拥有的一切。**

## 5. 关键边界

禁止：

- `母体 = 最强技能`；
- `母体 = MBTI / 原型 / 天赋标签`；
- `母体 = 此生唯一使命`；
- 只挑成功故事为母体作证；
- 用“爱、连接、创造”等不可证伪大词封口；
- `我觉得很准 = 已验证`；
- 用 John Snow / Tu Youyou 证明“母体客观存在”。
