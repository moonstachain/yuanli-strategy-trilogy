本次裁决不是修改五课结构，也不是修改 Soul 的 A→B→C 正典，而是在现有 Narrative Layer 内新增一套微观叙事发动机。

## 二、为什么需要这次升级

此前已经建立两层能力：

1. 五课结构层：决定讲什么、每课唯一判断和唯一产物；
2. Narrative / Director Layer：决定五次危机如何递进，以及课堂逐分钟怎样制造张力。

但仍缺一个关键中间层：

> **一个概念内部究竟怎样从具体事实、异常、两难和证据里“长出来”。**

如果没有这一层，课程仍可能退化为：

```text
定义
→ 框架
→ 案例
→ 练习
→ 总结
```

即使五课整体叙事很好，单个概念仍可能是“老师告诉学员答案”。

## 四、关键教学迁移

从：

> 先定义，再举例。

迁移到：

> **先经历，再解释；先困惑，再命名；先让事实压住人，再让理论升起来。**

因此课程中的关键概念原则上采用“延迟命名”：

```text
具体现场
→ 异常
→ 两难
→ 硬证据
→ 高弧光
→ 机制纵深
→ 跨尺度同构
→ 概念首次命名
→ 学员人格裁决
```

## 五、“大纵深”严格定义

本次裁决明确拒绝把“大纵深”理解成跨学科堆砌。

大纵深必须同时区分：

1. **事实纵深**：到底发生了什么；
2. **机制纵深**：为什么会发生；
3. **尺度纵深**：同一机制能否跨个人、组织、产业、时代迁移。

跨学科只在增加解释力时进入。

## 六、“小切口”严格定义

每个旗舰小切口优先包含：

```text
现场
+ 异常
+ 两难
+ 弧光
```

并由硬证据约束。

故事不是证据的替代品；叙事越强，证据纪律越强。
