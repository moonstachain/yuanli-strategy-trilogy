# 1. 本轮发生了什么变化

第三课旧版入口：

> **为什么偏偏是你？**

主要解决：

> 从能力表型追到持续生成能力的原力母体。

新版入口：

> # **你忙了十年，到底留下了什么？**

新版不是否定“为什么偏偏是你”，而是在它前面增加一个更上位的资产 WHY：

```text
为什么要资产化？
↓
什么叫资产？
↓
什么最值得资产化？
↓
什么叫原力？
↓
原力从哪里来？
↓
A1—A4 如何把母体炼成原力资产？
```

因此 L03 从“主体/母体发现课”升级为：

> **AI时代个人无形资本的生成课。**

---

# 2. 新增两个教学本体候选

## 资产

> **资产，是被保存下来的过去，能够继续为未来做功。**

严格解释：

> 被保存、可重新调用，并能因此改变未来结果的价值因果结构。

## 原力

> **原力，是原力母体经过训练后，在具体问题与情境中能够被主动调用，并持续产生非平均判断、行动与结果的差异作用力。**

核心判别：

> **能力回答“我会什么”；原力回答“因为我在，什么会变得不一样”。**

两者当前均按课程解释层治理，不自动升级 Soul Constitution。

---

# 3. 新教学总图

> **母体是源，原力是力，能力与作品是形，资产是留。**

```text
源 → 力 → 形 → 留
```

它不替换正典 A1—A4，只用于帮助小白区分：

- 生成源；
- 差异作用；
- 现实表型；
- 跨时间保存。

---

# 4. A1—A4 的新前台解释

后台正典不动：

```text
A1 发现母体
→ A2 回到母体
→ A3 获得原力
→ A4 显化原力
```

前台升级为：

```text
找源
→ 归源
→ 炼力
→ 证力
```

| 正典 | 新教学动作 | 新问题 |
|---|---|---|
| A1 | 找源 | 我的不同反复从哪里长出来？ |
| A2 | 归源 | 什么真正属于我？ |
| A3 | 炼力 | 我的不同能不能稳定做功？ |
| A4 | 证力 | 世界真的因此发生变化了吗？ |

---

# 5. 新增“世界验证 ≠ 资产形成”

旧版容易在 A4 世界验证结束。

新版明确：

> **结果发生了，不代表资产发生了。**

课上增加五道资产门：

```text
还在吗？
叫得动吗？
有效吗？
带得走吗？
会变强吗？
```

这只是课堂验收，不替代后台现有 inheritance lifecycle、Outcome、Task2 reuse 合同。

---

# 6. 主产物升级

旧默认：

> 《我的原力母体假设卡 v1》

新版默认：

> # **《我的第一张原力资产卡 v1》**

八格：

1. 我反复看见什么？
2. 我总想改变什么？
3. 因为我的介入，什么经常变得不一样？
4. 这种作用出现过哪些真实证据？
5. 它目前依赖什么具体技能或载体？
6. 过去我已经留下了什么？
7. 什么仍然只存在我本人身上？
8. 未来90天最值得资产化什么？

旧母体假设卡暂保留用于历史比较。

---

# 7. 90分钟课程合同如何保持不变

本轮讨论形成了一版 60 分钟高密度核心结构。

为不破坏现有 `5x90min` 旗舰通识课合同，采取：

```text
0—60min
最小可运行核心

60—90min
案例 + 跨载体检验 + 五道资产门互审 + 90天实验
```

因此没有把整门五课课程长度从 5×90min 偷改成 5×60min。

# 8. 五句皇冠

1. **资产，是被保存下来的过去，能够继续为未来做功。**
2. **能力回答“我会什么”；原力回答“因为我在，什么会变得不一样”。**
3. **母体是源，原力是力，能力与作品是形，资产是留。**
4. **真正的原力资产，不是你做过什么，而是你做完以后，那个只有你容易产生的价值没有消失。**
5. **真正的复利，是昨天开始参加今天的生产。**

最终皇冠：

> # **把只有你能持续产生的作用力，变成即使今天结束，明天仍能继续做功的资产。**

---

# 9. 与 L04 的新悬念

新版 L03 结尾不再只说“原力越强，创始人瓶颈越强”。

而是：

> **假设你真的找到了自己的母体，也炼出了原力，世界也证明它有价值。可是所有判断、关系、方法和经验仍然只存在你本人身上。你一天不工作，它就一天不生产。那它真的已经是一份成熟资产了吗？**

进入：

> **L04 原力 OS｜如何让你的原力，第一次离开你的身体继续生长。**
