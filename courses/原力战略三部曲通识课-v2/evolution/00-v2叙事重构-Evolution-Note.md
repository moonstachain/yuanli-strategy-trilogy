# Evolution Note｜通识课 v2 叙事重构

## 1. 变更对象

原力战略三部曲通识课前台教学叙事。

不变对象：

- Soul 正典三部十二模块；
- A→B→C 本体因果顺序；
- B4 虚 / 实 / 入 / 出四大壁垒；
- 原力 OS C1—C4 法权边界；
- 母公理“做会自我繁殖的事，不做一次性的事”。

## 2. 变更前

v1 前台主要按照：

```text
WHY：AI时代为什么需要原力战略
→ WHAT：原力战略是什么
→ HOW：A原力资产 → B原力创业 → C原力OS
```

记忆钩子：

> 找到原力，进入世界，形成复利。

优势：

- 与正典结构高度一致；
- 概念严谨；
- 适合作为教材骨架。

潜在问题：

- 小白学员进入 A 轴前，商业动机可能不足；
- “不可复制性 / 事业生命体”正确但前台抓力偏抽象；
- 十二模块容易被理解为知识地图，而不是财富生成故事。

## 3. 变更后候选

v2 前台改为：

```text
B 原力创业
财富怎么创造？
= 找到秘密，把它复制一万倍
↓
A 原力资产
为什么偏偏是你？
= 看见秘密的那双眼睛本身就是资产
↓
C 原力 OS
怎样让它不再依赖你？
= 让团队与AI继承判断并持续回写
```

超级母句：

> **新财富的本质，是找到这个世界上只有你才能发现的一个秘密，并把它复制一万倍。**

教学四动作：

> **见 → 名 → 繁 → 守**

对应：

```text
B1 原力借势
→ B2 品类独创
→ B3 模式升维
→ B4 壁垒锁定
```

## 4. 理论理由

### 理由A｜先回答用户正在问的问题

通识入口课首先需要回答“新财富怎么创造”，而不是要求学员先理解生成性本体论。

### 理由B｜形成悬念链

```text
财富怎么来？
→ 为什么你能看见？
→ 怎样不依赖你？
```

每一幕都自然制造下一幕的必要性。

### 理由C｜不牺牲后台严谨性

v2 只改变前台 UX，不修改后台 A→B→C。

### 理由D｜把“一万倍”重新定义为空间与时间

```text
B3 = 空间繁殖
B4 = 时间复利
```

避免把规模化简化为“多卖货 / 多流量”。

### 理由E｜让 AI 成为必然答案

当学员意识到独特价值越依赖本人，越形成创始人瓶颈，C1—C4 才不再像技术附录，而成为“一万倍”的必要基础设施。

## 5. 风险

### R1｜秘密过度传播化

可能被误解为内幕、捷径、信息差。

Guardrail：始终定义为“非共识 + 可验证 + 与母体有因果关系的价值真相”。

### R2｜只有你过度个人神话

可能被误解为天命、唯一性或自恋。

Guardrail：后台语言使用“你比绝大多数人更有可能持续看见”，并保留反证与替代解释。

### R3｜B→A→C 被误认为正典改版

Guardrail：课程中在101—111分钟明确回归 A→B→C；README与总控双重声明。

### R4｜一万倍被误解为规模崇拜

Guardrail：定义为“空间繁殖 × 时间复利 × 系统继承”，不是单一收入倍数。
