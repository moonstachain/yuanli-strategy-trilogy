## 核心判断

五课不应被讲成“五个主题”，而应被讲成**五次危机升级**：

```text
时代逼问你
↓
市场逼问你
↓
自己逼问你
↓
事业逼问你
↓
人生逼问你
```

上一课的成功，必须制造下一课更深的危机。

## 总叙事

> **AI正在把“一万倍机器”交给每个人。未来真正稀缺的，不再是复制能力，而是什么值得被复制。**

五课因此形成：

```text
AI让平均变便宜
↓
秘密让差异变值钱
↓
母体让差异持续生成
↓
OS让差异穿越本人
↓
人生决定差异最终去哪里
```

### 2. 微观叙事内核

回答：

> **一段关键内容怎样讲，才能让概念不是被老师告诉，而是从事实与冲突里自己长出来？**

真源：

- `01-叙事内核-小切口大纵深.md`

最高原则：

> # **小切口，大纵深；强证据，高弧光。**

统一九拍：

> **事 → 异 → 难 → 证 → 光 → 深 → 通 → 名 → 我**

也就是：

```text
入现场
→ 见异常
→ 设两难
→ 亮硬证据
→ 出高弧光
→ 下机制纵深
→ 跨学科/跨尺度同构
→ 概念升起
→ 回到学员自己
```

宏观六段与微观九拍互不替代：

```text
一整课
六段戏剧节奏

其中关键认知转折
↓

一个旗舰故事 / 核心概念单元
九拍叙事发动机
```

## 叙事内核的一句话

> **用一个故事打开一扇窄门，用硬史料把人钉在现场，用跨学科一路向下挖到第一性原理，最后再把刀锋转向学员自己。**
