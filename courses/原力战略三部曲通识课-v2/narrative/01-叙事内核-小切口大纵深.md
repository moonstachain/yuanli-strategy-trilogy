> **小切口，大纵深；强证据，高弧光。**

这不是一种文风，而是《原力战略三部曲通识课 v2》的微观叙事发动机。

现有五课叙事总纲负责宏观问题：

> **为什么五节课必须一路追下去？**

本协议负责微观问题：

> **一段关键内容究竟怎样讲，才能让概念不是“被老师告诉”，而是从事实与冲突里自己长出来？**

---

# 1. 最高叙事原则

原力通识课禁止从“概念定义”起讲。

推荐路径：

```text
先让学员经历
→ 再让学员困惑
→ 用事实把旧解释逼到失效
→ 再进入机制
→ 最后才命名概念
→ 随即把刀锋转回学员本人
```

也就是：

> **先经历，再解释；先困惑，再命名；先让事实压住人，再让理论升起来。**

因此，原力概念不能站在故事前面。

它应该在事实被挖到足够深之后，从地下“长出来”。

---

# 2. 什么叫“小切口”

小切口不是“讲一个案例”，而是：

> **用一个极具体的历史/商业/生命瞬间，打开一个复杂世界的窄门。**

优先选择：

- 一个人；
- 一个房间；
- 一张桌子；
- 一个数字；
- 一项异常；
- 一个物件；
- 一次拒绝；
- 一个具体决策时刻。

禁止用“工业革命”“AI时代”“商业模式”“原力母体”等宏大抽象词直接开场。

小切口必须包含四个部件。

## 2.1 现场｜Scene

把人放进具体时间、地点、人物、物件和动作中。

先让学员“看见”，不抢答意义。

## 2.2 异常｜Anomaly

好故事必须出现一个：

> **不对劲。**

例如：

- 为什么相邻两个产房的死亡率长期不同？
- 为什么最成功的公司恰好在最好的一年错过新周期？
- 为什么性能更弱的产品反而扩大市场？
- 为什么已在多国销售的药，一名审核员仍拒绝批准？

没有异常，就没有认知张力。

## 2.3 两难｜Dilemma

必须尽量还原结果尚未知时的真实选择。

至少两条路都应在当时具有合理性。

禁止把历史写成：

> 好人选择正确答案，愚蠢的人选择错误答案。

真正要问：

> **如果站在当时、只拥有当时的信息，你会怎么选？**

## 2.4 弧光｜Arc

故事最后必须出现一个足够锋利的显影瞬间：

- 一句话；
- 一次拒绝；
- 一个实验；
- 拆掉一个物件；
- 改变一个参数；
- 删除一个按钮；
- 做出一个高代价选择。

高弧光不是煽情，而是：

> **让几十年的结构变化，在一个可记忆瞬间突然显影。**

---

# 3. 什么叫“大纵深”

大纵深不是“多讲几个学科”，更不是知识拼盘。

它是：

> **围绕同一个异常，不断换镜头，直到找到跨尺度、可迁移的共同机制。**

大纵深分三层。

## 3.1 事实纵深｜What happened

先把事实钉牢：

- 时间；
- 原始数据；
- 原始文献；
- 决策记录；
- 人物关系；
- 关键争议；
- 当时可获得的信息；
- 事后才知道的信息。

课程不得用后来结果反向伪造当时的确定性。

## 3.2 机制纵深｜Why it happened

跨学科只为解释同一个机制：

- 心理学：人为什么这样判断；
- 经济学：激励如何改变行为；
- 社会学：群体与身份如何维持旧共识；
- 演化论：差异如何被选择或淘汰；
- 系统论：反馈、延迟、回路如何造成结果；
- 信息论：不确定性与信号如何影响决策；
- 脑科学：注意、显著性、记忆、价值判断如何参与；
- 商业史：组织、品类、基础设施与市场如何变化。

纪律：

> **只选真正增加解释力的学科。不得为了“跨学科感”而凑齐学科。**

## 3.3 尺度纵深｜Where else it appears

最后检查同一机制能否跨尺度显影：

```text
一个人的选择
↓
一个团队
↓
一家公司
↓
一个产业
↓
一个时代
↓
再回到今天的一个创业者
```

真正的“大纵深”不是：

> 我用了六个学科。

而是：

> **同一个底层机制，在多个尺度上仍然成立。**

# 4. 一事六镜

对一个旗舰故事，优先使用“一事六镜”，但不要求每次机械凑满六镜。

| 镜头 | 追问 | 典型用途 |
|---|---|---|
| 个体镜 | 他为什么看见/没看见？ | 注意力、判断、母体 |
| 心理镜 | 为什么事实出现后仍不改变？ | 认知失调、身份、风险 |
| 组织镜 | 为什么个人正确仍改变不了系统？ | 权威、流程、激励、惯性 |
| 科学镜 | 什么算证据？什么仍是未知？ | 因果、反证、边界 |
| 系统/演化镜 | 为什么错误/优势会被放大和保留？ | 反馈、选择、复制、积累 |
| 今天镜 | 今天哪里正在发生同构问题？ | 迁移、创业、AI、现实判断 |

最终必须完成：

> **历史 → 机制 → 我。**

---

# 5. 强证据

故事不是证据的替代品。

叙事越强，证据纪律必须越强。

## 5.1 证据优先级

```text
原始文献 / 官方档案 / 官方数据
>
同期记录 / 一手访谈 / 论文
>
长期序列 / 跨案例比较
>
可靠二手研究
>
名人故事 / 转述 / 未核验材料
```

## 5.2 每个关键事实至少标记

```yaml
claim: 这条事实在证明什么
source_pointer: 来源
status: verified | candidate | unknown
time_context: 当时已知 | 事后得知
```

## 5.3 禁止

- 无出处精确数字；
- 用事后结果证明当时“显然应该知道”；
- 把争议性叙述写成无争议事实；
- 为了故事弧光补造人物内心；
- 用案例证明超出案例能支持的理论范围。

---

# 6. 高弧光

高弧光不是“讲得感人”，而是让一个关键机制拥有可记忆的形状。

优先寻找：

```text
异常被看见
↓
两条路都合理
↓
证据仍不完整
↓
有人必须选择
↓
选择产生真实代价
↓
一个动作让结构突然显影
```

最高标准：

> **不是人物伟大，而是当结果尚未揭晓时，他依据什么作出选择，并愿意承担什么代价。**

---

# 7. 九拍叙事协议

每个核心叙事单元统一采用：

> # **事 → 异 → 难 → 证 → 光 → 深 → 通 → 名 → 我**

| 拍 | 动作 | 学员心智 |
|---|---|---|
| 01 事 | 入现场 | 我看见了 |
| 02 异 | 见异常 | 等等，不对 |
| 03 难 | 设两难 | 如果是我怎么选？ |
| 04 证 | 亮硬证据 | 原来事实是这样 |
| 05 光 | 出高弧光 | 原来关键在这一刻 |
| 06 深 | 下机制纵深 | 为什么会这样？ |
| 07 通 | 跨学科/跨尺度同构 | 原来不是孤例 |
| 08 名 | 概念升起 | 原来这就叫…… |
| 09 我 | 人格裁决 | 那我的现实呢？ |

九拍不是固定九页PPT，也不是每拍等时。

它是叙事逻辑顺序。

---

# 8. “六段协议”与“九拍协议”的关系

现有五课叙事总纲中的六段协议继续有效：

```text
场景 → 危机 → 反转 → 新眼睛 → 裁决 → 悬念
```

它负责**一整课的宏观戏剧节奏**。

本文件的九拍负责**一段关键概念/旗舰故事的微观认知推进**。

二者关系：

```text
课程级宏观节奏
六段：场景→危机→反转→新眼睛→裁决→悬念

其中关键认知转折
↓

故事级微观发动机
九拍：事→异→难→证→光→深→通→名→我
```

不得互相替代。

---

# 9. 概念延迟命名

原则：

> **能不在前5分钟报概念名，就不报。**

例如讲 B1 原力借势，不应先给定义。

先让学员进入一个旧世界数据最漂亮、但生产函数正在被替换的现场；让学员先根据当时数据做判断，再观察结果。

当旧判断被事实击穿后，才问：

> **为什么我们总是在旧世界数据最好看的时候，最容易看不见新世界？**

然后再命名：

> **原力借势。**

这样概念不是“老师告诉的词”，而是学员从事实中撞出来的判断工具。

---

# 10. 人格裁决｜最后一刀必须回到学员本人

任何叙事单元都不能停在：

> “所以我们理解了一个深刻规律。”

最后必须出现：

> # **那你呢？**

典型追问：

## B1

> 你业务里最漂亮的数字，究竟是未来的先行指标，还是旧周期最后的繁荣？

## A1

> 过去十年里，有什么异常别人已经习惯，而你始终无法假装看不见？

## B2

> 你的用户是不是已经感受到一个新问题，只是还没有人替他命名？

## C4

> 过去一年做对的事情里，有多少已经成为下一次任务的输入？

人格裁决不是情绪鸡汤，而是：

> **迫使学员用新判断重新解释自己的现实，并做一个真实取舍。**

---

# 11. 五课应用原则

本协议不要求五课都堆满历史案例。

每课只需要 1—2 个真正能打穿关键判断的旗舰切口。

| Lesson | 最适合的小切口类型 | 纵深目标 |
|---|---|---|
| L01 原力战略 | 技术范式切换 / 旧能力突然贬值 | 重新理解AI时代什么变贵、什么变便宜 |
| L02 原力创业 | 新旧周期、品类迁移、商业模式分岔 | 看见“见名繁守”的财富变形 |
| L03 原力资产 | 人物长期选择、异常注意、跨职业连续性 | 从能力表型追到生成源 |
| L04 原力OS | 创始人离场、组织失忆、判断无法继承 | 从工具栈追到判断继承与递归 |
| L05 原力人生 | 高成就后的反转、长期代价、不可逆选择 | 检验什么真正值得被放大 |

案例永远服务一个关键判断，不抢学员主角位。

---

# 12. 导演层执行纪律

Director Layer 使用本协议时：

1. 每课标出 1—2 个 `ANCHOR_CUT`；
2. 每个 `ANCHOR_CUT` 至少标注 `SCENE / ANOMALY / DILEMMA / EVIDENCE / ARC`；
3. 标注概念首次命名点 `CONCEPT_REVEAL`；
4. 标出 1 个最终 `PERSONAL_VERDICT`；
5. 如果故事结束后学员只记住人物、不记判断，判定失败；
6. 如果跨学科超过三个镜头却没有增加解释力，删减；
7. 如果证据不足以支持弧光，降低叙事强度，不补故事。
