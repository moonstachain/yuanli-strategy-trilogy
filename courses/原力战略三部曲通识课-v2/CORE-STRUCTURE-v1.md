# 1. 课程原点

## 1.1 母问题

> # **AI 时代，怎样把一个独特生命，活成一个会复利的事业与人生？**

课程不以“掌握十二个模块”为终点，而以一次完整的认知迁移为终点：

```text
我有很多能力
↓
什么在持续生成我的不同？
↓
这种不同为什么会被世界选择？
↓
怎样让被验证的价值脱离本人继续发生？
↓
最终什么值得被长期复制与留下？
```

## 1.2 母公理

> # **做会自我繁殖的事，不做一次性的事。**

课程所有知识、故事、工具与作业都必须服从：

```text
本轮输入
→ 判断
→ 行动
→ 真实结果
→ Learning
→ 下一轮输入改变
```

不能进入下一轮的“好内容”，不得被视为课程最终结果。

## 1.3 超级母句

前台教学记忆：

> # **找到这个世界上只有你更可能发现的一个秘密，并把它复制一万倍。**

后台严格边界：

- “秘密”是 narrative device，不替代 canonical concept；
- “只有你”是传播语言，后台要求可验证、可反证，并能追溯到生命路径与生成结构；
- “一万倍”不是销量，而是高质量价值跨人、跨产品、跨组织、跨 AI、跨时间持续发生；
- 正典负责正确，秘密负责记住。

# 2. 双层结构：后台正典 × 前台教学

## 2.1 后台正典永远不变

```text
A 原力资产
→ B 原力创业
→ C 原力 OS
```

因果语法：

```text
独特生成
→ 现实选择
→ 系统保留
→ 递归再生成
```

十二模块：

```text
A 原力资产
A1 发现母体
A2 回到母体
A3 获得原力
A4 显化原力

B 原力创业
B1 原力借势
B2 品类独创
B3 模式升维
B4 壁垒锁定

C 原力 OS
C1 一纸文脉
C2 一个大脑
C3 一张地图
C4 一条链路
```

## 2.2 前台教学采用 1+3+1

```text
L01 原力战略
→ L02 原力创业
→ L03 原力资产
→ L04 原力 OS
→ L05 原力人生
```

教学语法：

```text
世界观
→ 财富动机
→ 主体回归
→ 系统继承
→ 人生整合
```

边界：

> 教学顺序可以 B→A→C；正典因果永远仍是 A→B→C。

> 原力人生是整合课，不是第四部，不是第十三模块。

# 3. 五幕长篇：一个秘密的一生

整套课程不再由“五个主题”构成，而由同一个叙事对象的五次生命变形构成：

```text
第一幕｜秘密诞生
↓
第二幕｜秘密进入世界
↓
第三幕｜秘密找到主人
↓
第四幕｜秘密获得生命
↓
第五幕｜秘密获得方向
↓
新的异常 / 新一轮秘密
```

课程状态机：

```text
S0 异常
→ S1 秘密种子
→ S2 秘密候选
→ S3 被现实选择的秘密
→ S4 财富化秘密
→ S5 有源之秘
→ S6 可继承之秘
→ S7 有方向之秘
→ S8 递归之秘
→ 新异常
```

最高连续性原则：

> **上一幕的成功，必须亲手制造下一幕更深的危机。**

# 5. 每节课统一生产协议

每节课必须同时存在六个且只有六个一级教学对象：

## 5.1 One Crisis｜一个危机

不是“今天学什么”，而是：

> **今天有什么旧判断必须失效？**

## 5.2 One Story｜一个旗舰故事

主故事承担 60%—70% 的叙事注意力。

必须满足：

- 一个具体人 / 现场 / 物件 / 决定性时刻；
- 一个异常；
- 两条当时都合理的道路；
- 证据并不完整；
- 真实代价；
- 能向下挖出本课机制。

其他案例全部降级为回声案例，不允许与旗舰故事争主角。

## 5.3 One Idea｜一个不可替代的新判断

每节课结束，学员最多需要新增一个一级判断。

如果删除这个判断，本课应失去存在必要性。

## 5.4 One Verdict｜一次人格裁决

概念不能停在“理解”，必须落到：

> **那你呢？**

学员必须在现实取舍、假设、边界或下一步行动上作出一个选择。

## 5.5 One Artifact｜一个可检查产物

产物必须：

- 当堂可完成；
- 可检查；
- 可进入下一课；
- 可在真实工作中继续使用；
- 可在课程结束后合并为《我的原力战略 1.0》。

## 5.6 One Cliffhanger｜一个下一危机

绝不使用：

> “下节课我们学习……”

必须让本课成功自然制造下一问。

# 6. 原力叙事统一发动机

## 6.1 四诀

> # **一事开天，一问到底，一理贯通，一念照我。**

- 一事开天：小切口；
- 一问到底：大纵深；
- 一理贯通：跨尺度同构；
- 一念照我：高弧光最终回到学员自己。

基础纪律：

> **小切口，大纵深；强证据，高弧光。**

## 6.2 九拍

```text
事 → 异 → 难 → 证 → 光 → 深 → 通 → 名 → 我
```

其中：

- 事：进入真实现场；
- 异：出现旧解释无法消化的异常；
- 难：两条道路都合理；
- 证：用硬证据阻止老师自由发挥；
- 光：选择与代价让结构显影；
- 深：向第一性机制下钻；
- 通：跨学科、跨尺度出现同构；
- 名：此时才命名概念；
- 我：把规律变成学员自己的问题。

概念命名原则：

> **先经历，再解释；先困惑，再命名。**

# 7. 五课的认知压缩

通识课不是概念展览。每节课只允许一个主记忆结构。

## L01

```text
不同 ≠ 正确
正确 ≠ 被选择
被选择一次 ≠ 复利
```

母机制：

```text
生成 → 选择 → 保留 → 再生成
```

## L02

```text
见 → 名 → 繁 → 守
```

四种财富：

```text
时代财富 → 心智财富 → 空间财富 → 时间财富
```

## L03

```text
找 → 归 → 炼 → 证
```

关键边界：

> 母体不是能力，A1 只产生 Mother Hypothesis，不产生“终极真我”。

## L04

```text
懂 → 记 → 判 → 行 → 强
```

其中“强”是 C1—C4 经 Outcome / Learning / Reuse 后的递归结果，不是 C5。

## L05

```text
守 → 生 → 事 → 人 → 留
```

关键边界：

> 方向不是 KPI 总分；不可交换项首先是约束。

# 8. 五课不是知识课，而是五次心智迁移

| 课 | 课前旧心智 | 课后新心智 |
|---|---|---|
| L01 | 我越能干越安全 | 稀缺的是持续生成不同，并让它被选择和留下 |

| L03 | 我的资产是经验与能力 | 真正重要的是持续生成这些能力的源头 |

# 10. 课程五层架构

## Layer 1｜Canon｜正典层

回答：什么是真的？

来源：Soul Constitution / Concept System / A1-C4 canon。

不得因教学方便修改法权。

## Layer 2｜Narrative｜叙事层

回答：为什么学员愿意跟下去？

核心：一个秘密的一生 + 原力叙事四诀 + SECRET_THREAD。

## Layer 3｜Learning｜学习层

回答：学员究竟改变了什么判断？

核心：旧判断→认知危机→新判断→迁移。

## Layer 4｜Artifact｜工具层

回答：学完后现实里留下了什么？

核心：五张一页工具→《我的原力战略 1.0》。

## Layer 5｜Evidence & Trial｜验证层

回答：我们凭什么说这节课成立？

核心：史料核验、Desktop Trial、Live Trial、24h Recall、Transfer、Outcome / Learning。

五层不得互相越权：

> 故事精彩 ≠ 正典正确；学员感动 ≠ 概念掌握；工具填完 ≠ 现实验证；一次试讲成功 ≠ reusable。

# 11. 核心验收标准

通识课不以“满意度高”作为最高验收。

## 11.1 结构验收

学员能否在无提示下说出：

```text
一个秘密的一生
= 诞生 → 入世 → 寻主 → 得生 → 定向
```

## 11.2 概念验收

能否分清至少五组关键边界：

- 不同 ≠ 正确；
- 正确 ≠ 被选择；
- 收入 ≠ 财富；
- 能力 ≠ 母体；
- 信息 ≠ 判断；
- 做完 ≠ Outcome；
- 复利 ≠ 天然善。

## 11.3 工具验收

每课主产物能否在规定时间完成，并且被下一课直接调用。

## 11.4 24h Recall

24 小时后，学员首先记住的应是：

- 一幕故事；
- 一个判断；
- 一张工具；
- 一个未解决的问题。

不是一长串术语。

## 11.5 Transfer

能否把同一机制迁移到自己真实事业，而不是只会解释课堂案例。

## 11.6 Compounding

五课结束后至少产生一次：

> 前课产物 → 后课直接读取 → 后课判断因此改变。

否则“递归”只停留在课堂口号。

# 14. 最终北极星

这套通识课成功，不是因为学员记住了“原力战略三部曲”。

而是五课后，他第一次能够回答：

> **我持续生成什么不同？**
>
> **世界为什么会选择这种不同？**
>
> **哪些结果已经被留下，使下一次不再从零开始？**
>
> **如果我真的拥有一万倍机器，我究竟愿意把什么放进去？**

最终课程不是给学员十二个答案。

而是给他一套以后反复面对新事业、新技术、新周期、新人生阶段时，仍然能够继续使用的生成—选择—保留—定向系统。

> # **从一个秘密开始，最终让一个人学会建设自己的长期生命与事业。**
