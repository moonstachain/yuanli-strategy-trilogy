## 一、本课唯一任务

第一课离场时，学员只有一条 `Value Candidate`，不是“已被证明的秘密”。

所以第二课不假设世界已经同意，而是完成一次新的创业换轨：

> **你相信，不等于世界选择；真相，也不自动等于财富。**

本课唯一问题：

> **一个值得验证的独特判断，怎样连续通过时代、心智、复制与控制四次现实选择，逐步进入财富结构？**

全课唯一前台记忆：

> # **见 → 名 → 繁 → 守**

对应正典：

```text
见｜B1 原力借势
名｜B2 品类独创
繁｜B3 模式升维
守｜B4 壁垒锁定
```

四种财富只作为教学解释：

```text
见 → 时代财富
名 → 心智财富
繁 → 空间财富
守 → 时间财富
```

# 二、接口重构｜Value Candidate 进入世界

开场必须冻结两个不等号：

> **你相信 ≠ 世界选择**
>
> **真相 ≠ 财富**

L01 V3.1 的 Value Candidate 只能作为本课输入，不能冒充已经被市场验证的秘密。

本课路径：

```text
Value Candidate
↓
见｜时代选择
↓
名｜心智选择
↓
繁｜结构选择
↓
守｜时间选择
↓
Wealth Candidate / 财富化秘密候选
```

离场仍然是候选，不宣告企业已获得真实财富结果。

# 三、第一关｜见：为什么偏偏是现在？

B1 不是追风口，不是列热门赛道。

第一性问题：

> # **什么旧答案正在失效，什么新条件第一次成熟？**

教学边界：

> # **机会在外面；秘密是你对机会形成、并愿意交给现实验证的非平均判断。**

因此：

```text
AI / 银发 / 出海 / 机器人
≠ 秘密

结构变化
× 我的非平均判断
× 特定贵问题
→ Why Now Thesis
```

沿用已核验 Nokia / iPhone Anchor，只证明：旧世界规模仍然很强时，新生产函数也可能正在形成。

本关产物：

> **Why Now Thesis｜为什么偏偏是现在？**

一句钉子：

> **你不能拥有时代，只能借到时代的放大器。**

---

# 四、第二关｜名：用户为什么理解不了你的价值？

危机：

> 你可能真的看见了变化，但用户仍用旧分类、旧比较和旧购买标准理解你。

三个不等号：

```text
客观价值
≠ 被理解的价值
≠ 被购买的价值
```

B2 不是“起名字”，而是重构用户理解接口：

- 问题如何定义；
- 属于什么类别；
- 与谁比较；
- 用什么标准判断；
- 从哪个心理账户付钱。

沿用已核验 Wii Anchor，只证明品类创新可以改变“谁是用户、什么算价值、和谁比较”。

本关产物：

> **Category Thesis｜用户应该把它当成什么新的答案？**

皇冠句：

> # **用户不会购买客观价值，只会购买他能够理解的价值。**

辅助句：

> **一个东西最昂贵的不是叫什么，而是它属于哪个世界。**

---

# 五、第三关｜繁：你究竟在复制什么？

危机：

> **如果明天同时来 100 个客户，你的收入 ×100，还是疲劳 ×100？**

B3 的核心不是“扩张”，而是找到：

> # **最小复制单元**

定义：

> **那一份不需要每次由创始人重新发明，也能再次产生相似价值的最小结构。**

可能的演化链：

```text
判断
→ 方法
→ 产品
→ 团队可交付
→ 软件 / AI 增强
→ 跨人、跨场景重复发生
```

三条链继续保留，但只围绕复制单元服务：

```text
前链路｜价值如何到达
后链路｜价值如何稳定交付
财链路｜价值如何形成健康现金与利润循环
```

纪律：同源多元，不做无关扩张。

本关产物：

> **Replication Thesis｜我究竟要复制哪一份价值？**

皇冠句：

> # **规模不是客户越来越多，而是同一份价值越来越少需要重新制造。**

AI 边界：

> **没有最小复制单元，AI 只会把混乱复制一万倍。**

# 六、第四关｜守：每成功一次，你到底变强了什么？

危机：

> 一旦模式成立，竞争者才真正有动力进入。

B4 不是“别人永远抄不了”，而是：

> **每一次成功之后，什么长期控制权变得更深？**

严格只保留四种冻结控制权：

```text
虚｜心智控制权
实｜交付控制权
入｜入口控制权
出｜留存控制权
```

不新增第五壁垒；飞轮是强化结果，不是第五壁垒；母体是生成源，不是壁垒。

引入本课新的资产测试：

> **Revenue + Asset Delta**

每一单结束，不只问收入，还问：

- 心智占有是否更深；
- 交付能力是否更强；
- 入口是否更自然；
- 关系、数据、习惯与留存是否更深。

本关产物：

> **Control Thesis｜每一次成功正在增加我的什么控制权？**

皇冠句：

> # **真正的壁垒，不是别人不能抄你；而是别人开始抄你的时候，你已经因为昨天的成功变得更强。**

# 七、一理贯通｜四次现实选择

```text
见｜时代选择｜为什么是现在？
↓
名｜心智选择｜为什么用户会理解并购买？
↓
繁｜结构选择｜哪一份价值可以不重新制造就再次发生？
↓
守｜时间选择｜每成功一次，什么控制权继续加深？
```

结果解释：

```text
时代财富 → 心智财富 → 空间财富 → 时间财富
```

教学压缩：

> # **见时代，名价值，繁结构，守控制权。**

总判断：

> # **创业，就是让一个独特判断依次获得时代、心智、空间与时间。**

# 九、毕业门

学员必须能完成：

1. 区分机会与秘密，不能把“见”说成追风口；
2. 区分品类与命名，不能把“名”说成起一个新词；
3. 说出自己的最小复制单元，不能把“繁”说成多卖/多招人；
4. 只用虚实入出解释“守”，并能说出一次交易后的 Asset Delta；
5. 只圈一个未来 30 天主瓶颈。
