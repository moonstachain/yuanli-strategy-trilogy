# 0. 课程契约

本课不从“AI时代”“原力战略定义”或“三部曲结构”开始。

本课只完成一件事：

> **让学员亲历一个秘密从异常中诞生、接受现实审判、被世界选择，并由此自己需要“原力战略”这个概念。**

本课唯一新判断：

> # **长期复利的事业，不是不断重复已经会做的事，而是持续生成差异，让现实选择，把有效结果留下，再让留下的结果改变下一轮。**

后台机制：

```text
独特生成
→ 现实选择
→ 系统保留
→ 递归再生成
```

前台叙事：

```text
异常
→ 秘密种子
→ 秘密候选
→ 被选择
→ 留下来
→ 下一轮
```

唯一主产物：

> **《我的原力战略起点图 v1》**

只诊断三个断点：

```text
生成断点 / 选择断点 / 保留断点
```

# 1. 第一诀｜一事开天
## 0—15分钟：一个空袋子

## 1.1 0—3分钟｜SCENE

黑屏，不出现“Dyson”“原力战略”“秘密”。

口播只做现场：

> 一台吸尘器。
>
> 用了一段时间以后，吸力越来越弱。
>
> 主人把集尘袋拆下来。
>
> 他以为：袋子满了。
>
> 把灰尘倒掉。
>
> 袋子已经空了。
>
> 重新装回去。
>
> 开机。
>
> **还是吸不动。**

屏幕只留：

> # **袋子已经空了。为什么还是吸不动？**

导演纪律：

- 不急着说答案；
- 不讲“伟大发明家”；
- 不先告诉结果；
- 让学员先拥有异常。

## 1.2 3—7分钟｜ANOMALY

现场投票：

> 如果你负责改进这台产品，你先做什么？

允许答案：

- 加大电机；
- 换更好的袋；
- 改过滤材料；
- 提醒用户更勤换袋；
- 增强密封；
- 重新设计气流。

教师不评判，只追问：

> **有没有可能，我们一直在努力改进一个本来就不该存在的部件？**

第一次裂缝：

> **同一个异常，不同的人可能根本没有在解决同一个问题。**

## 1.3 7—11分钟｜DILEMMA

给出两个当时都合理的工程方向：

```text
A｜做一个更好的袋子
成熟架构 / 行业共识 / 已知制造体系

B｜质疑袋子本身
高不确定 / 需要新结构 / 未知市场
```

问：

> **如果结果还不知道，只拥有当时的信息，你把预算给哪边？**

禁止把 A 写成愚蠢旧势力。

## 1.4 11—15分钟｜EVIDENCE + FIRST ARC

引入候选史实链：

```text
家用过滤堵塞异常
↓
联想到工业旋风分离
↓
把大型机制缩小
↓
做粗糙纸板原型
↓
原型开始工作
```

这里第一次出现 James Dyson 名字。

但教师只问：

> # **真正稀缺的是“知道旋风分离原理”，还是把两个别人认为无关的问题看成同一个问题？**

第一记钉子：

> **秘密，常常先以“大家已经习惯的异常”出现。**

证据状态：

```yaml
dyson_anchor:
  status: candidate_to_verify
  required_before_live_use:
    - exact chronology
    - bag-empty anecdote primary/first-person source
    - cyclone transfer source
    - cardboard prototype source
    - wording boundary
```

# 2. 第二诀｜一问到底
## 15—48分钟：一个不同判断，凭什么值得相信？

整段只追一个问题：

> # **不同，什么时候才不只是不同？**

## 2.1 15—23分钟｜第一问：看见不同，就是真的吗？

从纸板原型进入连续原型测试。

只使用一个教学数字：`5,127`，正式真人使用前必须在 Evidence Gate 再核验来源与表述。

禁止讲：

> 5126次失败 + 第5127次成功。

改讲：

```text
一个版本
→ 现实反馈
→ 修改判断
→ 再做一个版本
```

问：

> **如果一个想法从不允许现实把它推翻，它还是秘密，还是信仰？**

得到第一条边界：

> # **不同 ≠ 正确。**

进一步：

> **原力战略不是固执地相信自己，而是敢于提出非共识判断，又有纪律把它交给现实裁决。**

## 2.2 23—32分钟｜第二问：正确，就会被世界选择吗？

进入产业拒绝与商业化困境。

叙事重点不是“大公司愚蠢”，而是：

> 一个新答案即便技术上开始成立，也会进入一个由用户、渠道、成本、既有利益、认知分类与风险共同构成的选择环境。

屏幕：

```text
技术成立
≠
世界选择
```

得到第二条边界：

> # **正确 ≠ 被选择。**

引导学员第一次意识到：

> 世界没有义务奖励你的真实。

## 2.3 32—40分钟｜第三问：被选择一次，就叫财富吗？

假设一个产品终于卖出去。

继续问：

> 如果下一次仍要从零开始，发生过一次的成功算复利吗？

屏幕：

```text
成功一次
≠
留下来
```

追问：

> 到底什么可以被留下？

只给类型，不展开模块：

- 判断；
- 方法；
- 技术；
- 产品；
- 用户关系；
- 品牌；
- 数据；
- 组织能力；
- 下一次可调用的规则。

第三条边界：

> # **被选择一次 ≠ 复利。**

## 2.4 40—48分钟｜第四问：什么才叫复利？

黑板只画：

```text
这一轮结果
↓
有没有改变下一轮起点？
```

如果没有：

> 只是重复。

如果有：

> 才开始出现递归。

第四条边界：

> # **重复 ≠ 复利。**

皇冠句候选：

> **真正的复利，不是把今天重复一万遍，而是让今天的真实结果改变明天的自己。**

# 3. 第三诀｜一理贯通
## 48—65分钟：生成 → 选择 → 保留 → 再生成

直到这里，才第一次离开旗舰故事。

## 3.1 48—52分钟｜抽出共同机制

从刚才一条故事链抽象：

```text
出现异常
↓
生成不同解释
↓
接受现实选择
↓
保留有效结果
↓
下一轮再生成
```

压缩为：

> # **生成 → 选择 → 保留 → 再生成**

## 3.2 52—59分钟｜跨尺度同构

只用四个镜头，每个镜头只做一个认知动作。

### 生命镜

差异必须经过环境选择，部分结果被保留，才可能进入下一轮。

纪律：不把原力战略伪装成生物学定理。

### 科学镜

新假说必须进入证据与反证，有效知识才能成为下一轮研究起点。

### 创业镜

独特价值必须被用户与市场选择，并沉淀为可继续调用的资产。

### 人生镜

经历只有改变未来判断，才不只是“发生过”。

一理：

> **一个会进化的系统，不能只有产生差异，也不能只有现实选择，还必须拥有保留与再生成。**

## 3.3 59—65分钟｜AI今天镜

这里才允许出现 AI。

AI 不再承担开场，而承担“今天镜”：

> 当复制、表达、执行、知识调用越来越便宜，真正稀缺的会更靠近：
>
> **什么值得被生成、被选择、被保留、被继续放大。**

旧版 L01 的 Gutenberg / Deep Blue 已核验 Anchor 可在这里作为 2 个短回声，不再与 Dyson 争夺旗舰主线：

- Gutenberg：复制能力变化后，稀缺性如何迁移；
- Deep Blue：机器能力抬升后，人类价值判断如何重新定位。

使用纪律：每个回声 90 秒以内，只证明一个点。

# 4. 概念延迟命名
## 65—73分钟：这套东西叫什么？

到这里才第一次正式出现：

# **原力战略**

教师口播逻辑：

> 我们从一个空袋子出发。
>
> 一路追问：为什么有人会产生不同解释；为什么不同不等于正确；为什么正确不等于被选择；为什么被选择一次仍然不等于复利。
>
> 最后我们发现，一个长期会进化的事业必须同时拥有：
>
> **独特生成、现实选择、系统保留、递归再生成。**
>
> 原力战略，就是围绕这套循环，建设一个会不断变强的事业生命体。

再给 Soul 正典定义，保持原文，不改法权：

> **原力战略，是围绕一个人不可复制的生成源，依次完成资产化、事业化与生命化，使独特性在不被稀释的前提下被世界放大、被系统继承，并在时间中形成复利的战略。**

然后翻成小白语言：

> **找到你真正不可复制的东西，让世界认出它，让生意放大它，让系统把它越做越强。**

## 4.1 三扇门，只露一次

```text
我｜原力资产｜独特生成
↓
世界｜原力创业｜现实选择
↓
时间｜原力 OS｜系统保留
↓
更强的下一轮
```

本课不展开 A1—C4。

# 5. “秘密”到这里才正式获得名字
## 73—78分钟

第一课只给“秘密”的最低教学定义：

> **秘密，是一个尚未成为共识、但值得进入现实验证的价值判断。**

进一步限定：

```text
秘密不是内幕
秘密不是聪明点子
秘密不是只有我相信
秘密不是无法反证的天命
```

第一课不讲完整“原力秘密”定义。

只让学员记住：

> # **没有现实审判的秘密，只是候选。**

第二课再把它升级成创业对象。

# 6. 第四诀｜一念照我
## 78—88分钟：《我的原力战略起点图 v1》

不再做大量前测，只做三格。

## 6.1 生成

> 过去十年，我反复产生过什么非平均的判断、连接或价值？

要求：至少 3 个跨时期实例。

## 6.2 选择

> 谁真的用钱、时间、行动、信任或结果选择过这种不同？

要求：不能只写“大家都说很好”。

## 6.3 保留

> 哪些结果已经离开当时的那次项目，进入了下一轮？

可写：

- 判断；
- 方法；
- 产品；
- 案例；
- 品牌；
- 用户关系；
- 数据；
- 流程；
- AI 规则；
- 组织能力。

最后只允许圈一个主断点：

```text
生成 / 选择 / 保留
```

黑屏。

这个问题同时照见：

- 有没有生成源；
- 有没有被现实选择；
