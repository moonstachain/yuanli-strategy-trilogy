# 0. 课程契约

前三幕已经完成：

```text
秘密诞生
→ 秘密进入世界
→ 秘密找到主人
```

但第三幕的成功制造了一个更危险的问题：

> **你越能持续产生高质量秘密，别人就越依赖你的判断。**

所以第四幕不是技术课，而是回答：

> # **怎样让一个高质量秘密摆脱“宿主依赖”，获得可以被事业继承的生命？**

本课唯一新判断：

> # **事业真正的规模，不是多少事情被自动化，而是多少原本只有创始人能做的高质量判断，已经能在边界内被团队与 AI 正确继承，并由真实结果继续修正。**

唯一主产物：

> **《我的原力 OS 一页架构 v1》**

全课唯一白话记忆：

> **懂你 + 记得住 + 会判断 + 能行动 + 每次变强。**

其中“每次变强”是 C1—C4 形成的递归结果，不是第五模块。

---

# 1. 一事开天
## 0—12分钟：创始人消失30天

不开场介绍 OS。

只给场景：

> 明天开始，你 30 天不能回微信、不开会、不能批准方案、不能临时救火。
>
> 第 7 天，团队遇到一个从没发生过的问题。

依次问：

1. 他们知道什么“像你”、什么“绝不能做”吗？
2. 他们能找到过去类似判断和可靠证据吗？
3. 三个机会同时出现，他们知道先押哪一个、停哪一个吗？
4. 决定以后，知道谁做、什么算真实结果、失败后写回哪里吗？

如果最后四个问题都汇成：

> **问老板。**

屏幕：

> # **秘密已经被你发现，却还没有离开你。**

异常：

> 文档可以很多、SOP 可以完整、AI 可以很强，为什么真正的判断仍然无法继承？

第一记钉子：

> **信息离开你，不等于判断离开你。**

---

# 2. 一问到底
## 12—25分钟：为什么知识库不是生命？

先摆五种“假活着”：

```text
文件很多，但不知道什么可信
Prompt 很多，但不知道什么不能做
知识很多，但不知道现在押什么
自动化很多，但不知道现实有没有改变
任务做完，但没有改变下一次
```

问：

> **如果系统只能重复过去明确写过的答案，遇到新问题就停摆，它是生命，还是档案馆？**

得到：

> 真正要继承的不是“老板过去说过什么”，而是一套在边界内继续判断、行动、学习的能力。

第二记钉子：

> # **原力 OS 不是让创始人不重要，而是让创始人的重要性不再成为事业的单点故障。**

---

# 3. 已核验回声 Anchor 01｜Boeing Model 299
## 25—32分钟：复杂度超过记忆以后怎么办？

只做一个认知动作：

> **当系统复杂到优秀个体也可能遗漏关键动作时，可靠性必须从“记住”迁移到“系统化外置”。**

史料纪律：

- 只使用已核验事故与复杂操作背景；
- 不口播“事故之后立刻发明 checklist”作为已冻结事实；
- 不把 checklist 本身等同原力 OS。

迁移：

> 事业里的“高价值判断”也会随着复杂度增长，超过单个创始人的现场处理能力。

---

# 4. 概念升起｜原力 OS
## 32—36分钟

到这里才命名：

> # **原力 OS**

课堂定义：

> **把创始人的身份边界、事业证据、战略判断与现实行动，组织成团队和 AI 能够持续调用、验证、执行、回写和进化的事业系统。**

不先讲工具。

先讲四个器官：

```text
C1 一纸文脉｜懂你
C2 一个大脑｜记得住
C3 一张地图｜会判断
C4 一条链路｜能行动
           ↓
        Outcome
           ↓
        Learning
           ↓
       下一轮更强
```

---

# 5. C1｜一纸文脉
## 36—47分钟：秘密怎样不变成“变种”？

一个秘密离开主人以后，第一个危险不是忘记，而是：

> **为了效率被改成了你根本不会接受的东西。**

C1 只回答：

> # **什么不能轻易变？**

最小保存：

- 身份与长期母题；
- 长期承诺；
- 品味/质量标准；
- 伦理与价值边界；
- Human Gate；
- 关键概念与表达边界。

区分：

```text
稳定身份/承诺 → C1
阶段策略       → C3
历史证据       → C2
执行动作       → C4
```

学员围绕一个真实单点任务填：

> 三条不能漂移的原则 + 一个必须 Human Gate 的节点。

秘密获得第一个器官：

> **身份。**

---

# 6. C2｜一个大脑
## 47—58分钟：秘密怎样拥有可信记忆？

第二个危险：

> 系统记住了很多，但不知道凭什么相信。

C2 只回答：

> # **下一次做这个判断，必须先知道哪些可信事实？**

最小字段：

- 一个事实；
- 一个案例；
- 一条历史判断；
- 一个来源；
- 一个 Unknown。

局部标签：

```text
Cited / Inferred / Unknown
```

不形成第二套学生口诀。

第三记钉子：

> # **真正的记忆，不是记得更多，而是知道自己凭什么记得。**

秘密获得第二个器官：

> **记忆。**

---

# 7. C3｜一张地图
## 58—68分钟：秘密怎样继续作出新判断？

有身份、有记忆，仍然不能自动回答：

> **现在最该做什么？**

C3 只回答：

> # **当前唯一控制点是什么？**

学员必须写：

```text
Top 1 控制点：______
为什么：______
如果改善，会影响：______ / ______ / ______
Stop Condition：______
```

没有 Stop Condition 的战略，很容易从判断变成信仰。

秘密获得第三个器官：

> **方向判断。**

---

# 8. C4｜一条链路
## 68—78分钟：秘密怎样进入现实并学会纠错？

知道“做什么”仍然不等于现实改变。

只画一条最小链：

```text
判断
→ Work Package
→ Action
→ Evidence
→ Outcome
→ Learning
→ Reuse
```

学员必须为同一个任务写：

- Owner；
- 下一现实 Action；
- Human Gate；
- Evidence；
- Outcome；
- Failure Signal；
- Learning 写回位置；
- 下一次如何 Preload。

关键句：

> # **输出不是行动，行动不是结果，结果也不会自动变成学习。**

秘密获得第四个器官：

> **行动与反馈。**

---

# 9. 已核验回声 Anchor 02｜Toyota Jidoka / Andon
## 78—82分钟：系统什么时候才开始“活”？

只做一个认知动作：

> **高质量系统不是把异常藏起来以保持运行，而是让异常进入反馈与纠错。**

不把 Toyota 单一机制等同完整原力 OS。

迁移到本课：

> 如果系统只会继续执行，而不会因为 Outcome 改变下一轮，它仍然只是自动化，不是递归生命。

---

# 10. 一理贯通
## 82—85分钟：四器官形成一个生命回路

第一次完整合体：

```text
CTX｜我是谁，什么不能变
↓
EVD｜我们知道什么，凭什么
↓
DEC｜现在押什么，何时停止
↓
WPK/ACT｜谁去改变现实
↓
OUT｜现实发生了什么
↓
LRN｜我们学到了什么
↓
REUSE｜下一轮起点发生变化
```

秘密状态：

```text
只能活在主人身上的秘密
↓
S6 可继承之秘
```

这时才完整重定义“一万倍”：

> # **一万倍不是把一个答案复制一万遍，而是让原本只能由你完成一次的高质量价值，跨人、跨组织、跨 AI、跨时间继续发生，而且每一次真实结果都能修正下一次。**

# 11. 一念照我
## 85—89分钟

《我的原力 OS 一页架构 v1》只围绕一个真实单点任务：

1. 哪个判断现在必须找我？
2. C1：三条不能漂移的边界；
3. C2：下一次必须先加载的证据；
4. C3：Top 1 控制点 + Stop Condition；
5. C4：Owner / Action / Evidence / Outcome；
6. Learning 写回哪里；
7. 下一次怎么 Reuse。

PERSONAL VERDICT：

> # **你事业里最贵的哪个判断，今天仍然只存在你脑子里？**
