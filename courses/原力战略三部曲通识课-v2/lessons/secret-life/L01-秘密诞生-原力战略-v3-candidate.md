## 一、本课唯一任务

不是介绍三部十二模块。

不是预测“哪些职业会被 AI 替代”。

而是让学员完成一次财富观换轨：

> **当机器越来越会做，真正的新财富，是找到值得被放大的独特价值，并让它穿越空间与时间。**

本课最终只回答四个越来越深的问题：

```text
能：未来什么正在突然变得可能？
贵：什么因此开始越来越稀缺、越来越贵？
值：如果很多事都能做，什么真正值得做？
我：我有什么值得让这个新时代放大？
```

---

# 二、旧财富算法为什么需要换轨

旧算法并没有失效，而是它的部分变量正在被重新定价：

```text
学更多知识
→ 提升通用能力
→ 更努力工作
→ 提高效率
→ 做更多事情
→ 获得更多收入
```

AI 改变的首先不是“人有没有价值”，而是很多能力的供给曲线。

所以第一记重锤是：

> # **AI首先改变的不是人，而是能力的价格。**

学员必须区分：

> **有价值 ≠ 仍然稀缺。**

---

# 三、第一幕｜能：能力革命

## 3.1 Anchor 仍保留：古腾堡与 Deep Blue

1455 的古腾堡，不是用来证明“印刷术导致一切现代化”，只用来让学员看见：

> **复制成本一旦突变，价值会从“复制本身”迁移到原件、选择、组织与解释。**

1997 的 Deep Blue，不是用来证明“机器像人”，只用来让学员看见：

> **一个过去高度代表人类专业性的任务结果，可以被另一种智能生产函数实现。**

## 3.2 理论桥：The Future Is Faster Than You Think

三本书中的第一本只负责一个词：

> **能。**

技术进步不只是单线增长，更重要的是多种能力开始聚变。

课堂迁移：

```text
AI × 软件 × 网络 × 数据 × 自动化
↓
过去需要一个团队的任务
开始被一个人 + 系统完成
```

## 3.3 丰裕定律

> **技术革命首先改变的，是某种能力的供给成本。**

在 AI 时代：

```text
知识获取
基础表达
翻译
基础分析
基础设计
代码
研究辅助
内容生成
标准流程执行
↓
越来越容易获得
```

边界：不是“这些能力没有价值”，而是仅仅拥有它们越来越难形成长期超额差异。

# 四、第二幕 A｜贵：稀缺搬家了

## 4.1 理论桥：The World After Capital

第二本书只负责一个词：

> **贵。**

如果一部分旧瓶颈被技术突破，人类并不会进入“没有稀缺”的世界。

新的约束会出现。

## 4.2 稀缺迁移定律

> # **技术不会消灭稀缺，只会让稀缺搬家。**

让学员自己推：

```text
内容越多 → 注意力越贵
答案越多 → 好问题越贵
方案越多 → 判断越贵
选择越多 → 品味越贵
连接越多 → 信任越贵
无责任建议越多 → 承担结果的人越贵
```

课堂解释用“稀缺阶梯”，但必须说明这是原力教学模型：

```text
物质
→ 资本
→ 信息
→ 智能
→ 注意力
→ 选择
→ 判断
→ 品味
→ 信任
→ 意义
→ 主体性
```

问题从：

> “AI会不会替代我？”

迁移到：

> **“当平均能力越来越丰裕，什么反而越来越难扩容？”**

# 五、第二幕 B｜值：如果都能做，为什么还要做？

## 5.1 理论桥：Deep Utopia

第三本书只负责一个词：

> **值。**

不要把它讲成未来预测。

只做思想实验：

> 假设技术发展非常成功，大量工具性问题越来越容易解决。你不再需要仅仅因为“必须”而做很多事情，那么你会把有限生命投入在哪里？

## 5.2 目的显现定律

> **当 HOW 越来越容易被解决，WHY 就越来越无法被隐藏。**

过去大量“为什么”被外部结构代答：

- 生存压力；
- 老板；
- 行业惯性；
- 社会评价；
- 身份期待；
- 收入焦虑。

当工具能力增强以后，问题开始变成：

> **什么真正值得占用我的生命？**

## 5.3 价值主权

课程定义：

> **AI 可以优化手段，但具体的人仍必须承担目的、代价与结果。**

```text
AI 可以告诉你怎么做大公司
≠ 你应该做大公司

AI 可以帮助你赚更多钱
≠ 任何钱都值得用任何生命代价交换

AI 可以把一个目标放大一万倍
≠ 这个目标值得被放大
```

皇冠句：

> # **效率不能证明方向。**

治理边界：价值主权当前是教学原则，不自动升级为新的顶层正典概念。

# 六、第三幕｜我：人的能力开始重新定价

到这里才正式问：

> **那我究竟靠什么形成长期差异？**

## 6.1 能力重估

| 更容易被丰裕化 | 更难被平均化 |
|---|---|
| 已知问题的标准答案 | 定义值得回答的问题 |
| 通用信息组合 | 独特生命路径形成的跨域连接 |
| 普通表达 | 品味与选择标准 |
| 标准流程执行 | 高不确定性裁决 |
| 无责任建议 | 为结果承担责任 |
| 大规模连接 | 长期信任 |

第二记重锤：

> # **AI 不是在清算“人”，而是在重新给人的不同能力定价。**

# 七、秘密出现

现在才出现“秘密”。

传播语言：

> **找到这个世界上只有你更容易发现的一个秘密。**

后台教学定义：

```text
原力秘密
=
独特生成源
×
变化的时代
×
用户贵问题
×
现实验证
```

秘密不是：

- 内幕；
- 短期信息差；
- 一个聪明点子；
- 一条爆款标题；
- 一次碰巧赚钱。

真正的秘密，是一个尚未成为普遍共识、但你比平均意义上的人更容易持续看见，并愿意让现实验证的价值判断。

本课不回答：

> **为什么偏偏是你更容易看见？**

这个问题留给 L03《原力资产》。

# 八、AI 的大反转：一万倍机器

前半场 AI 似乎在“让能力变便宜”。

现在完成反转：

> **AI 同时也是历史上最强大的个体复制杠杆之一。**

一个判断可以进一步变成：

```text
判断
→ 内容
→ 方法
→ 产品
→ 软件
→ Agent
→ 工作流
→ 团队
→ 平台
→ 生态
```

所以：

> # **AI既是平均能力平权机，也是独特价值放大器。**

第三记重锤：

> # **当每个人都有一万倍机器，真正稀缺的是值得被复制的原件。**

---

# 九、复制很多次，还不等于财富

如果 AI 帮你每天生产一百条内容，但没有留下：

- 更深的用户理解；
- 更强的信任；
- 方法；
- 数据；
- 产品；
- 判断；
- 关系；
- 系统；
- 下一轮更低的启动成本；

那么只是把一次性劳动扩大了。

所以进入原力母公理：

> **做会自我繁殖的事，不做一次性的事。**

> **每一次输出，都必须成为下一次输入。**

第四记重锤：

> # **真正的财富，是过去创造的价值仍然能够参与未来。**

---

# 十、最终揭晓：新财富算法

传播版：

> # **秘密 × 一万倍**

V3 完整版：

> # **新财富 = 值得被放大的秘密 × 一万倍杠杆 × 时间保留率**

三个乘数：

```text
值得的秘密
→ 值不值得复制？

一万倍杠杆
→ 能不能跨人、跨产品、跨场景放大？

时间保留率
→ 今天结束以后，什么仍然属于未来？
```
