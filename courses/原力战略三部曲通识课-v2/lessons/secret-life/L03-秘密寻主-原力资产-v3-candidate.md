## 0. 课程契约

前两课已经回答：

```text
L01：什么值得被放大？
→ Value Candidate

L02：世界怎样选择并放大它？
→ Wealth Candidate
```

第三课不假设你已经“找到了被证明的秘密”，只沿着这个候选继续向后追：

> **为什么这类非平均判断偏偏更容易从你身上出现？**

本课唯一新判断：

> # **真正不可复制的，不是你现在拥有的能力，而是世界变化以后，你仍然能够重新生成价值的结构。**

唯一产物：

> **《我的原力母体假设卡 V2》 → Mother Hypothesis v0.1**

禁止离场语言：

> “我终于找到了真正的自己。”

合法离场语言：

> “我有了一个值得继续验证、也允许被推翻的生成假设。”

# 1. 第一幕｜归零实验
## 0—8min：如果现在最值钱的东西全部失效

黑屏逐项出现：

```text
行业经验：归零
平台流量：归零
公司职位：归零
现有产品：归零
客户名单：归零
最强技能：被 AI 平权
```

只问：

> # **五年以后，你会重新变得值钱吗？**

第一根钉子：

> **真正高级的资产，不是不贬值，而是贬值以后还能重新长出来。**

这不是要求学员预测未来职业，而是把注意力从“我现在拥有什么”切换到“我有没有再生能力”。

---

# 2. 第二刀｜能力为什么不是根
## 8—20min

让学员先写一句：

> 我最核心的能力是：________。

然后逐层拆：

- “战略” → 如果未来不做战略，你还能产生相似价值吗？
- “写作” → 如果以后不用文字表达，你还能不能以别的载体显化？
- “连接” → 为什么你总想连接？连接前你先看见了什么？
- “结构化” → 为什么混乱会对你特别显著？

核心区分：

```text
Capability｜能力
= 已经长出来、当前可调用的表型

Generator｜生成机制
= 让不同表型反复长出来的更深结构
```

第二根钉子：

> # **能力是果实，不是根。**

教学模型，仅作解释：

```text
生成结构 + 环境 + 资源 + 约束
→ 判断 / 能力 / 产品 / 作品 / 关系
```

职业只是某个时代的一个版本，不是源代码。

# 3. 第三段｜反向侦探：找三个同构痕迹
## 20—34min

不要找三个“成功故事”。

要求三个尽可能不同的阶段或载体：

```text
场景 A：职业/工作
场景 B：创业/项目
场景 C：兴趣/关系/跨域任务
```

每个场景只回答：

1. 别人当时主要在看什么？
2. 我偏偏注意到了什么？
3. 我做出了什么不同判断？
4. 我把什么转化成了什么？
5. 最终给谁创造了什么价值？

形成：

```text
场景 A：异常 → 判断 → 转化 → 价值
场景 B：异常 → 判断 → 转化 → 价值
场景 C：异常 → 判断 → 转化 → 价值
```

然后删掉行业名、职位名、产品名。

问：

> **剩下的生成动作像不像？**

命名：

> **同构痕迹｜不同故事里反复出现的生成动作。**

第三根钉子：

> **重复的不是你做过什么，而是你如何看见、判断和加工世界。**

# 4. 已核验回声｜John Snow / Tu Youyou
## 34—40min

只使用现有 Evidence Packet 已允许的边界。

### John Snow

只问：

> 同一个城市、同样的死亡，为什么有人接受“就是这样”，有人却持续追问分布异常？

教学动作：**注意对象不同。**

### Tu Youyou

只问：

> 同样面对连续失败，为什么有人继续增加同一种努力，有人开始重写实验条件？

教学动作：**判断与问题重写方式不同。**

教师必须说：

> **这两个案例不证明“原力母体”。它们只让我们看见：注意与判断方式可能存在跨任务的稳定形状。**

# 5. 概念延迟命名｜原力母体
## 40—47min

到这里才出现：

# **原力母体**

课堂定义保持正典：

> **不是一个人最强的能力，而是持续生成其独特能力、判断、作品、关系与意义的底层生命结构。**

小白解释：

> **把它暂时理解成你的“价值生成函数”。**

前台脚手架：

```text
注意 Attention
↓
判断 Judgment
↓
转化 Transformation
↓
承诺 Commitment
↓
反复生成某一类价值
```

边界页：

```text
母体 ≠ 兴趣
母体 ≠ MBTI
母体 ≠ 原型标签
母体 ≠ 职业
母体 ≠ 最强技能
母体 ≠ 人设
母体 ≠ 此生唯一使命
母体 ≠ 不可反证的灵魂本质
```

教师：

> 今天我们没有资格找到“真正的你”。我们只提出一个目前最值得继续验证的生成假设。

# 6. A1｜找：构造 Mother Hypothesis
## 47—60min

使用四个观察变量：

| 变量 | 追问 |
|---|---|
| 注意 | 什么别人已经习惯了，你却总会看见？ |
| 判断 | 什么别人觉得够好，你却总觉得不对？ |
| 转化 | 你总喜欢把什么变成什么？ |
| 承诺 | 哪类问题短期没回报，你仍会反复回来？ |

生成句式：

> **当我面对 ______ 类型的复杂性时，我似乎会反复注意 ______，用 ______ 作为判断标准，把 ______ 转化为 ______，从而为 ______ 创造 ______。**

必须同时填写：

- 三个不同场景的支持证据；
- 一个最强竞争解释：职业训练 / 平台资源 / 身份人格 / 奖励机制 / 偶然成功 / 其他；
- 一个反证：什么事实最可能说明这个解释不成立或不完整？

铁律：

> # **一个无法被反驳的母体，只是一段好听的自我故事。**

命名：`A1 发现母体｜找`。

---

# 7. A2｜归：让假设产生取舍成本
## 60—68min

屏幕只问：

> # **如果这个假设是真的，你应该停止什么？**

四动作：

```text
加｜应该加强什么
减｜应该减少什么
停｜应该停止什么
拒｜即使赚钱，也不愿长期成为什么
```

课堂只圈一个，不允许全部填写。

必须出现真实机会成本。

第四根钉子：

> # **真正的自我认知，一定会让你失去一些机会。**

如果一个母体故事支持所有机会，它没有战略价值。

命名：`A2 回到母体｜归`。

---

# 8. A3｜炼：把“我一看就知道”变成判断资产
## 68—77min

问：

> **你最值钱的一句“这个我一看就知道”是什么？**

例如：

- 这个商业模式跑不通；
- 这个定位用户记不住；
- 真问题不是流量；
- 这单生意有收入但没有资产；
- 这个人不是这件事的正确 Owner。

只外化一个：

```text
判断：我认为 ______
触发：当我看到 ______
依据：我重点观察 ______
反例：如果出现 ______，这个判断可能不成立
```

核心：

> **A3 不是把天赋变强，而是把只有本人能调用的隐性模式，第一次变成可观察、可讨论、可训练的判断资产。**

命名：`A3 获得原力｜炼`。

---

# 9. A4｜证：新场景测试
## 77—84min

V3 新增：`Out-of-Sample Mother Test`。

不允许只用过去的成功继续证明自己。

找一个过去没做过、或至少不属于前三个证据场景的新任务。

写：

> **如果 Mother Hypothesis 是真的，我预测：**

```text
我仍会优先注意 ______
我仍会做出 ______ 类判断
我仍会倾向把 ______ 转化为 ______
最终更可能产生 ______ 类型价值
```

再写：

> **如果 ______ 没有发生，我愿意修改这个假设。**

三层证据：

```text
过去证据：能否解释多个跨期表型
取舍证据：能否改变今天的真实选择
预测证据：能否预测新场景里的行为与价值
```

命名：`A4 显化原力｜证`。
