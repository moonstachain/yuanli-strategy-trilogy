# 1. 本课唯一任务

不是介绍三部十二模块，也不是预测“哪些职业会被 AI 替代”。

本课只完成一次财富观换轨：

> **当机器越来越会做，真正的新财富，是找到值得被放大的独特价值，并让它穿越空间与时间。**

学员前台只需要记住四个字：

> # **能 → 贵 → 值 → 我**

对应四问：

```text
能：未来什么正在突然变得可能？
贵：什么因此开始越来越稀缺、越来越贵？
值：如果很多事都能做，什么真正值得继续验证？
我：我有什么非平均判断，值得交给世界验证并被新时代放大？
```

三本书只作为理论脚注，不要求记住作者、书名或完整模型。

---

# 2. 能｜AI 首先改变能力价格

保留两个历史 Anchor，但合计压缩：

- 1455 古腾堡：复制成本突变，原件与复制开始大规模分离；
- 1997 Deep Blue：某种高度专业任务结果可以由另一种智能生产函数实现。

外部理论脚注：《The Future Is Faster Than You Think》只负责解释“技术聚变会使能力边界外移”。

课堂主判断只有一句：

> # **AI首先改变的不是人，而是能力的价格。**

必须同时保留边界：

> **有价值 ≠ 仍然稀缺。**

知识获取、基础表达、翻译、基础分析、基础设计、代码、研究辅助和标准流程执行可以继续很有价值，但它们的供给增加后，仅靠“会做”越来越难形成长期超额差异。

---

# 3. 贵｜技术不会消灭稀缺，只会让稀缺搬家

外部理论脚注：《The World After Capital》只负责提供“旧瓶颈被突破后，新瓶颈浮现”的视角。

前台不再展示 10—11 级稀缺阶梯，只保留三组代表迁移：

```text
答案越来越多 → 好问题越来越贵
方案越来越多 → 判断越来越贵
选择越来越多 → 品味 / 价值取舍越来越贵
```

课堂主判断：

> # **技术不会消灭稀缺，只会让稀缺搬家。**

这一段的任务不是证明“注意力是唯一稀缺”，而是让学员完成一次迁移：

> 从“我还能学什么技能”转向“当平均能力变便宜后，下一层真正的瓶颈是什么”。

---

# 4. 值｜效率不能证明方向

外部理论脚注：《Deep Utopia》只做条件性思想实验：

> 假设技术发展得非常成功，大量工具性问题越来越容易解决，那么“为什么做”会比过去更难被外部结构代答。

课堂不展开人生终局，不把这一课变成 L05。

只收一个原则：

> # **效率不能证明方向。**

```text
AI 可以优化 HOW
≠
AI 自动拥有你的 WHY
```

课堂版“值”必须收束到一个可修订的短周期问题：

> **即使短期回报下降，我仍愿意继续验证哪个人群 / 问题至少一年？为什么？**

边界：

> **这不是唯一使命，不是终极人生答案，只是下一阶段值得继续验证的 Value Candidate。**

它可以被现实修订、缩小、放弃或重写。

---

# 5. 我｜AI 重新给人的不同能力定价

只保留一张两列表：

| 更容易被丰裕化 | 更难被平均化 |
|---|---|
| 标准答案 | 问题定义 |
| 普通表达 | 品味与选择标准 |
| 标准执行 | 高不确定性裁决 |
| 通用信息组合 | 独特跨域连接 |
| 无责任建议 | 责任承担 |
| 大规模连接 | 长期信任 |

主判断：

> # **AI不是在清算“人”，而是在重新给人的不同能力定价。**

“我”不是“找一个 AI 还不会的技能”，也不是“找一个更容易赚钱的赛道”。

它指向：

> **我长期形成了什么非平均判断与价值结构，值得继续交给现实验证？**

---

# 6. 秘密｜机会在外面，秘密是你的非平均判断

传播语言仍然保留：

> **找到这个世界上只有你更容易发现的一个秘密。**

后台教学定义：

```text
原力秘密
=
独特生成源
× 变化的时代
× 用户贵问题
× 现实验证
```

## 6.1 P0 边界：秘密 ≠ 商业机会

这是 V3.1 新增的强制 20—30 秒对照：

```text
机会：外部窗口，很多人都可能同时看见。
秘密：你对这个窗口形成的非平均判断。
```

秘密必须能继续回答三个问题：

1. 为什么你更容易持续看见？
2. 你看见的到底是哪一个贵问题？
3. 现实准备怎么推翻你？

皇冠边界：

> # **机会在外面；秘密是你对机会形成、并愿意交给现实验证的非平均判断。**

因此秘密不是：

- 内幕；
- 短期信息差；
- 风口本身；
- 赛道名称；
- 聪明点子；
- 爆款标题；
- 一次幸运。

## 6.2 不提前打开 L03 悬念

不再用“为什么偏偏是你更容易看见？”作为开放悬念。

只做边界提示：

> **秘密的来源问题后面再处理，本课先不证明。**

---

# 7. AI 大反转｜一万倍机器

AI 不只是让平均能力变便宜，也是一种个体复制杠杆。

课堂只保留最短链：

```text
判断 → 内容 / 方法 → 产品 / Agent → 系统化交付
```

主判断：

> # **当每个人都有一万倍机器，真正稀缺的是值得被复制的原件。**

真正问题不是：

> AI 还能替我做多少？

而是：

> **我究竟有什么值得让它帮我做一万遍？**

---

# 8. 时间｜复制很多次，还不等于财富

如果 AI 帮你扩大了产出，但没有留下用户理解、信任、方法、数据、产品、判断、关系、系统或下一次更低的启动成本，那么只是把一次性劳动扩大了。

回到母公理：

> **做会自我繁殖的事，不做一次性的事。**

> **每一次输出，都必须成为下一次输入。**

主判断：

> # **真正的财富，是过去创造的价值仍然能够参与未来。**

---

# 9. 最终揭晓｜新财富算法

传播版：

> # **秘密 × 一万倍**

V3.1 完整教学版：

> # **新财富 = 值得被放大的秘密 × 一万倍杠杆 × 时间保留率**

三问：

```text
值得的秘密：值不值得继续验证和复制？
一万倍杠杆：能不能跨人、跨产品、跨场景放大？
时间保留率：今天结束后，什么仍然帮助未来？
```

---

# 10. 三部曲只出现 2 分钟

```text
什么值得放大？ → 原力资产
怎样被世界选择并放大？ → 原力创业
怎样被时间留下并让下一轮更强？ → 原力 OS
```

不展开十二模块。

# 11. 本课唯一工具｜Live Core + 24h Extension

课堂只完成 Live Core，目标 10—12 分钟：

```text
A 1项：正在变便宜的能力
B 1项：AI 越强越值得训练的非平均价值
C 1项：即使短期回报下降，仍愿意至少一年继续验证的人群 / 问题
D 1项：准备把哪次输出变成下一次输入
E 1句：Value Candidate
```

完整 A/B 各 3 项、证据场景、停止项、资产化清单放到 24h Extension。

Value Candidate 强制边界：

> **它不是“唯一使命”，而是下一阶段值得现实验证的方向。**

# 12. 毕业门

学员必须能回答：

1. 为什么 AI 不是“人整体贬值”，而是能力重新定价？
2. 为什么技术丰裕会产生新的稀缺？
3. 为什么效率不能自动证明方向？
4. 为什么“商业机会”不等于“原力秘密”？
5. 自己目前至少有什么 Value Candidate，并知道它可以被现实修订？
