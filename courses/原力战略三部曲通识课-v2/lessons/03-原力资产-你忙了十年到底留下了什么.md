# 0. 本课位置｜从“财富怎么创造”回到“究竟是谁在创造”

前两课已经回答：

```text
L01 原力战略
当 AI 把复制变便宜，什么值得被放大？
↓
L02 原力创业
秘密怎样经过见—名—繁—守变成新财富？
```

第三课不立刻问“我的母体是什么”。

先问一个更锋利的问题：

> # **你忙了十年，到底留下了什么？**

一个人可以：

- 工作二十年；
- 创业十年；
- 做五百场直播；
- 服务一千个客户；
- 写一千篇文章；
- 赚过几千万营业额；
- 管过几十个人。

但如果今天全部停下来，真正的资产问题是：

> **其中有多少东西，明天仍然能够替你做功？**

本课唯一认知迁移：

> # **从“我有很多能力和经历”，迁移到“我正在把只有我容易持续产生的作用力，建设成未来仍会做功的资产”。**

本课唯一主产物：

> **《我的第一张原力资产卡 v1》**

# 1. 第一场心智革命｜收入不等于资产

## 1.1 资产不是“有钱的东西”

课堂第一句定义：

> # **资产，是被保存下来的过去，能够继续为未来做功。**

钱可以是资产。

但更重要的是：

- 过去建立的品牌，今天仍降低信任成本；
- 过去服务的用户，今天仍愿意回来；
- 过去形成的方法，今天团队仍能调用；
- 过去做出的内容，今天仍在获客；
- 过去训练的判断，今天能迁移到新问题；
- 过去积累的数据，让 AI 今天比昨天更懂你；
- 过去建立的系统，让今天不必重新开始。

共同点只有一个：

> **昨天没有完全消失。**

## 1.2 两种人生

### 耗散人生

```text
时间
↓
劳动
↓
结果 / 收入
↓
任务结束
↓
价值消散
↓
下一次重新开始
```

即使当期收入很高，也可能仍然高度耗散。

### 复利人生

```text
时间
↓
行动
↓
结果
↓
有价值的部分被保存
↓
成为资产
↓
参与下一次生产
↓
下一轮从更高起点开始
```

第一记重锤：

> # **真正的复利，不是今天比昨天更努力，而是昨天开始参加今天的生产。**

## 1.3 收入思维 → 资产思维

| 收入思维 | 资产思维 |
|---|---|
| 今天赚多少？ | **今天留下什么？** |
| 这场直播 GMV 多少？ | 结束后留下多少用户关系、内容、判断、方法与数据？ |
| 这次客户交付完成了吗？ | 下一次是否因此更容易、更好？ |
| 我本人越来越厉害 | **什么已经能够脱离一次任务继续存在？** |
| 明年继续干 | **明年能否站在今年积累之上继续干？** |

课堂闭卷题：

> **一个项目很成功，但下一次仍然从零开始，它为什么还不能算高质量资产化？**

# 2. 第二场心智革命｜能力不等于原力

人身上有很多能力：

> 写作、销售、战略、设计、管理、咨询、剪辑、AI、编程……

它们都可能有价值。

但 AI 时代真正应该追问：

> **哪些能力只是当前载体？哪些东西即使载体变化，仍然会反复从我身上产生差异？**

原力的课堂定义：

> # **原力，是原力母体经过训练后，在具体问题与情境中能够被主动调用，并持续产生非平均判断、行动与结果的差异作用力。**

第二记重锤：

> # **能力回答“我会什么”；原力回答“因为我在，什么会变得不一样”。**

## 2.1 一个例子

一个人拥有：

```text
战略咨询
课程设计
商业模式设计
知识图谱
AI OS
```

如果只看能力，这是五件不同的事。

继续往下追，可能发现同一种稳定作用：

> **进入复杂、混乱、碎片化的系统，识别隐藏结构，再把它重构成清晰、可行动、可递归的秩序。**

于是：

```text
咨询      课程      商业模式      知识图谱      AI OS
  \         |          |             |          /
   \        |          |             |         /
    └────────── 同一种差异作用力 ──────────┘
```

技能依赖载体。

> # **原力可以迁移载体。**

## 2.2 原力不是

- 天赋；
- 兴趣；
- MBTI / 人格标签；
- 高能感；
- 单项技能；
- 一次高光；
- 一次灵感；
- AI 生成能力。

一个潜能如果没有经过训练、不能稳定调用、不能产生现实作用，仍然不是成熟原力。

# 3. 一张总图｜源 → 力 → 形 → 留

本课只保留一个总图：

```text
过去的生命经历
长期注意 / 重复判断 / 品味 / 承诺
              ↓
        【原力母体｜源】
     为什么我持续产生这种不同？
              ↓
         训练 / 选择
              ↓
          【原力｜力】
     因为我的介入，什么会改变？
              ↓
判断 / 能力 / 方法 / 作品 / 关系
          【表型｜形】
              ↓
       真实世界选择与验证
              ↓
      保存 / 调用 / 复用 / 升级
              ↓
        【原力资产｜留】
      过去开始参与未来生产
```

第三记重锤：

> # **母体是源，原力是力，能力与作品是形，资产是留。**

四者不能混用：

- 母体不是能力；
- 原力不是潜能；
- 能力与作品是原力的现实表型；
- 一次表型成功不自动等于资产；
- 只有被保存、可调用并经现实证明有价值的差异作用，才开始具有原力资产性。

# 4. A1｜找源：我的不同反复从哪里长出来？

正典名称：**发现母体**。

课堂任务不是宣布“终极真我”，而是形成一个：

> `Mother Hypothesis v0.1`

母体定义：

> **原力母体，不是一个人最强的能力，而是持续生成其独特能力、判断、作品、关系与意义的底层生命结构。**

## 4.1 四条线索

### 长期注意

> **过去十年以上，你总会自动看见什么？**

### 重复判断

> **面对不同问题，你总会用什么方式判断？**

### 品味函数

> **什么答案别人觉得已经够好，你却长期觉得不够？**

### 长期承诺

> **什么问题，即使短期没有回报，你还是会回来？**

## 4.2 反证与替代解释

必须同时问：

> **什么事实不支持这个母体解释？**

以及：

> **它会不会只是职业训练、平台红利、身份要求、资源优势或成功惯性？**

关键句：

> **一个无法被反驳的“母体”，只是一段好听的自我故事。**

A1 产物：

```yaml
mother_hypothesis: candidate
confidence: not_proven
counter_evidence: required
alternative_explanation: required
```

# 5. A2｜归源：什么真正属于我？

正典名称：**回到母体**。

很多人把“我过去做得好”误认为“这就是我”。

A2 做一次：

> # **生成源剥离实验**

逐层拿走：

```text
去掉职位，还剩什么？
去掉公司，还剩什么？
去掉平台，还剩什么？
去掉过去的成功，还剩什么？
去掉掌声与奖励，我仍会关心什么？
```

母体如果是真的，必须能够指导未来取舍，而不是只解释过去。

## 5.1 加、减、停、拒

- 加：什么应该投入更多生命时间？
- 减：什么应该降低投入？
- 停：什么应该停止？
- 拒：什么即使赚钱，也不应该长期成为自己？

第四记重锤：

> **真正的自我认知，不是更会解释自己，而是开始敢于舍弃不属于自己的成功。**

A2 的高质量证据：

> **真实机会成本。**

# 6. A3｜炼力：我的不同能不能稳定做功？

正典名称：**获得原力**。

发现母体本身没有价值，除非它能做功。

一个人可能：

- 天然敏感，但不能形成判断；
- 有洞察，但无法稳定调用；
- 有审美，但做不成作品；
- 有经验，但说不清为什么；
- 有直觉，但无法跨任务复现。

这些都还停留在潜在状态。

## 6.1 炼力路径

```text
隐性手感
→ 显性判断

模糊经验
→ 概念与标准

一次高光
→ 稳定能力

直觉
→ 方法

本人会
→ 可反复调用
```

A3 真正炼出来的不是“更多技能”，而是：

> **可控、可主动调用的差异作用力。**

可以使用 AI：

- 帮你复盘；
- 帮你外化；
- 帮你比较；
- 帮你形成训练题；
- 帮你找反例。

但 AI 不是身份授权者，也不是原力来源。

# 7. A4｜证力：世界真的因此发生变化了吗？

正典名称：**显化原力**。

第五记重锤：

> # **独特性不是自我声明，而是现实结果。**

A4 把原力放进真实选择环境：

- 真实任务；
- 真实对象；
- 真实行为；
- 真实代价；
- 真实 Outcome。

课堂统一追问：

> # **Because of you, what changed?**

也就是：

> **因为你的介入，世界到底哪里变得不一样？**

可观察变化可能发生在：

- 理解；
- 判断；
- 行动；
- 作品；
- 关系；
- 用户结果；
- 经营结果。

点赞、夸奖、报名等弱信号可以记录，但不得自动冒充最终价值证明。

# 8. 世界验证仍不够｜最后还要过“资产门”

这里是本课与旧版最大的升级。

> **一个人做成了一件事，并不等于形成了资产。**

例如：

> 一场咨询非常精彩，但没有留下判断规则、方法、案例、数据或下一次可调用的结构。

那么：

> **结果发生了，资产没有发生。**

所以 A4 之后继续问：

> # **这次做完以后，什么留下来了？**

可能留下：

- 判断；
- 模型；
- 方法；
- 作品；
- 内容；
- 品牌；
- 获许可的用户关系与信任；
- 合作关系；
- 数据；
- 规则；
- 系统；
- AI 上下文；
- 控制权。

注意：

> **人本身不是资产。所谓“用户资产”只能指获许可、可持续经营的关系、理解、信任与触达结构，不能把用户本人对象化。**

## 8.1 五道资产门

| 资产门 | 验收问题 |
|---|---|
| **还在吗？** | 任务结束以后，它是否仍存在？ |
| **叫得动吗？** | 下一次是否能够被重新调用？ |
| **有效吗？** | 是否有真实结果证明它能产生价值？ |
| **带得走吗？** | 换场景、产品或平台以后，是否仍有作用？ |
| **会变强吗？** | 下一次使用能否在这一次基础上继续升级？ |

五问越多为“是”，资产性越高。

这五问是课堂验收，不替代后台已有的 inheritance lifecycle、Outcome、Task2 reuse 等治理合同。

# 9. 原力资产｜把“原力”和“资产”重新合在一起

最小定义：

> # **原力资产，是被保存下来的原力。**

完整教学定义：

> **原力资产，是一个人的原力母体经过训练形成差异作用力，在真实世界中创造可观察价值，并被保存为未来仍可调用、可复用、能够继续产生非平均价值的因果能力。**

可以压成：

```text
原力资产
=
母体同源
× 非平均差异
× 可主动作用
× 现实验证
× 保存
× 调用
× 复用
```

不是财务测算公式，而是必要条件提示。

第六记重锤：

> # **真正的原力资产，不是你做过什么，而是你做完以后，那个只有你容易产生的价值没有消失。**

# 10. 唯一工具｜《我的第一张原力资产卡 v1》

本课不再要求学员同时完成多张复杂工具。

只完成一张资产卡：

| 字段 | 学员填写 |
|---|---|
| **我反复看见什么？** | 母体线索 |
| **我总想改变什么？** | 原力方向 |
| **因为我的介入，什么经常变得不一样？** | 差异作用 |
| **这种作用出现过哪些真实证据？** | 原力证据 |
| **它目前依赖什么具体技能或载体？** | 表现形态 |
| **过去我已经留下了什么？** | 现有资产 |
| **什么仍然只存在我本人身上？** | 资产缺口 |
| **未来 90 天最值得资产化什么？** | 下一实验 |

最后写出：

> **我似乎长期能够通过 ______，让 ______ 从 ______ 变成 ______；接下来我要把这种作用力训练、验证并保存下来。**

注意：这不是个人定位，也不是终极母体宣言。

它只是下一轮现实验证的资产建设假设。

# 13. 五句皇冠｜全课只反复这五句

> **① 资产，是被保存下来的过去，能够继续为未来做功。**

> **② 能力回答“我会什么”；原力回答“因为我在，什么会变得不一样”。**

> **③ 母体是源，原力是力，能力与作品是形，资产是留。**

> **④ 真正的原力资产，不是你做过什么，而是你做完以后，那个只有你容易产生的价值没有消失。**

> **⑤ 真正的复利，是昨天开始参加今天的生产。**

最终皇冠：

> # **把只有你能持续产生的作用力，变成即使今天结束，明天仍能继续做功的资产。**
