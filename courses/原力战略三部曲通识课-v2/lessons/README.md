## 五课路由语义

### L01｜原力战略

只建立：

> 世界变了，我到底应该经营什么？

不深讲十二模块。

### L02｜原力创业

只建立：

> 见 → 名 → 繁 → 守。

B4严格保持虚、实、入、出四壁垒。

### L03｜原力资产

只建立：

> 找 → 归 → 炼 → 证。

母体只产生候选假设，不宣布终极真我。

### L04｜原力 OS

只建立：

> 懂 → 记 → 判 → 行 → 强。

其中“强”是递归结果，不是C5；OS不是技术栈。

### L05｜原力人生

只建立：

> 守 → 生 → 事 → 人 → 留。

它是整合课，不是第四部、不是第十三模块。

## 历史单堂稿法权

`00-原力战略三部曲-秘密与一万倍.md` 继续保留，用于：

- 历史对照；

## 正典边界

课程路由不改变 Soul 正典：

```text
A 原力资产 → B 原力创业 → C 原力 OS
```

五课是教学实例，不是新的本体结构。
