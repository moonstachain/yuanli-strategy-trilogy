# lessons｜课程路由

本目录存放《原力战略三部曲通识课 v2》的具体授课实例。

## 当前默认结构

```text
01 原力战略
→ 02 原力创业
→ 03 原力资产
→ 04 原力 OS
→ 05 原力人生
```

当前只有第一课完成 `content_draft`；02—05 仍为 `planned`。

## 文件路由

| 文件 | 角色 | 当前状态 | 默认使用 |
|---|---|---|---|
| `01-原力战略-AI时代的新财富.md` | 五课版第一课正式候选 | content_draft | **YES** |
| `00-原力战略三部曲-秘密与一万倍.md` | 历史120分钟单堂候选 | legacy_single_session_candidate | NO |

## 历史单堂稿法权

`00-原力战略三部曲-秘密与一万倍.md` 继续保留，用于：

- 历史对照；
- 内容回收；
- 单堂版 vs 五课版的桌面 / 真实试讲比较。

它不再代表当前 v2 默认授课顺序，也不得因为文件编号为 `00` 获得更高课程法权。

## 正典边界

课程路由不改变 Soul 正典：

```text
A 原力资产 → B 原力创业 → C 原力 OS
```

五课是教学实例，不是新的本体结构；“原力人生”不是第四部或第十三模块。
