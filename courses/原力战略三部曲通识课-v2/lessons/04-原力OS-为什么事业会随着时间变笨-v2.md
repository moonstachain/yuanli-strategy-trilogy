# 0. 这节课不讲什么

不从 AI Agent、知识库、自动化、数据库、工作流开始。

因为这些都是 HOW。

本课从一个更简单的问题开始：

> # **为什么很多人经营十年，却像把同一年重复了十遍？**

很多公司资料越来越多、员工越来越多、系统越来越复杂，却同时发生：

```text
新人不知道老人为什么这样做
老人记不清当年为什么这样决定
同样的问题换一批人重新踩坑
创始人一不在，关键判断就停
流程越来越完整，却越来越不像最初想做的事
AI越来越能干，却可能越来越高效地跑偏
```

这就是本课的起点：

> # **时间不会自动带来复利。时间的默认方向，常常是熵增。**

---

# 1. 一事开天｜十年实验
## 0—12 分钟

让学员想象两家公司。

A 公司经营 10 年：

```text
每年都遇到客户问题
每年都做项目
每年都开复盘会
每年都招新人
```

但每一次任务结束后：

```text
经验留在人脑里
结论留在群聊里
判断留在老板脑子里
失败留在情绪里
下一次又重新开始
```

B 公司也经营 10 年，但每一次真实结果都会留下三样东西：

```text
什么是真的
什么判断有效/无效
下一次什么应该提前改变
```

问：

> **十年以后，哪家公司真正拥有了十年的时间？**

第一记钉子：

> # **年龄不是复利；经历被继承，才开始有复利。**

---

# 2. 为什么事业会随时间变笨
## 12—22 分钟

时间至少制造七种损耗：

1. **遗忘**：人记不住全部因果；
2. **流失**：人离开，经验一起离开；
3. **失真**：结论流传，证据消失；
4. **漂移**：今天的效率慢慢覆盖最初的价值边界；
5. **僵化**：过去有效的规则变成今天不可质疑的 SOP；
6. **复杂化**：系统越大，任何个体越难掌握全局；
7. **重复犯错**：任务完成了，但没有改变下一次任务的起点。

所以：

```text
时间 + 经营 ≠ 复利
```

甚至常常是：

```text
时间 + 无继承经营 = 熵增
```

第二记钉子：

> # **原力 OS 对抗的不是“效率低”，而是时间把一个事业慢慢弄丢、弄忘、弄僵、弄笨。**

---

# 3. 第一性矛盾｜既要还是自己，又要已经不同
## 22—32 分钟

一个活着的事业必须同时完成两个看似矛盾的任务：

```text
Continuity × Adaptation
连续性 × 适应性
```

### 只有连续性

什么都不改：

> 会死于僵化。

### 只有适应性

什么都随市场、数据、AI 改：

> 会死于失去自己。

所以原力 OS 的第一性问题是：

> # **什么必须守住？什么必须改变？谁有权改变？凭什么改变？改变以后如何知道发生了什么？**

这时才给出一个极简定义：

> **原力 OS，是让一个事业在变化世界里既保持自己，又能依据现实持续进化的系统。**

---

# 4. 四个不可少的问题｜守 · 知 · 择 · 变
## 32—52 分钟

先不讲四个产品名，只讲四个问题。

## 守｜什么不能随便变？

任何系统都需要不变量：

```text
我是谁
为什么存在
什么不能牺牲
什么质量不接受
谁有权做什么决定
```

否则 AI 越强，跑偏越快。

对应：

> **C1 一纸文脉｜Normative State**

---

## 知｜什么是真的？

系统必须知道：

```text
我们真正知道什么
凭什么相信
过去发生过什么
哪些证据相互冲突
哪些结论已经过期
哪些仍然未知
```

否则“记得很多”只是更大的幻觉。

对应：

> **C2 一个大脑｜Epistemic State**

---

## 择｜什么最值得改变？

知道很多仍不等于会做决定。

注意力、时间、钱、组织能力永远有限，所以必须选择：

```text
什么最重要
哪里是瓶颈
现在押什么
什么不做
什么时候停止
```

对应：

> **C3 一张地图｜Policy State**

---

## 变｜变了以后发生什么？

判断如果没有进入现实，只是漂亮理论。

必须继续问：

```text
谁真的做了
做了什么
现实发生了什么
结果与行动有什么关系
我们学到了什么
下一次会不会因此不同
```

对应：

> **C4 一条链路｜Reality State**

四句合起来：

> # **守住自己，看清世界，选择关键，接受结果。然后，再来一次。**

---

# 5. 原力 OS 的原子不是文档，而是一次状态迁移
## 52—62 分钟

很多公司会这样衡量数字化：

```text
有多少文档
有多少 SOP
接了多少 AI
自动化了多少流程
```

这些都可能有用，但都不是 OS 最终的价值。

真正的问题是：

> **经历一件真实事情以后，这家公司有没有变得更会处理下一件事？**

画出：

```text
State_t
+ Context / Evidence
→ Decision
→ Action
→ Outcome
→ Learning
→ Validated Delta
→ State_t+1
```

解释：

> `State_t+1` 不是“文件变多”，而是下一次真正的判断或行动起点改变了。

第三记钉子：

> # **真正的 OS 升级，不发生在版本号上，而发生在下一次行为里。**

---

# 6. 为什么 Output、Action、Outcome、Learning 必须分开
## 62—72 分钟

给一个简单例子：

AI 写出一份“客户流失诊断报告”。

问：

```text
报告写出来了吗？     是 → Output
有人照着做了吗？     未必 → Action
客户流失变了吗？     未知 → Outcome
为什么变/没变？      未知 → Attribution
下次规则改变了吗？   未知 → Learning
下一次真的用了？     未知 → Reuse
```

因此：

```text
Output ≠ Action
Action ≠ Outcome
Outcome ≠ Learning
Learning ≠ Reuse
```

这不是治理洁癖，而是对现实诚实。

> **如果系统把“写完了”当“发生了”，它会越来越自信，却不一定越来越聪明。**

---

# 7. 时间什么时候第一次产生复利
## 72—80 分钟

第一次任务得到一条 Learning，还不能宣称复利。

真正的复利发生在：

```text
Task1
→ ACT
→ OUT
→ LRN
→ WAIT
→ 独立真实 Task2
→ 决策之前 Preload
→ Applicability Match
→ 改变 DEC / WPK / ACT
→ REUSED
```

因此：

> # **复利不是重复，而是带着上一次真实学习进入下一次重复。**

以及：

> # **知识被找到不算复用，知识改变未来行为才算复用。**

---

# 8. 为什么 C1 慢、C4 快
## 80—84 分钟

如果所有东西都同速变化，系统不是僵化，就是漂移。

所以：

```text
C1｜身份/长期承诺/边界     最慢
C2｜事实/证据/记忆         较快
C3｜策略/优先级/控制点     中速
C4｜任务/实验/行动         最快
```

课堂钩子：

> # **稳定的内核，快速的边缘。**

`Slow Core + Fast Edge` 让一个事业既还是自己，又能不断适应现实。

---

# 9. 一念照我｜我的原力 OS 状态迁移
## 84—89 分钟

围绕一个真实问题填写：

1. **守**：这次无论如何不能牺牲什么？
2. **知**：我现在真正知道什么？最大 Unknown 是什么？
3. **择**：目前 Top 1 控制点是什么？什么不做？
4. **变**：下一现实 Action 是什么？Outcome 怎么看？
5. **学**：什么结果会让我改变原判断？
6. **复**：未来哪类 Task2 应在决策前调用这条学习？
7. **冻**：在得到真实结果前，我明确不继续建设什么？

个人裁决一：

> **你事业里最贵的哪个判断，今天仍然只存在你脑子里？**

个人裁决二：

> **过去一年发生过什么，本来应该让今天少犯一次错，却没有进入今天的判断？**

老师说：

>
> 它知道什么不能变，知道什么是真的，知道现在押什么，也能从现实里学习。
>
> 它甚至会越来越强。

> **可如果它变强以后，放大的恰好是你根本不想过的一生呢？**

# 11. 本课皇冠句

只反复四句：

1. **时间不会自动产生复利。**
2. **原力 OS 的任务，是让一个事业既不丢掉自己，又能因现实持续改变。**
3. **真正的 OS 升级，不发生在版本号上，而发生在下一次行为里。**
4. **复利不是重复，而是带着学习进入下一次重复。**

最终皇冠：

> # **原力 OS，不是帮助一个事业做更多事情，而是帮助一个主体穿越时间：该守的守住，该变的因现实而变，并让每一次变化成为下一次更高的起点。**
