# 8｜课末闭环检查

- [ ] 我只选了一个本人单点故障
- [ ] C1写的是稳定原则，不是阶段目标
- [ ] C2至少有一个可信事实和一个 Unknown
- [ ] C3只选一个 Top 1，并有 Stop Condition
- [ ] C4有 Owner / Human Gate / Evidence / Outcome
- [ ] 我写出了 Learning 的回写位置
- [ ] 我写出了第二次真实复用
- [ ] 我没有把 Prompt / RAG / Dashboard / Automation 当成 C1—C4 本身
- [ ] 我没有把“每次变强”新增为 C5

```yaml
os_hypothesis: candidate
single_point_dependency: identified
c1_constraints: draft
c2_evidence: partial
c3_decision: candidate
c4_action: not_run
outcome: not_observed
reuse: not_run
```
