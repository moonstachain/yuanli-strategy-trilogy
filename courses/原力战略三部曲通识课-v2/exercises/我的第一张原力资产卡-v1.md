# 一、先记住三句话

> **资产，是被保存下来的过去，能够继续为未来做功。**

> **能力回答“我会什么”；原力回答“因为我在，什么会变得不一样”。**

> **母体是源，原力是力，能力与作品是形，资产是留。**

# 三、五道资产门

对你准备资产化的对象逐项判断：

| 门 | 问题 | YES / NO / UNKNOWN | 证据 |
|---|---|---|---|
| **还在吗？** | 任务结束以后，它是否仍存在？ |  |  |
| **叫得动吗？** | 下一次是否能够重新调用？ |  |  |
| **有效吗？** | 是否有真实结果证明它能产生价值？ |  |  |
| **带得走吗？** | 换场景、产品或平台以后是否仍有作用？ |  |  |
| **会变强吗？** | 下一次使用能否在本次基础上继续升级？ |  |  |

任何 UNKNOWN 都保留，不用硬凑成 YES。
