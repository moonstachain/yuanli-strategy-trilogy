# Part A｜课堂 Live Core｜10—12min

只填 `1 + 1 + 1 + 1 + 一句话`。

## A｜正在变便宜｜1项

> **AI 正在把我的哪一项能力逐渐基础设施化？**

```text
我过去依赖的一项能力：

AI / 自动化怎样改变它的供给：
```

边界：正在变便宜 ≠ 没有价值。

---

## B｜正在升值｜1项

> **AI 越强以后，我身上哪一种非平均价值反而更值得训练？**

只能写一个，并给一个真实场景。

```text
非平均价值候选：

它曾在哪个真实场景出现：
```

可参考：问题定义、判断、品味、用户理解、跨域连接、信任、责任承担。

禁止只写：

```text
认真 / 坚持 / 善良 / 学习能力强 / INTJ / 有资源
```

> **即使短期回报下降，你仍愿意继续验证哪个人群 / 问题至少一年？为什么？**

```text
我愿意继续验证的人群：

我愿意继续验证的问题：

至少一年仍值得验证，因为：
```

强制边界：

> **Value Candidate 是下一阶段值得验证的方向，不是唯一使命。它可以被现实修订、缩小、放弃或重写。**

## E｜我的 Value Candidate｜一句话

只写一句：

> **如果平均能力继续变便宜，我希望世界仍然因为我的 __________，来找我解决 __________；下一年我愿意用现实结果验证它。**

然后做三个自检：

- [ ] 这不是一个赛道 / 风口名称；
- [ ] 这不是一个人格或技能标签；
- [ ] 这不是“我一生唯一使命”。

如果三个都勾不上，重写。

# Part B｜机会 vs 秘密｜30秒自检

```text
机会：外部窗口，很多人可能同时看见。
秘密：我对窗口形成、愿意交给现实验证的非平均判断。
```

我的 Value Candidate 如果只是：

> “AI教育很有机会 / 银发经济是风口 / 做个人IP很赚钱”

则还只是机会，不是秘密候选。

继续补一句：

> **我对这个机会的非平均判断是：________________。**

它未来必须回答：

1. 为什么我更容易持续看见？
2. 我看见的到底是哪一个贵问题？
3. 现实准备怎么推翻我？
