# G3｜五课工具链交接协议

```yaml
status: active_candidate
same_object_across_lessons: required
canon_effect: none
live_trial_required: true
```

> 五张工具不是五份独立作业，而是同一条 `VALUE THREAD` 的五次加工。

---

# 1. 唯一对象

学员在 L01 选择一个当前最值得验证的独特价值/秘密候选，并给它一个临时编号：

```yaml
VALUE_THREAD_ID: __________
```

除非现实证据证明对象无效，否则 L02—L05 不允许随意换新点子。

---

# 2. 五课交接

## L01 → L02

《我的原力战略起点图 v1》最低输出：

- VALUE_THREAD_ID；
- 一个独特价值/秘密候选；
- 当前主断点：生成 / 选择 / 保留；
- 30天可证伪动作。

L02 必须沿用同一对象。

## L02 → L03

《我的原力秘密四步卡 v1》最低输出：

- 时代变化；
- 用户贵问题；
- 新分类/比较方式；
- 最小复制路径；
- 当前控制权缺口；
- 至少一条真实世界选择证据。

交给 L03 的唯一问题：

> **这个已经被世界看见/选择的价值，做完以后到底留下了什么？**

## L03 → L04

《我的第一张原力资产卡 v1》课堂最低输出：

1. 差异作用：我总在把什么从 A 推到 B；
2. 一条真实 Outcome + 一条反证/替代解释；
3. 一个当前已留下的资产；
4. 一个最大本人单点依赖；
5. 一个90天资产化实验。

交给 L04 的唯一输入：

> **如果我不在现场，哪一种最高价值判断/方法/关系/行动能力会立刻停止？**

## L04 → L05

《我的原力 OS 一页架构 v1》最低输出：

- 同一个本人单点任务；
- C1 边界；
- C2 证据；
- C3 Top1 + Stop Condition；
- C4 Owner + Action + Outcome + Learning/Reuse；
- `AMPLIFICATION_TARGET`：系统正在持续放大的究竟是什么。

交给 L05：

> **这个 AMPLIFICATION_TARGET 值得我放大十年吗？**

## L05 → 毕业产物

《我的原力人生一页纸 v1》最低输出：

- 一条不可交换边界；
- 一种长期生成动作；
- 一个愿意长期承担的问题；
- 一组关键同行者；
- 一个值得留下的对象；
- 未来90天方向裁决。

五课最终合并：

> **《我的原力战略 1.0》**

---

# 3. 换对象规则

允许更换 VALUE_THREAD 的唯一原因：

- 前一课出现明确反证；
- 世界选择证据为零且假设被否定；
- 价值方向触碰 L05 不可交换边界；
- 学员明确记录“旧对象为何被淘汰”。

若无理由换对象：

```yaml
artifact_chainability: FAIL
```

---

# 4. L03 课堂最小完成协议

新版资产卡有八格，但 7 分钟核心段不要求八格全部完整。

课堂 P0 必填：

```text
格2｜我总想把什么从 A 推到 B
格4｜至少一条真实证据 + 一条反证/替代解释
格7｜最大本人单点依赖
格8｜90天最值得资产化什么
最终一句话｜Force Asset Hypothesis v0.1
```

格1/3/5/6 允许课堂只写关键词，扩展段或课后补全。

五道资产门属于审计 checklist，不要求闭卷背诵。

学生主记忆只有：

> **源 → 力 → 形 → 留**

`找源→归源→炼力→证力` 作为 A1—A4 导航，不与主记忆竞争。
