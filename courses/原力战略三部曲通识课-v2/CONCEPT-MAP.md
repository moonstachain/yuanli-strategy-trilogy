# 3. 本课程采用的教学压缩

这些表达只用于认知压缩，不替换正典模块名。

```text
A轴：找 → 归 → 炼 → 证
B轴：见 → 名 → 繁 → 守
C轴：懂 → 记 → 判 → 行 → 强
```

其中：

> **强 = Outcome → Learning → Reuse 的递归结果，不是 C5。**

课程允许调用的教学总脊柱：

> **源 → 力 → 势 → 名 → 繁 → 守 → 文 → 脑 → 图 → 链 → 回源**

该脊柱的法权来自 Soul Concept System，不是 A1-C4 的替代结构。
