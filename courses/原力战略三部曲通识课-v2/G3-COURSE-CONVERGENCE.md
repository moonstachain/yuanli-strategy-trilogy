# 2. 五课教学顺序重新裁决

## 2.1 保留默认前台顺序

```text
L01 原力战略｜看懂新世界
→ L02 原力创业｜价值进入世界
→ L03 原力资产｜价值被保存
→ L04 原力 OS｜价值被继承
→ L05 原力人生｜价值被定向
```

后台正典仍然：

```text
A 原力资产 → B 原力创业 → C 原力 OS
```

前后台顺序不同，但不冲突：

- 正典回答因果结构；
- 课程回答最适合小白企业家的认知进入顺序。

## 2.2 为什么 G3 不把 A 提前到 B 前面

G3 同时比较了 challenger：

```text
L01 战略 → L02 资产 → L03 创业 → L04 OS → L05 人生
```

桌面判断：暂不升为默认。

原因：

### A. 动机张力

企业家更容易先从“财富怎样发生”进入，而不是先进入自我生成结构。

### B. 世界验证依赖

新版 L03 的关键反转是：

> **世界验证 ≠ 资产形成。**

先学 L02，学员已经知道“世界如何选择价值”，L03 才能进一步理解“被选择以后仍可能没有留下资产”。

### C. A4 更容易理解

A4 显化原力需要真实对象、行为、付费、Outcome 等现实选择环境；L02 已提供前置语境。

### D. 叙事危机更强

```text
我学会了创造财富
↓
但为什么我每次仍要重新亲自创造？
↓
我过去真正留下了什么？
```

比“先找自己，再学创业”更符合当前目标学员的现实痛点。

## 2.3 Challenger 的位置

`战略→资产→创业→OS→人生` 不删除，保留为未来顺序 A/B challenger。

但在第一轮 3—8 人真人验证完成前：

# 4. 五幕课程合同

## 第一幕｜重估｜L01 原力战略

母问题：

> **AI 把平均能力变便宜以后，什么反而会变贵？**

唯一新判断：

> **不要只经营“我会什么”，要经营“什么只有我更容易持续生成并值得被放大”。**

成功后制造危机：

> **就算你真的看见了一个秘密，它凭什么会变成财富？**

交给 L02：`价值候选 / 主断点 / 30天可证伪实验`。

---

## 第二幕｜入世｜L02 原力创业

母问题：

> **一个私人价值真相，怎样变成世界愿意选择的财富？**

唯一新判断：

> **价值必须经历见、名、繁、守，才能从私人判断进入财富结构。**

成功后制造危机：

> **你已经知道怎样把价值变成财富。但每一次做完以后，真正有多少东西留下来了？**

不再以“为什么偏偏是你？”作为默认悬念。

交给 L03：同一个 `SECRET/VALUE CANDIDATE`，以及它已经获得的世界选择证据。

---

## 第三幕｜留存｜L03 原力资产

母问题：

> # **你忙了十年，到底留下了什么？**

唯一新判断：

> **做成很多不等于拥有很多；只有被保存、未来仍能做功的原力，才开始成为资产。**

内部主线：

```text
资产 WHY
→ 原力 WHAT
→ 源 / 力 / 形 / 留
→ A1—A4
→ 世界验证 ≠ 资产形成
→ 五道资产门
```

成功后制造危机：

> **假设最值钱的判断、方法、关系和手感已经被你识别出来，但只要你不在，它们就停止工作——这真的是成熟资产吗？**

交给 L04：唯一一个 `FOUNDER_SINGLE_POINT_DEPENDENCY`。

---

## 第四幕｜继承｜L04 原力 OS

母问题：

> **怎样让原本只有你本人能调用的高质量判断，被事业和 AI 在边界内正确继承？**

唯一新判断：

> **真正的规模，不是创始人能做多少，而是多少高质量判断已经离开创始人仍能正确发生。**

成功后制造危机：

> **如果一套系统已经能把你的判断复制一万倍，那么一个更危险的问题来了：你确定现在放进去的方向值得被复制一万倍吗？**

交给 L05：`AMPLIFICATION_TARGET`——当前系统正在持续放大的那个价值与方向。

---

## 第五幕｜定向｜L05 原力人生

母问题：

> **什么值得被你持续复制、持续建设、持续留下？**

唯一新判断：

> **复利不是天然善；方向永远先于放大。**

五课最终回收：

```text
成功 = 做成
财富 = 被世界选择并留下价值
资产 = 被保存、未来仍能做功
OS = 让价值被继承并继续升级
人生 = 决定这些复利最终去哪里
```

最终产物：

> **《我的原力战略 1.0》**

```text

“做完以后，什么真正留下？”

L03 → L04
```

# 6. 五课工具链｜同一对象原则

G3 新增最高工具纪律：

> # **五课不能每节重新想一个例子。必须围绕同一条 VALUE THREAD 连续加工。**

统一对象字段：

```yaml
VALUE_THREAD_ID: learner_defined
same_object_across_lessons: required
```

交接：

```text
L01 起点图
输出：一个最值得验证的独特价值/秘密候选
↓
L02 秘密四步卡
输出：它如何被世界选择，以及当前最弱一关
↓
L03 原力资产卡
输出：它背后的差异作用力、已经留下什么、仍有哪些本人单点依赖
↓
L04 OS 一页架构
输出：让其中一个本人单点判断第一次被系统继承
↓
L05 人生一页纸
输出：裁决这条价值是否值得长期复利，以及未来90天方向
↓
《我的原力战略 1.0》
```

若学员在 L02/L03/L04 任意一课无理由换对象：


# 7. L03 G3 Desktop Regression 裁决

新版 L03 因结构级重写，旧 `PASS_DESKTOP` 不再自动继承。

旧状态应解释为：

```yaml
old_l03_desktop_pass: historical_pass
current_l03_effect: stale_by_rewrite
```

G3 已重新运行独立桌面回归，结果记录于：

> `trials/08-l03-g3-desktop-regression/RESULT-v1.md`

主要发现：

1. **概念链成立**：资产 WHY → 原力 WHAT → 源力形留 → A1—A4 → 资产门；
2. **最大 P0 是工具过载**：7 分钟不能要求完整填写八格；
3. **记忆层级需收敛**：`源→力→形→留` 是学生主记忆；`找源→归源→炼力→证力` 是 A1—A4 导航；五道资产门是审计工具，不再形成第三套背诵；
4. **L02→L03 悬念必须更新**：从“为什么偏偏是你？”切换为“做完以后，什么真正留下？”；
5. **L03→L04 交接成立**：资产卡第7格的本人单点依赖可直接成为 OS 输入。

采用 G3 最小完成协议后：

