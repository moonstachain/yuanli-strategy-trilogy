# 原力战略三部曲通识课 2.0 · PPT蓝图

> 目标：用最少页面完成“被击中 → 看见财富 → 看见自己 → 看见OS终局 → 形成行动”。

建议 28 页，不把十二模块做成十二页知识点。

## A. 序幕｜AI重新定价人的价值

1. 封面：找到只有你能发现的秘密，把它复制一万倍
2. 如果AI把你会做的80%都变便宜，你还剩什么？
3. 前测四问：什么仍会属于你？
4. 会做事变便宜，发现什么值得做变贵

## B. 第一幕｜财富怎么创造？

5. 新财富 = 秘密 × 一万倍
6. “秘密”不是什么：内幕 / 信息差 / 小聪明 / 短期套利
7. 原力秘密：独特生成源 × 变化时代 × 用户贵问题
8. B1｜见：旧世界哪个共识正在失效？
9. 四类时代裂缝：技术 / 用户 / 成本 / 语言
10. B2｜名：这个秘密到底叫什么？
11. 从模糊痛苦到问题、品类、标准、预算账户
12. 微练习：秘密候选 v0.1
13. B3｜繁：本人 → 方法 → 产品 → 团队 → AI → 网络
14. B4｜守：虚 / 实 / 入 / 出四种控制权
15. 一万倍 = 空间繁殖 × 时间复利
16. 第一幕转场：为什么偏偏有些人总能更早看见？

## C. 第二幕｜为什么偏偏是你？

17. 原力母体：不是“我会什么”，而是“什么持续生成我”
18. 一棵树：母体 → 能力 → 职业 / 产品 → 市场 → 结果
19. 四条线索：长期注意 / 重复判断 / 品味 / 长期承诺
20. A1—A4：找源 → 归源 → 炼源 → 证源
21. 微练习：我的秘密为什么可能属于我？

## D. 第三幕｜怎样让它不再依赖你？

22. 可是你只有一颗脑、两只手、24小时
23. 创始人瓶颈：越独特，越可能越依赖本人
24. C1—C4：懂你 / 记住 / 判断 / 行动与回写
25. 真正的一万倍：让判断进入产品、团队、关系、AI与时间

## E. 全景与行动

26. 完整十二模块：前台B→A→C，后台A→B→C
27. 《我的原力三部曲起点图 v3》八格
28. 结尾：找到你的原力｜发现你的秘密｜让它自我繁殖

## 视觉原则

- 每页只承担一个心智动作；
