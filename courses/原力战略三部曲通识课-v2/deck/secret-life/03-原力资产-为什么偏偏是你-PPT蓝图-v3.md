## 01｜如果一切归零

黑屏，大字：

> **如果明天，你现在最值钱的东西全部失效？**

下方极小字：行业 / 流量 / 职位 / 产品 / 客户 / 技能。

## 02｜你还能重新长出来吗？

单句：

> **真正高级的资产，不是不贬值，而是贬值以后还能重新长出来。**

视觉：被砍掉枝叶但重新发芽的树根结构，避免励志海报感。

## 03｜职业只是一个版本

中间：

`职业 / 产品 / 技能 / 公司 = 表型`

下方：

> **它们解释“现在长出了什么”，不解释“为什么会长出来”。**

## 04｜能力是果实

只显示：

# **能力是果实，不是根。**

## 05｜Generator ≠ Capability

左右对照：

```text
Capability
现在会什么

Generator
为什么不同能力反复长出来
```

## 06｜三个完全不同的人生切片

三列：A / B / C。

只放：场景、年份、角色占位；不提前给答案。

## 07｜删掉行业以后，什么没变？

三条链：

```text
异常 → 判断 → 转化 → 价值
异常 → 判断 → 转化 → 价值
异常 → 判断 → 转化 → 价值
```

共同部分高亮为：`同构痕迹`。
