# 二、全课唯一母图

必须把第12页做成全课视觉锚点：

```text
过去的生命经历
长期注意 / 重复判断 / 品味 / 承诺
              ↓
        【原力母体｜源】
              ↓
          【原力｜力】
              ↓
判断 / 能力 / 方法 / 作品 / 关系
          【表型｜形】
              ↓
       真实世界验证
              ↓
保存 / 调用 / 复用 / 升级
              ↓
        【原力资产｜留】
```

页脚必须注明：

> `源→力→形→留` 为教学解释，不替换 A1—A4 正典。

# 三、A1—A4 展示纪律

四页必须分别使用正典名 + 教学动作双标：

```text
A1 发现母体｜找源
A2 回到母体｜归源
A3 获得原力｜炼力
A4 显化原力｜证力
```

禁止只写“找源/归源/炼力/证力”而隐藏正典名。

A1 必须出现：

- Mother Hypothesis；
- 反证；
- 替代解释。

A2 必须出现：

- 去掉职位/公司/平台/成功；
- 加减停拒；
- 真实机会成本。

A3 必须出现：

```text
隐性手感 → 显性判断
模糊经验 → 概念/标准
一次高光 → 稳定能力
直觉 → 方法
本人会 → 可调用
```

A4 必须出现：

> **Because of you, what changed?**

并同时显示真实任务、真实对象、真实行为与 Outcome。

# 四、五道资产门必须单独一页

第22页不要堆资产类别，只问五个问题：

1. **还在吗？**——任务结束后是否仍存在？
2. **叫得动吗？**——下一次是否能重新调用？
3. **有效吗？**——是否有真实结果证明价值？
4. **带得走吗？**——换场景/产品/平台还能否作用？
5. **会变强吗？**——下一次能否在本次基础上升级？

视觉建议：五道门 / 五个闸口，而不是五维雷达。

# 五、主工具页

第23页只显示八格：

```text
1 我反复看见什么？
```

最后一句：

> **我似乎长期能够通过 ______，让 ______ 从 ______ 变成 ______；接下来我要把这种作用力训练、验证并保存下来。**

# 六、五个最高传播页

1. **资产，是被保存下来的过去，能够继续为未来做功。**
2. **能力回答“我会什么”；原力回答“因为我在，什么会变得不一样”。**
3. **母体是源，原力是力，能力与作品是形，资产是留。**
4. **真正的原力资产，不是你做过什么，而是你做完以后，那个只有你容易产生的价值没有消失。**
5. **真正的复利，是昨天开始参加今天的生产。**

终极页可用：

> # **把只有你能持续产生的作用力，变成即使今天结束，明天仍能继续做功的资产。**
