# 原力战略三部曲通识课 2.0 · 课程总控

## 一、课程定位

这是一门 120 分钟旗舰通识入口课，不是十二模块压缩课。

唯一任务：完成三次心智跃迁。

```text
财富怎么创造？
↓
为什么偏偏是你？
↓
怎样让财富不再依赖你本人？
```

## 二、超级母句

> **新财富的本质，是找到这个世界上只有你才能发现的一个秘密，并把它复制一万倍。**

后台严谨解释：

> 原力秘密，是一个人的独特生成源，与时代变化和用户贵问题相遇后产生的、尚未成为共识但能够接受现实验证的价值真相。

## 三、前后台双序

### 后台正典

```text
A 原力资产 → B 原力创业 → C 原力 OS
```

这是生成源 → 世界选择 → 系统遗传的因果链，不改变。

### 前台教学

```text
B 原力创业 → A 原力资产 → C 原力 OS
```

这是动机 → 悬念 → 终局的体验链。

## 四、课程三幕

### 第一幕｜原力创业｜财富怎么创造？

```text
秘密前半程：找到秘密
  B1 原力借势 = 见
  B2 品类独创 = 名

秘密后半程：复制一万倍
  B3 模式升维 = 繁
  B4 壁垒锁定 = 守
```

教学压缩：

> **见 → 名 → 繁 → 守**

其中：

- B3 = 空间繁殖；
- B4 = 时间复利；
- 一万倍 = 空间繁殖 × 时间复利。

### 第二幕｜原力资产｜为什么偏偏是你？

```text
A1 发现母体 = 找源
A2 回到母体 = 归源
A3 获得原力 = 炼源
A4 显化原力 = 证源
```

核心判断：

> 母体不是能力清单，而是持续生成独特判断、作品、关系与意义的底层生命结构。

> 母体候选必须经过现实选择，才能逐步成为原力资产。

### 第三幕｜原力 OS｜怎样让它不再依赖你？

```text
C1 一纸文脉 = 懂你
C2 一个大脑 = 记得住
C3 一张地图 = 会判断
C4 一条链路 = 能行动 + 每次变强
```

核心判断：

> AI 的最高价值不是替你多做内容，而是让过去只能由你本人调用的高质量判断，逐渐成为事业可以调用的能力。

## 六、学员离场四果

1. 能解释：AI时代的新财富为什么不是“多赚钱”，而是发现并繁殖独特价值。
2. 能诊断：自己当前卡在“没有秘密 / 源头不清 / 无法复制 / 系统不继承”的哪一层。
3. 有候选：形成一个《原力秘密候选 v0.1》。
4. 有行动：形成一项具成功信号、失败信号、证据与回写位置的 30 天实验。

## 十、Fail-Closed 条件

出现任一情况，v2 不得升级：

- 把 B→A→C 误写成正典因果顺序；
- 把“秘密”讲成内幕、信息差或短期套利；
- 把“只有你才能发现”讲成不可证伪的天命；
- B4 出现四大壁垒以外的新并列壁垒；
- C3 退化为思维导图；
- 没有真实试讲却宣称 reusable；
- 没有 30 天迁移证据却宣称课程形成复利；
- 未经 Human Gate 宣称 v2 supersede v1。
