# 原力战略三部曲通识课 2.0 · 课程总控

## 一、课程定位

这是一门 **1+3+1、五节、每节90分钟** 的旗舰通识课程。

它不是十二模块压缩课，也不是把原120分钟单堂稿机械拆成五段。

认知阶梯：

> **1 个母概念 → 3 次事业跃迁 → 1 次人生升维。**

总问题：

> # **AI时代，怎样把一个独特生命，活成一个会复利的事业与人生？**

> **世界 → 财富 → 自我与资产 → 时间 → 方向。**

# 三、超级母句

> # **新财富的本质，是找到这个世界上只有你才能发现的一个秘密，并把它复制一万倍。**

后台解释：

> 原力秘密，是一个人的独特生成源，与时代变化和用户贵问题相遇后产生的、尚未成为共识但能够接受现实验证的价值真相。

> 一万倍，是让原本只能在本人身上发生一次的高质量价值，跨人、跨产品、跨组织、跨 AI、跨时间持续发生。

# 四、前后台双序

## 后台正典

```text
A 原力资产 → B 原力创业 → C 原力 OS
```

这是：

> 独特生成 → 现实选择 → 系统保留 → 递归再生成。

正典因果顺序不改变。

## 前台课程

```text
原力战略
→ B 原力创业
→ A 原力资产
→ C 原力 OS
→ 原力人生
```

这是：

> 世界观 → 财富动机 → 主体与资产回归 → 系统继承 → 人生整合。

“原力人生”是整合课，不是第四部，不是第十三模块。

## L03｜原力资产

新版标题：

> # **《你忙了十年，到底留下了什么？》**

唯一认知迁移：

> **从“我有很多能力和经历”，迁移到“我正在把只有我容易持续产生的作用力，建设成未来仍会做功的资产”。**

60分钟最低可运行核心：

| 时间 | 幕 | 教学任务 |
|---|---|---|
| 0—7 | 你忙了十年，到底留下了什么？ | 从成功/收入切换到资产 |
| 7—15 | 耗散人生 vs 复利人生 | 建立“过去参加未来生产” |
| 15—23 | 能力≠原力 | 从“我会什么”到“我让什么改变” |
| 23—30 | 源→力→形→留 | 区分母体、原力、表型、资产 |
| 30—44 | 找源—归源—炼力—证力 | 把 A1—A4 看成资产生成链 |
| 44—50 | 世界验证≠资产形成 | 通过五道资产门 |
| 50—57 | 第一张原力资产卡 | 形成90天资产化假设 |
| 57—60 | 悬念 | 推向原力 OS |

30分钟旗舰深化：

| 时间 | 幕 | 教学任务 |
|---|---|---|
| 60—68 | 结果未资产化案例 | 看见高成果背后的耗散 |
| 68—76 | 跨载体原力练习 | 检验同一差异作用能否迁移 |
| 76—83 | 五道资产门互审 | 还在/叫得动/有效/带得走/会变强 |
| 83—88 | 90天资产化实验 | 明确一个最值得保存的原力作用 |
| 88—90 | 悬念与闭卷 | 创始人单点依赖 → L04 |

课堂资产定义：

> **资产，是被保存下来的过去，能够继续为未来做功。**

课堂原力定义候选：

> **原力，是原力母体经过训练后，在真实任务中能够被主动调用，并持续产生非平均判断、行动与结果的差异作用力。**

课堂总钩子：

> **母体是源，原力是力，能力与作品是形，资产是留。**

A轴治理：

```text
找源｜A1 发现母体
归源｜A2 回到母体
炼力｜A3 获得原力
证力｜A4 显化原力
```

资产门：

```text
还在吗？
叫得动吗？
有效吗？
带得走吗？
会变强吗？
```

最小定义：

> **原力资产，是被保存下来的原力。**

最终皇冠：

> **把只有你能持续产生的作用力，变成即使今天结束，明天仍能继续做功的资产。**

治理：

> **A1只产生候选，不宣布终极真我；“源→力→形→留”只属于教学解释；世界验证不自动等于资产形成；用户本人不是资产。**

# 八、五课教学纪律

统一原则：

> **一课一念，一念一主图，一课一果。**

禁止：

- 第一课塞十二模块；
- 第二课塞完整康波、58模式与全部B轴工具；
- 第三课把母体讲成天命或人格标签；
- 第三课把原力讲成神秘能量、高能感或一次灵感；
- 第三课把一次成功直接叫资产；
- 第四课讲成GitHub/Agent/知识库工具课；
- 第五课讲成人生八维平衡或使命宣言；
- 任一课程传播语言自动升级 Soul 正典。
