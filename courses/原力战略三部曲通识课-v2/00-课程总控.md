# 原力战略三部曲通识课 2.0 · 课程总控

## 一、课程定位

这是一门 **1+3+1、五节、每节90分钟** 的旗舰通识课程。

它不是十二模块压缩课，也不是把原120分钟单堂稿机械拆成五段。

认知阶梯：

> **1 个母概念 → 3 次事业跃迁 → 1 次人生升维。**

总问题：

> # **AI时代，怎样把一个独特生命，活成一个会复利的事业与人生？**

---

# 二、五课总结构

```text
01 原力战略｜看懂新世界
世界变了：AI时代什么正在被重新定价？
↓
02 原力创业｜创造新财富
秘密怎样被发现、命名、繁殖和守住？
↓
03 原力资产｜找到独特的你
为什么有些秘密偏偏是你更可能看见？
↓
04 原力 OS｜建立会进化的事业
怎样让高质量判断离开本人仍继续工作？
↓
05 原力人生｜决定长期方向
什么才值得被持续复制与留下？
```

五课分别解决：

> **世界 → 财富 → 自我 → 时间 → 方向。**

---

# 三、超级母句

> # **新财富的本质，是找到这个世界上只有你才能发现的一个秘密，并把它复制一万倍。**

后台解释：

> 原力秘密，是一个人的独特生成源，与时代变化和用户贵问题相遇后产生的、尚未成为共识但能够接受现实验证的价值真相。

> 一万倍，是让原本只能在本人身上发生一次的高质量价值，跨人、跨产品、跨组织、跨 AI、跨时间持续发生。

---

# 四、前后台双序

## 后台正典

```text
A 原力资产 → B 原力创业 → C 原力 OS
```

这是：

> 独特生成 → 现实选择 → 系统保留 → 递归再生成。

正典因果顺序不改变。

## 前台课程

```text
原力战略
→ B 原力创业
→ A 原力资产
→ C 原力 OS
→ 原力人生
```

这是：

> 世界观 → 财富动机 → 主体回归 → 系统继承 → 人生整合。

“原力人生”是整合课，不是第四部，不是第十三模块。

# 六、五课90分钟 Run of Show

## L01｜原力战略

| 时间 | 幕 | 教学任务 |
|---|---|---|
| 0—10 | AI清算 | 看见“平均能力”正在被重新定价 |
| 10—25 | 旧财富算法失效 | 击中“能力多但不复利” |
| 25—43 | 原力战略是什么 | 建立“秘密 × 一万倍” |
| 43—58 | 三部曲最低地图 | 只建立我—世界—时间 |
| 58—70 | A/B/C主瓶颈 | 只能选一个 |
| 70—83 | 起点图 | 形成30天可证伪实验 |
| 83—90 | 悬念 | 推向财富发生学 |

三记重锤：

1. **AI首先清算的不是人，而是平均。**
2. **你的问题可能不是能力不够，而是没有完成能力形态的升级。**
3. **新财富的本质，是找到这个世界上只有你才能发现的一个秘密，并把它复制一万倍。**

| 时间 | 幕 | 教学任务 |
|---|---|---|
| 0—8 | 收入≠财富 | 区分交易与可调用价值 |

| 15—31 | 见｜B1 | 发现时代裂缝与贵问题 |
| 31—46 | 名｜B2 | 从旧解释进入新价值和品类 |
| 46—64 | 繁｜B3 | 从本人单点进入空间复制 |
| 64—77 | 守｜B4 | 沉淀虚实入出四种控制权 |
| 77—82 | 四种财富合一 | 时代×心智×空间×时间 |
| 82—87 | 四步卡 | 形成秘密候选 |
| 87—90 | 悬念 | 为什么偏偏是你？ |

核心：

```text
见｜B1｜时代财富

繁｜B3｜空间财富

```

> **虚、实、入、出只有四种控制权；飞轮不是第五壁垒。**
