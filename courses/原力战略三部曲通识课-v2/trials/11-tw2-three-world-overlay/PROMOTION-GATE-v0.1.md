# TW2 Three Worlds｜Promotion Gate v0.1

> status: `NOT_ELIGIBLE_BEFORE_REALITY`

## Promotion is not the current task

TW2 当前任务只是：

```text
Overlay
→ Live Use
→ Evidence
→ Settlement
→ Human Gate
```

任何模板、CI、设计完整度都不能替代真人证据。

## Minimum evidence before Human Gate

至少需要：

1. `REAL_SESSION_OCCURRED`；
2. Three Worlds overlay 在真实课堂中被实际使用；
3. 至少有 L0 自然证据；
4. 能计算或合理估计核心误解信号；
5. 有正反两面的具体学员语言证据。

L1 抽样推荐但不强制；L2 仅在强声明或正式课程 Promotion 时启用。

必须至少同时观察到：

- Three Worlds 帮助学员更快解释三部关系；
- 至少一部分学员能用它定位自己的真实问题；
- 学员能继续落到原力资产 / 原力创业 / 原力OS 或模块；
- 没有明显新增认知负担。
