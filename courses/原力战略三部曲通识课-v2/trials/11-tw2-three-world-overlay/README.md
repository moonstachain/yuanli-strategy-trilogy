## Natural observation points

讲师或观察者优先记录自然发生的语言：

- 学员主动用“源头 / 现实 / 未来”复述；
- 学员能否区分三者；
- 学员是否把自己的问题放进某个世界；
- 学员是否进一步落到原力资产 / 原力创业 / 原力OS 或具体模块；
- 学员是否出现核心误解。

## L1 light validation

只在自然机会下抽样 1–3 人，可问：

1. “如果不用课上的原话，你怎么解释三个世界？”
2. “你现在最卡的是哪个世界？为什么？”
3. “这个问题继续往下，对应原力资产、原力创业还是原力OS？”
4. “源头世界是不是人格测试？现实世界是不是赚钱？未来世界是不是 AI？”
5. “如果明天只能做一件事，你会做什么？”

不要提示正确答案。
