# 3. 各课现场核心验收

## L01｜秘密诞生

闭卷说出：
- 不同 ≠ 正确；
- 正确 ≠ 被选择；
- 被选择一次 ≠ 复利；
- 生成 → 选择 → 保留 → 再生成。

工具：能只圈一个生成/选择/保留主断点。

## L02｜秘密入世

闭卷说出：
- 见 → 名 → 繁 → 守；
- 至少能解释一种“财富”不是现金的含义；
- B4 不多于虚实入出四类。

工具：能用 L01 同一个秘密，不换新点子。

## L03｜秘密寻主

闭卷说出：
- 能力是果实，母体是根；
- A1 只产生 Mother Hypothesis；
- 一个无法被反驳的母体只是好听故事。

工具：有反证 + 真实取舍 + 90天验证。

## L04｜秘密得生

闭卷说出：
- 信息离开我 ≠ 判断离开我；
- 懂 / 记 / 判 / 行 / 强；
- Output ≠ Action ≠ Outcome ≠ Learning。

工具：能围绕一个真实单点任务完成最小控制循环。

## L05｜秘密定向

闭卷说出：
- 复利不是天然善；
- 成功 / 财富 / 人生三个问题不同；
- 守生事人留只是整合问题，不是第四部模块。

工具：能给出至少一个真实不可交换项与现实验证动作。

# 4. 24h Recall｜必须第二天执行

不提供课程材料，先让学员自由回忆。

## Q1｜五幕

> 这五节课如果是一部故事，五幕分别是什么？

目标：
`诞生 → 入世 → 寻主 → 得生 → 定向`

## Q2｜底层机制

> 第一课最底层那条机制是什么？

目标：
`生成 → 选择 → 保留 → 再生成`

## Q3｜一句自己的话

> 现在你怎么解释“秘密 × 一万倍”？

要求：不能只复述口号，必须包含现实验证 / 放大 / 继承 / 方向中的至少两个。

## Q4｜现实动作

> 过去24小时里，哪一个判断或行动已经因为课程发生变化？

记录真实行为，不接受“我想了很多”。

# 5. 概念混淆测试

让学员快速判断：

1. 原力母体 = 我最强的技能。 `FALSE`
2. 一个很赚钱的秘密一定是我的母体。 `FALSE`
3. 收入高就说明已经资产化。 `FALSE`
4. 知识库很全就等于原力OS。 `FALSE`
5. 飞轮是第五种壁垒。 `FALSE`
6. 原力人生是第四部。 `FALSE`
7. 复利一定越多越好。 `FALSE`
8. 世界选择是原力战略不可省略的一环。 `TRUE`

目标正确率：≥ 75%；P0 项（1/4/5/6）必须全部正确。

# 7. 失败后的回写顺序

```text
P0 法权/概念混淆
→ 先改 Canon Alignment / 名称边界

P0 时间/工具做不完
→ 先减内容和字段，不加解释

P1 主故事抓不住
→ 改小切口/异常/两难，不先加更多案例

P1 大纵深掉线
→ 强化主故事回扣，不增加学科数量

P1 追课欲不足
→ 检查上一课成功是否真的制造下一课危机
```
