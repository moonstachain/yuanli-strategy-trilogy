# 4. P0 Required Patches

## P0-01｜工具 10 分钟仍然过满

当前工具要求：

- 3 个跨时期实例；
- 1 个现实选择强证据；
- 1 个反证；
- 保留物清单；
- 最大流失；
- 圈一个断点；
- 离场句。

对第一次接触原力战略的小白，10 分钟内高质量完成概率偏低。

风险：

> **叙事成功，工具失败；学员最后 10 分钟仓促填表，削弱整课高弧光。**

P0 修复：

课堂只强制：

```text
2 个生成实例
+ 1 个现实选择证据
+ 1 个保留物
+ 只圈 1 个断点
```

反证 / 最大流失 / 第 3 个跨时期实例改为课后补全或下一次复盘字段。

验收目标：

```yaml
median_completion_time: <= 8min
required_fields_completion: >= 90%
```

状态：`REQUIRED`
