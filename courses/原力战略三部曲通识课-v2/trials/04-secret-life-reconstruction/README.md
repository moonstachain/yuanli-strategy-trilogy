## 3. Desktop Gate A｜SECRET_THREAD 连续性

逐课检查：

```text
L01 exit_state == L02 entering_state
L02 exit_state == L03 entering_state
L03 exit_state == L04 entering_state
L04 exit_state == L05 entering_state
L05 exit_state == S8递归并回到新异常
```

必须通过：

- 每课开场承接上一课，不重新初始化世界；
- 每课结尾成功制造下一课危机；
- “秘密”始终是同一叙事对象，不突然变成新正典概念；
- 五幕状态变化清晰可复述。

## 4. Desktop Gate B｜四诀完整性

每课必须有：

1. 一事开天：一个旗舰小切口；
2. 一问到底：一个贯穿问题；
3. 一理贯通：一个跨尺度机制；
4. 一念照我：一个人格裁决；
5. 强证据：关键事实有来源状态与边界。

失败条件：

- 开场先讲定义；
- 多案例平铺，没有旗舰主线；
- 跨学科只是知识拼盘；
- 高弧光只剩励志；
- 最后没有回到学员现实。

## 5. Desktop Gate C｜法权与概念漂移

检查：

```text
原力战略 = canonical_concept
原力资产/创业/OS = canonical_concept
原力母体 = canonical_cross_cutting_concept
秘密 × 一万倍 = narrative_device / narrative_object
原力人生 = integration_only
```

必须保持：

- A→B→C 正典因果顺序不变；
- 五课前台顺序仍为 原力战略→B→A→C→人生；
- B4 只有虚/实/入/出四种控制权；
- “强”不是 C5；
- “守生事人留”不是第四部模块。

## 6. Desktop Gate D｜旧资产复用率

目标不是推倒重来。

必须检查现有已核验 Anchor 是否被合理吸收：

- L01：Gutenberg / Deep Blue → 回声案例；
- L02：Nokia / Wii → 见/名回声；
- L03：John Snow / Tu Youyou → 注意/判断回声；

标准：

## 8. Human Live Gate｜真人试讲后才可测

目标学员：专家型创业者 / 小白学员。

至少验证：

### 8.1 24h 记忆

不提示情况下能否复述：

> 诞生 → 入世 → 寻主 → 得生 → 定向

及：

> 生成 → 选择 → 保留 → 再生成

### 8.2 概念不混淆

能否分清：

- 秘密 vs 原力战略；
- 母体 vs 能力；
- 收入 vs 财富；
- 知识库 vs OS；
- 复利 vs 方向。

### 8.3 工具完成质量

五张产物是否比旧版更好，而不是因为故事变长导致工具做不完。

### 8.4 追课欲

每课末尾的 `exit_crisis` 是否真实制造下一课需求。
