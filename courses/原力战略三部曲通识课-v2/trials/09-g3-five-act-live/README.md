# 3. L0｜自然证据｜默认

系统优先从真实教学本身获得证据：

- 课堂自然反应；
- 学员自然提问 / 复述；
- 课后聊天；
- 作业；
- 后续主动引用；
- 真实决策 / 行动中的自然使用。

讲师不需要额外给每位学员编号后完成完整五问。

当前 2026-08-18 这场课已经完成 L0。
