# 4. 各课核心验收

## L01｜重估

闭卷目标：

- AI 使大量平均能力边际成本下降；
- 真正要经营的是更难被平均化、值得被放大的独特价值；
- 能解释“秘密 × 一万倍”不是信息差套利。

Artifact：选出一个 VALUE_THREAD_ID，不要求证明它正确。

自然问题应接近：

> “它怎样变成世界愿意选择的财富？”

## L02｜入世

闭卷目标：

> **见 → 名 → 繁 → 守**

并能说明：

> 价值不被世界选择，就还不是财富结构。

Artifact：沿用 L01 同一 VALUE THREAD；至少形成一条真实世界选择证据或明确 UNKNOWN。

自然问题应接近：

> **“即使做成了，做完以后到底留下什么？”**

## L03｜留存

新版闭卷目标：

1. **资产，是被保存下来的过去，能够继续为未来做功。**
2. **能力回答我会什么；原力回答因为我在，什么会变得不一样。**
3. **母体是源，原力是力，能力/作品是形，资产是留。**
4. 世界验证成功不自动等于资产形成。
5. “留下来”不是复利终点；未来任务中的正确调用仍需 L04 解决。

课堂资产卡最低必须独立完成：

- 差异作用 A→B；
- 1条真实证据；
- 1条反证或替代解释；
- 最大本人单点依赖；
- 90天资产化实验。

不要求八格全部精写。

自然问题应接近：

> **“如果这些东西仍只存在我本人身上，或者过去经验不能进入下一次判断，怎样让它穿过时间继续工作？”**

## L04｜继承

本轮新增第一性 WHY：

> **为什么一个事业会随着时间变笨？怎样让时间从熵增变成复利？**

闭卷目标：

1. OS 不是工具栈，也不是 Agent / 文档 / 自动化数量；
2. 能解释“时间不会自动产生复利”，并至少说出一种时间熵：遗忘、流失、失真、漂移、僵化、复杂化或重复犯错；
3. 能解释 `Continuity × Adaptation`：只有连续性会僵化，只有适应性会漂移；
4. 能把 C1—C4 映射成：

```text
C1 Normative State｜什么不能随便变？
C2 Epistemic State｜什么是真的？
C3 Policy State｜什么最值得改变？
C4 Reality State｜变了以后发生什么？
```

5. 能用“守 / 知 / 择 / 变”复述四问，但知道它只是教学压缩，不是新正典命名；
6. 能区分 `Output ≠ Action ≠ Outcome ≠ Learning ≠ Reuse`；
7. 能解释一次真正 OS 升级应体现为 `State_t → Reality → Learning → State_t+1`；
8. 能说明 Retrieval 不等于 Reuse，Task2 必须在决策前使用 Learning 并实际改变 DEC / WPK / ACT 才开始证明复利。

Artifact：沿用 L03 的同一个 `FOUNDER_SINGLE_POINT_DEPENDENCY`，完成《我的原力OS状态迁移一页纸》最小字段：

```yaml
KEEP: ______
KNOW: ______
CHOOSE: ______
CHANGE_ACT: ______
OUTCOME_WINDOW: ______
LEARNING_TRIGGER: ______
TASK2_CLASS: ______
FREEZE: ______
```

同时必须产生：

```yaml
AMPLIFICATION_TARGET: ______
STATE_T: ______
EXPECTED_STATE_T_PLUS_1: ______
```

自然问题应接近：

> **“如果系统真的会越来越强，这件事值得我让它放大十年吗？”**

## L05｜定向

闭卷目标：

- 复利不是天然善；
- 成功 / 财富 / 人生回答不同问题；
- 至少给出一条真实不可交换边界；
- 能裁决 AMPLIFICATION_TARGET 是否值得长期放大。

最终形成：

> **《我的原力战略 1.0》v0.1**

# 5. 概念混淆测试

课后快速判断：

1. 原力母体就是最强技能。 FALSE
2. 世界愿意付钱就说明完成资产化。 FALSE
3. 用户本人是我的资产。 FALSE
4. 源→力→形→留是新增四个正典模块。 FALSE
5. 知识库很多就等于原力 OS。 FALSE
6. 飞轮是第五种壁垒。 FALSE
7. 原力人生是第四部。 FALSE
8. 复利越多天然越好。 FALSE
9. 世界选择是原力战略不可省略的一环。 TRUE
10. 企业经营得越久，就天然积累得越聪明。 FALSE
11. C1-C4 是“主权/认知/判断/实践”四类新资产。 FALSE
12. Learning 被检索出来，就已经证明 Reuse。 FALSE
13. 一次真实结果若改变下一任务的事前判断，才开始接近复利。 TRUE

P0 项 1/2/4/5/6/7/10/11/12 必须全部正确。

# 6. 24h Recall

第二天不看资料，依次问：

### Q1 五幕

> 五节课如果只剩五个动作，是什么？

目标：

> **重估 → 入世 → 留存 → 继承 → 定向**

### Q2 一条价值生命史

> 用自己的话解释：一个独特价值怎样从“我看见”走到“值得长期复利”？

要求至少覆盖：世界选择、保存/资产化、OS 继承/学习、方向中的三个。

理想结构不强求逐字，但可接近：

```text
Asset_n
→ Venture
→ Reality
→ OS
→ Asset_n+1
```

### Q3 L04 时间问题

> 为什么一家经营十年的公司，可能并没有拥有十年的复利？

可接受答案至少包含：

- 时间存在遗忘/漂移/僵化等损耗；
- 真实结果没有进入 Learning 或下一次任务；
- “做过”不等于“被继承”。

### Q4 L04 State Transition

> 举一个你自己的例子：过去一次真实经历，下一次应该因此怎样不同？

至少应覆盖：

```text
过去 Reality / Outcome
→ 一条 Learning
→ 下一 Task 决策或行动改变
```

### Q5 现实变化

> 过去24小时，哪一个真实判断、拒绝、保存或行动已经变化？

“觉得很有启发”不算行为证据。
