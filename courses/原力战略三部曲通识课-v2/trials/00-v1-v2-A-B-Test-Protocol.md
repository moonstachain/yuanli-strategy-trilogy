# 原力战略三部曲通识课 v1 / v2 对照试讲协议

## 一、目的

不是证明 v2 一定更好，而是比较两种前台叙事是否产生更强的理解、记忆、对号入座和迁移。

```text
v1：A → B → C
找到原力 → 进入世界 → 形成复利

v2：B → A → C
财富怎么创造 → 为什么是你 → 怎样不再依赖你
```

后台正典在两版中都保持 A→B→C，不参与 A/B Test。

## 二、核心假设

H1：v2 能更快建立学习动机。

H2：v2 的“秘密 × 一万倍”比 v1 的抽象总定义更容易在 24 小时后被准确复述。

H3：v2 不会因为传播性增强而显著增加“秘密=内幕 / 天命 / 风口”的误解。

H4：v2 能提高学员完成真实 30 天实验的比例，而不只是提高满意度。

## 三、试讲单位

优先两阶段：

### Phase 1｜桌面试讲

对象：课程设计者 + 2—4 位内部审阅者。

验证：

- 叙事是否断裂；
- 时间是否超载；
- 前台B→A→C是否会误伤后台A→B→C；
- “秘密”是否被错误理解；
- 十二模块是否仍可准确回归。

### Phase 2｜真实课堂

尽量使用相近学员画像、相近人数、相近授课环境。

若无法随机分组，必须在报告中声明 quasi-experiment，不宣称严格因果。

## 四、共同前测

开课前填写：

1. 你认为 AI 时代最稀缺的个人价值是什么？
2. 你能否说清自己事业的独特价值源头？
3. 你现在最大的瓶颈更接近：源头 / 市场 / 复制 / 系统？
4. 如果你停止工作30天，哪些价值会继续增长？

## 五、课堂即时指标

每项 1—5 分：

- 被击中：这讲的是我的问题；
- 分得清：能区分母体、能力、秘密、风口、品类、OS；
- 说得出：能不看材料复述总逻辑；
- 对得上：能找到自己的当前瓶颈；
- 用得起：能完成主工具；
- 认知负荷：是否觉得概念过多 / 结构混乱。

## 六、24小时延迟测试

不看讲义回答：

1. 用一句话讲原力战略三部曲。
2. 三部各解决什么问题？
3. “秘密”不是什么？
4. 为什么教学可以B→A→C，但事业因果仍是A→B→C？
5. 你记得哪一个行动？

## 七、7天迁移

检查：

- 是否重新打开起点图；
- 是否与真实同事 / 用户讨论秘密候选；
- 是否收集新证据或反证；
- 是否改变至少一个取舍；
- 是否开始30天实验。

## 八、30天复利验证

最低要求：

```text
真实对象
+ 真实行动
+ 真实 Outcome 或失败
+ 至少一条 Learning
+ 明确回写
```

课程真正的胜负不以满意度决定，而以：

> **哪一版更容易让学员从“听懂”进入“真实选择与回写”。**

## 九、关键风险监测

v2 必须额外监测四种误解：

- `秘密 = 内幕 / 信息差`
- `只有你 = 天命 / 自恋`
- `一万倍 = 单纯规模 / 流量`
- `B→A→C = 新正典结构`

任一误解显著高于 v1，应触发叙事修正。

## 十、Human Gate

只有同时满足以下条件，才允许提议 `supersedes_v1: true`：

- 桌面试讲通过；
- 至少一轮真实课堂；
- 24小时记忆不劣于v1；
- 核心误解不高于可接受阈值；
- 7天迁移优于或不劣于v1；
- 至少有可审阅的30天行动证据；
- 形成正式 Evolution Note；
- 人工裁决批准。

否则：

```yaml
supersedes_v1: false
```
