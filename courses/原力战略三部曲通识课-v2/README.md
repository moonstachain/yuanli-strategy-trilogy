## 核心裁决

本课程**不修改 Soul 的 A→B→C 正典因果顺序**。

```text
后台正典：
原力资产 A
→ 原力创业 B
→ 原力 OS C

前台教学：
原力创业 B
→ 原力资产 A
→ 原力 OS C
```

原因：通识课首先回答学员最直接的问题“新财富怎么创造”，再追问“为什么偏偏是你能看到”，最后回答“怎样让财富不再依赖你本人”。

## 三幕叙事

### 第一幕｜财富怎么创造？

原力创业：

> 找到秘密，把它复制一万倍。

四个教学动作：

```text
见 → 名 → 繁 → 守
```

对应正典：

```text
原力借势 → 品类独创 → 模式升维 → 壁垒锁定
```

### 第二幕｜为什么偏偏是你？

原力资产：

> 看见秘密的那双眼睛，本身就是一种资产。

对应：

```text
发现母体 → 回到母体 → 获得原力 → 显化原力
```

### 第三幕｜怎样让它不再依赖你？

原力 OS：

> 让团队与 AI 继承你的判断，让事业在你不在现场时仍然继续生长。

对应：

```text
一纸文脉 → 一个大脑 → 一张地图 → 一条链路
```

白话：

> 懂你 + 记得住 + 会判断 + 能行动 + 每次变强。

## 母公理

> **做会自我繁殖的事，不做一次性的事。**

任何输出不能成为下一次输入，就不是原力资产；任何系统不能让下一轮更强，就不是原力 OS。
