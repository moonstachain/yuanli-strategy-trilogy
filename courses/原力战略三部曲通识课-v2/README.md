## 一、课程母命题

> **新财富的本质，是找到这个世界上只有你才能发现的一个秘密，并把它复制一万倍。**

这里的“秘密”不是内幕、信息差或短期套利；“一万倍”也不是简单卖一万份。

后台严谨解释：

> 原力秘密，是一个人的独特生成源，与时代变化和用户贵问题相遇后产生的、尚未成为共识但能够接受现实验证的价值真相。

> 一万倍，是让原本只能在本人身上发生一次的高质量价值，跨人、跨产品、跨组织、跨 AI、跨时间持续发生。

## 二、1+3+1 五课结构

这不是把一堂课拆成五段，而是一条完整认知阶梯：

> **1 个母概念 → 3 次事业跃迁 → 1 次人生升维。**

```text
第一课｜原力战略
看懂新世界
财富规则变了，我到底应该经营什么？
        ↓
第二课｜原力创业
创造新财富
秘密怎样被发现、命名、繁殖和守住？
        ↓
第三课｜原力资产
找到独特的你
为什么有些秘密偏偏是你更可能看见？
        ↓
第四课｜原力 OS
建立会进化的事业
怎样让这种能力脱离本人继续生长？
        ↓
第五课｜原力人生
回到这一生
什么才值得被持续复制与留下？
```

整门课回答一个越来越深的问题：

> **AI时代，怎样把一个独特生命，活成一个会复利的事业与人生？**

## 四、正典与教学法权

本课程**不修改 Soul 的 A→B→C 正典因果顺序**。

### 后台正典

```text
原力资产 A
→ 原力创业 B
→ 原力 OS C
```

这是：

> 独特生成 → 现实选择 → 系统保留 → 递归再生成。

### 五课前台教学

```text
原力战略
→ 原力创业 B
→ 原力资产 A
→ 原力 OS C
→ 原力人生
```

其中：

- 第一课建立世界观，不展开十二模块；
- 中间三课采用 B→A→C 的体验顺序；
- 第五课是整合课 / 毕业课 / 价值方向课；
- “原力人生”不是第四部，也不是第十三模块。
